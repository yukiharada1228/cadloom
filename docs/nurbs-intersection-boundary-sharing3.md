# 元面UV境界と交差辺の有限区間一致

`matchNurbsIntersectionSourceBoundary3(refined)`は、細分交差グラフとsourceトリム境界の共有区間を返す。ターゲット側の一般的な対応は別途必要であり、このAPIで認定しない。

境界の分割にx/y座標微分の全零点を加え、各境界片を両座標について単調にする。ノット・交差頂点と元のringの向きも保持する。ゼロ多項式や定数の微分に根列挙を適用しない。

通常の交差枝では、境界span全体を平方因子除去後の非垂直多項式へ同次代入して恒等零を確認する。垂直枝は、境界のuが選択枝の固定uと全spanで一致することを確認する。端点や少数の中間点が一致するだけでは採用しない。

選択した投影座標の単調な範囲と交差辺の範囲を交差させ、正の長さの部分だけを扱う。境界パラメータへ正確に逆写像し、選択枝上の内部点を照合する。元グラフの辺内部には枝の交差イベントがないため、恒等式・単調性・内部の枝選択から全区間で同じ枝を保持する。両閉端点も独立に照合する。

戻り値はboundaryEdge/intersectionEdgeと、増加順の境界パラメータ範囲・交差辺パラメータ範囲、両進行方向の一致/反対を示すdirectionを持つ。辺の全長が一致する場合に限らず、有限な部分一致も保持する。元のグラフや境界をこの段階で統合しない。

テストは水平・逆向き・垂直、相手の有限範囲による部分一致、曲線境界とノット、端点と中点が直線上にあっても全体は異なる三次境界を扱う。

次はターゲット側のパラメータ写像と折り返しの処理、共有区間の共通原子化、UV配置の枝順序と閉ループ抽出が必要。これは材料・面の埋め込み・一般BRepの認定ではない。
