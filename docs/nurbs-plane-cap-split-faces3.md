# 再切断した有限キャップのB-rep採用

`buildNurbsCapSplitFaces3` は所有された子キャップ境界分割から各側の有限面領域を再認定し、共通のB-rep位相エンジンへ採用します。既定では両側を組み立て、sideを指定すれば片側の開いた面集合を作ります。元の曲線区間・代数的端点・切断直線のオブジェクトを保持し、両側の切断辺は同じ辺を逆向きに共有します。

外周と直属の穴を各面のループへ写し、元キャップのsenseと既存の有向境界を保持します。全辺の有限面所属は認定済みループ全体の使用関係から渡し、点のサンプルから全辺所属を推測しません。共通エンジンで辺の対向、次・前・双対coedge、境界ループ、頂点リンクと方向の整合性を検査します。結果は元の分割辺・頂点から採用後の番号への対応を持ち、片側に含まれない要素はnullです。空の側には人工的な面・辺を生成しません。

新しい面には所有された有限面領域とその面番号・側を保持します。`locateNurbsCapSplitSurface3` は空間点を面チャートへ逆写像し、支持平面外をoutside、有限面上を厳密な所属判定へ渡します。`nurbsCapSplitSurfacePoint3` は有限面に所属するチャート点だけを空間へ写し、穴・外部・未解決を伝搬します。構造をコピーした面は問い合わせできません。

これはキャップを構成する有限面の開いたB-repです。元NURBS面の再分割と共有辺のnoding・再接続、新しい閉立体の埋込みと材料認定は残ります。再切断Body APIやSolidCraft全体の再実装の完成を主張しません。
