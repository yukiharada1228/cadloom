# 有限NURBS面の平面符号セル

配置多項式の構築では、矩形境界だけで零になる一次式を省きます。矩形は別途セルを制限し、他の曲線と矩形境界の交点は既存の射影イベント計算が保持します。また、各支持式の重複因子を微分とのGCDで除き、既存の積との共通因子を正確に除算してから掛けます。開いた矩形内の零点集合を保ち、恒等的な重複による次数増大を避けます。平面符号は元の平面式から評価し、積の符号は使いません。

`partitionNurbsSourceFaceByPlane3` は、認定済み有限面のUVトリム、有限境界の端点イベント、各パッチ矩形、切断平面の同次多項式を使って曲線配置を作ります。配置の射影イベント間で、上下の連続した曲線枝または矩形境界に挟まれた開いた2Dストリップを列挙します。元の有限面内部に所属するセルだけを保持し、平面の負側・共面・正側を `sign` に記録します。

入力支持曲線の交点・特異点・矩形境界との交点は既存の厳密な曲線配置の射影イベントになります。イベント間では枝の順序と支持多項式の符号が一定です。標本点の有限面所属は、実際のトリムと元の面の識別を用いて評価します。支持曲線が存在するだけで面領域とみなすことはありません。

`nurbsSourcePlaneCellPoint3` は、セルの開いたu区間と上下の枝の間の有理な割合を受け取り、代数的なUV点を構成します。元の有限面の内部所属、片側パッチ、実際の空間点での平面符号を再検査します。区間端点・割合0/1・複製された報告・不正なセル番号は拒否します。

これは開いた2Dセルの分解です。射影イベントのu座標・曲線頂点・支持曲線は配置グラフに残りますが、イベント上の1Dファイバーの面所属はまだ列挙しません。また、閉セルの全ての隣接関係、元の断面との共有辺の対応、キャップ面、縫合された子Bodyはまだ生成しません。各ストリップを独立したBRep面として公開することもありません。元の面を正負へ分割して再構築するための中間表現です。

初版の動作テストは2ケースとも成功しました（178439.093417 ms、失敗・キャンセル・スキップ0）。穴のある有限面の両側、穴の除外、共面セル、非線形曲線で囲まれたストリップ、セル点評価と入力ガードを確認しました。ただし曲面ケースに176757.214209 msかかっています。定数倍の支持多項式を正規化して重複を除く改訂版でも2テストが成功しました（120856.144125 ms、失敗・キャンセル・スキップ0）。曲面ケースは120426.232625 msでした。実行条件が異なるため厳密な速度比較ではなく、計算時間は引き続き課題です。定数倍は零点集合を変えません。

改訂版のビルドとstrict型検査は成功。独立スナップショット `/tmp/cadloom-planecells215b-staged` はビルド・strict型検査済みで、248ソースのハッシュとステージ済みソース・テスト512ファイルの一致を確認しました。関連4ファイル24テストが成功しました（162606.588208 ms、失敗・キャンセル・スキップ0）。全リポジトリの検証や新規形式証明は主張しません。
