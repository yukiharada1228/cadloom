# 定義から構築した材料境界のシェル領域解析

`materialSurfaceRegions3` は、実際の `boundaryMaterialSurfaces3` の結果だけを受理します。閉じた多様体接続を要求し、任意の復元レコードや構造コピーをこの認定経路へ受け入れません。対象は完全支持分割と材料の両側分類から構築した、現在対応する有限円柱・半空間の材料族です。

領域を持つ各面をレコードへ変換して再構築し、完全な面境界を共有辺へ結びます。既存の正確な直線交差エンジンで各シェルの両側に厳密な有理点を取り、全シェルの交差から包含関係を求めます。循環や不整合な包含を拒否し、各シェルの親・深さ・物理的な向き・材料の内外が一致することを検査します。境界上にある候補点は判定せず再試行します。

`strictCylinderMaterialProgramLocation3` は所有されたプログラムの厳密な証人点用の判定です。全プリミティブ境界から離れた点だけをinside/outsideとし、それ以外はnullを返します。正則化境界上の汎用locateではありません。旧材料境界の厳密な証人判定も同じ実装へ接続します。

返却値はシェルの親子関係、材料領域の表、材料内部点と面領域付きレコードを持ちます。所有された結果の復元面は内部の `finiteCylinderRegionFaces3` で取得できます。閉じた接続を持つ任意の輸入B-repに対する一般的な埋め込み検証器や、共通Bodyの採用・保存形式を完成させたものではありません。
