# 曲面の両方向の厳密な局所符号

`surfaceGermSides3(p, v, surface)` は、十分小さな正の `t` に対する `p - t*v` と `p + t*v` の符号を `{minus, plus}` で返します。平面は与えられた法線の向きを保持し、円柱は内部が負です。有限の epsilon を選んだり座標を丸めたりしません。ゼロは未知ではなく、その直線の局所経路全体が支持面上に留まることを意味します。

平面の代入式は一次式です。円柱の代入式は、軸方向を `d`、軸原点を `o`、二乗半径を `r2` とすると、次の二次式です。

```
f(t) = |d × (p-o)|² - r2*|d|²
     + 2*t*((|d|²*v - d*(d·v))·(p-o))
     + t²*|d × v|²
```

定数項が非ゼロなら両側の符号は同じです。定数項がゼロなら一次項を調べ、それもゼロなら二次項を調べます。一次項の符号だけが負方向で反転します。全係数がゼロなら、その経路は支持面上です。点は代数的座標に対応し、方向と支持面の定義には有理数を使います。

既存の円柱材料式の境界照会にあった方向別の半径判定を、この共通関数に接続しました。軸方向に沿って支持円柱上に留まる場合の再試行と、有限円柱の高さ境界の判定は既存処理に残します。円柱の有限な面領域や立体の判定を、この支持面の符号だけで代替しません。

平面分割セルの内部点と面法線を使えば、内部点での両方向の符号を得られます。ただし、セル内部に未分割の交差・零点が残らないことを示すまでは、内部点の結果をセル全体の材料分類とは呼びません。一般NURBSや接触の全体分類は未対応です。

検査では交差・接線・支持面上に留まる方向、ゼロ方向、法線反転、無理数の接点、10^-100の非ゼロずれ、軸の移動・再パラメータ化を確認します。有理座標147組について、別途3点で評価して復元した多項式係数をオラクルとし、方向反転も確認します。新規4件と型検査は成功。既存133宣言の限定監査は成功していますが、このAPIの形式証明ではありません。
