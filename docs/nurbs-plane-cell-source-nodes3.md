# 共有辺の分割点をセル閉路へ反映

`nodeNurbsPlaneCellSourceEdges3` は所有された全区間の共有辺照合を受け、元の共有辺の全ての子区間に合わせてセル辺を分割します。元境界の照合が未解決の場合は、元の報告を保持した未解決結果を返し、部分的な成功結果は作りません。

子区間の両端を、認定済みのパラメータ対応曲線へ逆写像します。`nurbsSpanIntervalMatchParameters3` は指定側の有限区間を検査し、反対側の全実候補を求め、両曲線のXYZで再検査します。セル辺の節点化では逆像が一意であることを要求し、複数の場合は未解決として保持します。

逆写像を回収済みの有理写像でUV・空間点へ戻し、セルnative parameterが増加する順に新しい辺を作ります。元のセル辺から子辺への対応、元の共有子辺番号と厳密な部分区間、向き、元のセル頂点番号または新規頂点、共有トポロジー頂点番号を保持します。点の統合はUVの厳密な等値と空間座標の一致によります。

新しい子区間が元の全区間を隙間なく覆うこと、連続した子区間の端点、元の最終端点を検査します。セル内で逆向きに使われる辺は、子辺列と使用方向をともに反転して展開します。全てのセル閉路と既に単純と認定された領域閉路の接続を再検査します。曲線を端点間の弦へ置換しません。

共有辺への対応がない面内部の辺は、その元の暗黙曲線とnative intervalを保持します。単純な閉路ではない領域の `cycles: null` も保持します。この処理はセル辺の接続情報の整合であり、分割面や閉じた子Bodyを新たに認定するものではありません。一般の暗黙SSI枝の未解決対応、キャップの構築と縫合は引き続き必要です。

得られた単純な領域閉路を共通BRepの分割面へ組み立てる処理は `buildNurbsPlaneSplitFaces3` が提供します。

独立スナップショットでビルド、関連2ファイルのstrict型検査、関連12ファイル44テストが成功しました（8514.162333 ms、失敗・キャンセル・スキップ0）。全ての立方体面で共有辺の追加分割をセルへ反映し、元の各子辺が物理的に逆向きの二つの使用を持つこと、区間被覆と閉路、共有トポロジー頂点を検査しました。円柱の曲線キャップと壁、非線形パラメータ対応、未解決入力の保持も含みます。256ソースのハッシュとステージ済みソース・テスト532ファイルの一致を確認しました。全リポジトリの検証や新規形式証明は主張しません。
