# セル境界と元の共有曲線の全区間対応

`matchNurbsPlaneCellSourceEdges3` は所有された共有辺の細分化と、一つの有限面のセル複合体を受けます。既存の頂点逆写像で、同じ面・支持平面と面に接続する候補辺を確認します。

セル配置の開いた辺が元の面内部にある場合は `interior` を返します。元の有限境界上の一定u/vの経路は、有理な定数座標でパッチの同次多項式を厳密に制限して、空間の有理曲線を取り出します。辺の両端の逆像は候補の元辺と有限区間を絞るために使い、成功判定には全XYZのパラメータ対応曲線と両区間の完全な被覆を要求します。

成功した `matched` は元の共有辺番号、全区間対応の認定、その区間を覆う細分化済みの子辺列を保持します。子辺列はセル辺のnative parameterの増加に合わせた順序で、逆向きの場合は列と使用方向をともに反転します。子辺の一部だけに対応する場合は厳密な部分区間を残します。セルの閉路で逆方向に使う際の反転は、利用側の別処理です。

元の支持配置と有限境界の端点イベントが辺の開区間を分割済みであることを前提とし、その区間の有限面stratumを評価します。端点や標本の一致だけで曲線全体を同一とは判断しません。

一定座標が非有理の場合や、一般の暗黙曲線の有理写像をまだ取り出せない場合は `unresolved` と理由を返します。候補の被覆が認定されない場合も未解決です。`allOriginalBoundariesMatched` はこの報告内の元境界経路に未解決がないことを表し、面・立体の完成を意味しません。一般の曲線トリム、セル辺の全共有分割点での節点化、キャップとの縫合と子Body生成は引き続き必要です。
