# 共通の曲線切断イベント

`curveNodingPoints3(a, b)` は、有限な直線区間・代数的端点の線分・円弧・楕円弧について、分割に必要な点を返します。孤立した交点、接点、重複区間の端点を含め、厳密な代数的等値で重複を除き、辞書順に並べます。引数の交換や走査方向の反転は点集合を変えません。

重なる曲線の全点集合を返すAPIではありません。閉曲線の一致では表現上のシームを切断点に残します。接触の多重度、交差の向き、面領域や立体の成立は認定しません。

`collectCurveNodingEvents3(curves)` は各入力の端点と全ペアのイベントをまとめ、各点に集まる入力曲線のインデックスを保持します。配列・イベント・インデックス配列は凍結します。元の面や切断面との対応は呼び出し側が入力インデックスへ対応付けます。これは元の面IDを推測する処理ではありません。

`partitionPlanarFaceByCylinders3` はこの集約器を利用して既存の平面上の分割を構築します。平面／円柱専用ファイルにあった支持楕円への変換と線分の交差処理を共通モジュールへ移し、トリム面の照会でも同じ線分処理を利用します。旧内部インポート経路には再エクスポートを残します。

一般の曲面間交差、円柱SSI曲線同士の切断、NURBS曲線、重複区間の明示的な対応、材料分類・縫合との全面統合は後続です。この変更は一般BRep Booleanの完成を意味しません。

検査では、ねじれた線分の非交差、端点接触、重複線分、無理数交点、接線、円弧の有限範囲、同一円上の重複、三本の曲線が集まる点の由来を確認します。既存の面分割・トリム・混合材料の回帰も対象にします。新しいAPI自体のLean形式証明は追加していません。
