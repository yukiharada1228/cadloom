# 複数の再分割NURBS有限面と元共有辺の再縫合

`sewNurbsRecutSourceFaces3` は所有された前回の面集合、同じ元形状の新しい共有辺細分化、全旧有限面の再分割・採用結果を受け取り、元の共有source曲線区間を統合して縫合します。前回の有限面の同一性で入力を管理するため、一つの元面から残った離れた同符号領域も別々に扱えます。各旧有限面がちょうど一度供給されることを要求し、欠落・重複・異なる所有面を検査します。

通常の初回分割と、共有辺上の全区切り値の統合、辺使用の展開、逆向き使用、有限面の所有権、B-rep位相再構築を共用します。両側をまとめると元の有限面集合を維持し、side指定ではその側の面だけを残します。旧面集合をpreviousとして保持し、入力辺・面から出力への対応表を引き継ぎます。通常の初回APIは制限付き再分割入力を受け付けず、元形状全体として誤採用することを防ぎます。

元の完全な形状ではなく前回の面集合の閉鎖状態を基準に検査するため、キャップのない旧半面集合を誤って閉立体と要求しません。再分割の方向・頂点リンク・境界ループが整合しない場合や、閉鎖状態を保つべき集合が保てない場合はrecut-incidenceとして未解決です。未解決の旧集合も成功扱いしません。

これは元共有source辺による再縫合です。前回のsection曲線を共有する別の旧有限面同士、複数の元面と旧キャップを一括する区間統合、新しい切断平面の閉鎖面、全立体の埋込み・材料認定は残ります。再切断Body APIやSolidCraft全体の再実装の完成を主張しません。
