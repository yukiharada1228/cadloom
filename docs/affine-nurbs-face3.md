# アフィン左逆写像で認定されたNURBS面

`createAffineNurbsFace3` は、所有されたアフィン左逆写像証明書と、パラメータ空間の外周・穴から、所有された埋め込み面を構築する。前段の[左逆写像証明書](nurbs-affine-projection3.md)を一般NURBSの認定へ拡大しない。これは共通Bodyの面テーブルへの採用、共有稜線の縫合、閉ソリッドや材料領域の認定ではない。

## 成立条件

入力のdomainのlocate/sampleは使用せず、曲線と向きから外周と穴を再検査する。外周は単純なJordan境界、穴は互いに接触も入れ子もなく、外周の厳密な内部にある。senseに従う巡回方向を保持する。

各境界曲線を `liftNurbsSurfaceBoundary3` で空間へ写す。曲線の全spanについて、全表面節点の逆像で分割し、各開区間が有効なパッチ内にあることを確認する。境界は連続なため端点も閉じた矩形内にある。端点や制御点だけによる包含判定ではない。支持矩形は凸なので、外周全体が矩形内ならその有界Jordan内部も矩形内である。矩形外の部分を自動で切り落とす操作ではない。

左逆写像を持つ支持曲面は矩形上の連続な埋め込みであり、その部分集合である閉じたJordan領域への制限も埋め込みである。したがってパラメータ境界の像が面の境界になる。各一側パッチの階数は2だが、節点に連続な折れ目があってもよい。C1/G1の滑らかさは認定しない。この説明は新しい実装のLeanによる機械証明ではない。

## 公開操作

- `boundaries` は外周、次に各穴の順の空間境界で、元の曲線順・方向・パラメータとパッチ片への対応を保持する。これは既存の混合BRep稜線へ自動変換されたものではない。
- `sample` は検査済みdomainの厳密な内部witnessを曲面へ写した点。
- `locateAffineNurbsFace3` は入力点を一度snapshotし、厳密な支持面所属を確認した後にUVのトリム所属を返す。空間射影だけでは受理しない。insideは面の相対内部であり、立体材料の内部ではない。
- `affineNurbsFacePoint3` は閉じたトリム領域内だけで曲面評価する。
- `intersectAffineNurbsFacePlane3` は既存の全トリム断面を用い、曲線、孤立点、平面に含まれるパッチ領域を返す。これをBodyの切断完了とは扱わない。

factory所有をWeakSetで確認し、コピーしたfaceやprojectionで認定を偽造できない。公開値は不変で、domainは入力から再構築する。

## 検証

新規6件と既存31件の計37件が成功した。穴の内部・境界、同じUV射影を持つ支持面外の点、代数的な点、全境界の閉鎖、穴で分離する平面断面、端点が有効でも途中で支持矩形を出る曲線の拒否、反対のsense、C0折れ目の境界分割と断面の接続、偽のdomainメソッド、所有検査、入力getterの一度だけの読取りを確認した。全体回帰はこの記録では完了していない。
