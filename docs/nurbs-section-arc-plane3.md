# 有限NURBS交差枝と別平面の交差・分割

`intersectNurbsSectionArcPlane3(arc, plane)` は、所有された有限の交差枝を別の平面と照合し、`none`・`points`・`overlap` を返します。平面は有理数でスナップショットします。

```ts
const hit = intersectNurbsSectionArcPlane3(arc, plane);
const split = splitNurbsSectionArcByPlane3(arc, plane);
// split.pieces: {arc, side}[]。元のarcの巡回順。
```

## 交差の意味

`points` は元のuまたはvの `parameter`、`parameterPoint:{u,v}`、正確な空間 `point` を持ち、arcの巡回順に並びます。同じパラメータは重複させませんが、異なるパラメータが同じ空間点へ写る場合は別々に保持します。多項式根の重複度や交差・接触の種類までは返しません。孤立した接触点も交点として残します。

`overlap` は有限arc全体が平面上にあります。交点のサンプル列で全体一致と推測することはありません。`none` は閉区間の端点も含めて交点がない場合です。

## 厳密な解法と共通因子

空間成分を同次多項式 `(X,Y,Z,W)`、平面を `(a,b,c,d)` とすると、平面上の条件は `G=aX+bY+cZ+dW=0` です。有効範囲では重みWが正なので、分母のゼロによる見かけの解はありません。

- 垂直な元グラフ辺はuが定数です。正確な代数的uにおけるGのfiberを解き、有限のv根または全fiberの一致を区別します。
- 通常の辺は重複因子を除いた非垂直暗黙式HとGの連立方程式を解きます。候補のuを元の枝の評価へ戻し、vが一致するものだけを採用するため、同じuの別枝の交点を混ぜません。
- HとGに共通因子Dがある場合、元の投影分割グラフの辺が、特異イベントのない単一の開slabの枝であることを使います。Hの多項式因子Dはこの開枝全体を含むか、イベント端点でのみ接触します。したがって、既存のグラフ構築の成立条件と厳密な共通因子を前提に、元の内点でDがゼロかを調べて全体一致を判定できます。任意の空間曲線で一点の平面所属から一致を推論する手法ではありません。
- 連立方程式の解表は共通零点集合上の点を除外します。別の枝がその集合へ端点で接する場合を落とさないよう、有限arcの両閉端点は別途Gで検査します。

この手順は所有された単一グラフ辺の区間に限定します。パッチや投影イベントをまたぐ任意のパラメータ区間へ一般化しません。

## 分割後の側

`splitNurbsSectionArcByPlane3` は有限の交点パラメータですべて分割し、正の幅の断片を元の巡回順で返します。`side:-1|1` は断片の相対的な開内部の平面側です。閉端点は切断平面上でもかまいません。全体一致は元arcを1片として `side:0` で返します。

全交点を除いた開区間ではGは連続でゼロを持たないため、正確な中間点の符号が区間全体の符号です。非一致の断片の中間点がゼロなら未分類としてエラーにし、ゼロ側として成功させません。接点の両側が同じ符号でも、接点で分割した2片を保持します。

空間像の埋め込み認定、トリム領域全体との交差、NURBS Bodyの切断、BRep辺への採用、一般の2曲面交差は未実装です。計算時間とメモリの固定上限は未保証です。
