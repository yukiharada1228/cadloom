# NURBS曲面とアフィン逆写像付き曲面の閉パッチ交差

`intersectNurbsSurfaceAffineTarget3` は、一般の正重みNURBS元曲面と、所有されたアフィン左逆写像を持つターゲットについて、全閉パッチ対の交差を解く。`solveNurbsAffineIntersectionEquations3` は[既存の消去方程式](nurbs-affine-intersection-equations3.md)を再利用する入口である。ターゲットにも逆写像がない一般NURBS同士のSSIや、トリム付き面の交差を完成させたものではない。

## 完全な閉集合の表現

各パッチ対の3残差を同時に解き、共有零点曲線と、その外の有限解を保持する。共有因子に実曲線がなく孤立実点だけがある場合も、実零点グラフから点を保持する。

元のパッチ矩形内では元の重みWは正である。ターゲット座標A/W、B/Wの閉矩形条件を、A−uMin W、uMax W−A、B−vMin W、vMax W−Bの4つの多項式が非負という条件へ変換する。これらとの全交点と、共有因子による全区間の重なりで元のグラフ辺を分割する。垂直辺は特殊化した一変数方程式で切る。全イベントで分割した後の開区間を分類し、閉端点・孤立接触も残す。サンプルだけで交点を探索しない。

出力のverticesは元の(u,v)、ターゲット座標、空間点を保持する。edgesは元グラフ、sourceEdge、保持された閉区間、頂点番号を持つ。枝は通常u、垂直辺はvで評価する。評価は所有・番号・閉区間と、元の両曲面の厳密な一致を再確認する。

パッチ間のseamや異なるパラメータの同じ空間点は統合しない。元の曲面は折り返し・特異点・不連続を持ってよく、パラメータ曲線の像が空間曲線として単純・正則・非退化であるとは宣言しない。

## 恒等零のパッチと非空性

全残差が恒等的にゼロのときは、4不等式と元の矩形の共通部分を暗黙の閉集合として保持する。その集合は空、線や角だけ、面積を持つ集合、複数成分のいずれにもなり得る。

非定数の制約多項式の積の零集合を、元の有理矩形で完全に分解する。全射影イベントのuと各開slabの厳密なuを使い、各fiberの全非垂直零点とv側端点でvを分ける。全零点と全開区間を調べ、元の不等式を満たすwitnessを探す。垂直因子、孤立した零点、矩形辺・角だけの接触も含む。積の零集合外では全制約の符号が一定であり、イベントfiber上も全根で分割するため、全ての符号セルを代表する。witnessが存在する場合だけregionを残す。

regionは非空の閉パラメータ集合と所属述語であり、正の面積・連結性・全境界列挙を主張しない。潰れた元曲面なら、その空間像は1点の場合もある。`empty` はこの対象クラスの全閉パッチ像の共通部分が空であることを表す。

これは実装契約の数学的説明であり、新実装やTypeScript全体の機械証明ではない。

## 制限

トリム領域の外周・穴による制限、面領域の分割、seamをまたぐ混合次元の全体位相、region境界の明示的な列挙、一般ターゲットのSSI、殻全体の幾何・包含・材料認定、共通Bodyへの採用は残る。

## 検証

両矩形で切られた双曲線、正定値多項式による孤立実接触、折り返した元曲面の二つの垂直枝、重なり・線だけ・角だけ・空集合、非定数重み、一側パッチ由来、潰れた元曲面、所有・番号・範囲を確認する。内部helperは孤立した接線接触、全共有因子、孤立点・垂直セルのwitness、実解のない集合、幅10^-40の帯も直接試験する。
