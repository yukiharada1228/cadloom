# セル頂点と元の共有辺の対応

`nurbsSourcePlaneEdgeFragmentPointPreimages3` は所有された有限共有辺と厳密な空間点を受け、その閉区間内の全てのパラメータ逆像を返します。非定数座標の有理関数に対象座標の最小多項式を代入して全実候補を分離し、選択された実座標との一致と全XYZの一致を再検査します。定数座標が一致すれば次の軸へ進み、zだけが変化する辺も扱います。区間外・別の共役・一座標だけ一致する点は採用しません。

定数の有理座標は分子と分母の係数比から比較します。有限区間外の `startParameter` で同次重みが零になる合成曲線でも、その位置を評価して0/0を生じさせません。

`matchNurbsPlaneCellSourceVertices3` は所有された共有辺の細分化とセル複合体を受け、同じ元の有限面・同じ支持平面であることを検査します。各セル頂点を、その面に実際に接続している子辺だけに逆写像します。元のトポロジー頂点と一致する場合はその番号を返し、一致しない場合も子辺内部の厳密なパラメータを保持します。このパラメータは次に共有辺を追加分割する位置です。

元の面の有限境界上の頂点に逆像がなければ不変条件違反です。面内部に新たに生じたセル頂点は共有辺に対応しないことがあります。既存のcoedge、面番号と元のUV面IDを区別します。

これは点の対応です。端点・標本の一致から辺全体の一致を主張しません。追加パラメータでの共有辺の再細分化、曲線区間全体の対応、面の分割・縫合、キャップと子立体の生成は引き続き必要です。

逆像候補では同次重みが零の根を除いてから有理関数を評価します。分子と分母の共通因子による偽の根で0/0を生じさせません。独立スナップショットでビルド、関連2ファイルのstrict型検査、関連10ファイル43テストが成功しました（16656.78725 ms、失敗・キャンセル・スキップ0）。無理数の端点、zのみ変化する辺、XYZによる除外、有限区間外の点、定数座標と分母零の偽根、面に接続する子辺、追加分割パラメータ、所有と面のガードを含みます。252ソースのハッシュとステージ済みソース・テスト521ファイルの一致を確認しました。全リポジトリの検証や新規形式証明は主張しません。
