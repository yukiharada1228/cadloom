# NURBS切断面のキャップ境界

`nurbsPlaneCapBoundary3` は所有された片側の分割面縫合結果から、キャップ側の向きで境界ループを取り出します。元表面に閉じた向き付き接続があること、片側表面の接続と頂点リンクが整合すること、境界が単純な接続サイクルに分解できることを要求します。

切断平面上という判定は端点や有限個のサンプルでは行いません。元の共有辺の場合は既存の共面フラグを使い、内部切断辺の場合は同じ有限曲線が正と負の領域の閉包に属する由来を要求します。各閉包では平面式の符号がそれぞれ非負・非正なので、その共有曲線全体で平面式がゼロになります。これを確認できない境界は未解決です。

ループは既存の開いた表面の境界coedge列を逆順にし、各方向も反転します。元の辺ID・曲線・有限パラメータ区間を保持します。平面チャートの法線は切断平面の法線に一致し、キャップに要求する材料側のsenseは選択側の符号の逆です。元シェルの材料方向が未認定の場合、ループとこの法線の幾何学的な一致までは認定しません。`nurbsPlaneCapBoundaryPoint3` は所有された境界辺だけを元のパラメータで厳密に評価し、その平面チャート座標を返します。

離れたループ、穴に対応するループ、円形曲線をそのまま保持します。端点多角形の面積から曲線の内外を推測しません。ループの包含関係、外周・穴の分類、材料領域ごとのグループ化はまだ行いません。これはキャップ面や閉じた子Bodyの認定ではなく、キャップ生成に必要な向き付き境界です。元表面が閉じていても幾何学的埋込み・材料の認定は別途必要です。
