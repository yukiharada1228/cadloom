# 三回目の平面で既存の閉境界全体を細分化

`repartitionNurbsRecutSourceFaces3` は、現在の閉再切断境界に実在する各有限NURBS面だけを、祖先の領域制限を保持して再分割します。各面から新しいcell・native曲線・有限領域を構築し、現在の親faceへ対応します。元の面番号だけで異なる有限領域をまとめません。

元の物理的共有辺は、所有されたtrim-map証明書と同じ元raw sourceに対する正準native区間へ戻します。各親coedgeについて、向きを含めて子区間がlowerからupperまで隙間・重複なく覆うことを検査します。切断で生まれた祖先section辺は既存の全親区間被覆を使います。新しい内部切断辺以外の全境界辺に親対応が必要です。未対応の辺を線分近似や端点の一致で補いません。

`subdivideNurbsRecutBoundary3` は、このsource面群と全旧／新キャップ分割を、一つの閉B-rep表へ組み立てます。同じ最終親edgeに由来する全端点の和で正準分割を作り、物理的source/source辺、source/cap section辺、cap/cap辺を同じ子edgeへ揃えます。native方向が逆の対応は子配列の順序と方向の両方を反転します。新しいsource内・cap内の切断辺は、それぞれの両側面で逆向きに共有します。

親curveと全区間のtrim／section対応が空間像一致の根拠です。元のcurveは保持し、メッシュや近似直線へ置き換えません。採用後に全辺2使用・逆向きcoedge・頂点リンクを含む `closedOrientedIncidence` を確認し、失敗時は診断付きの未解決を返します。入力edge・vertex・faceと親edgeから全体表への対応も保持します。

`faceSigns` は共通の切断平面に対する各有限面の符号です。元のNURBS面全体が平面上にある場合は0を保持します。既存capの支持面と平面全体が一致する場合は、現在のcap分割が未対応のため明示的に未解決です。元の境界辺に沿う接触や孤立接触から反対側の面を捏造しません。

`nurbsRecutSubdivisionCurvePoint3` と `locateNurbsRecutSubdivisionSurface3` は所有されたnative曲線の評価と実際の有限面への所属を扱います。source/capの区別と親face、各元surfaceの有限領域と向きを保持します。元capがない親や空の境界にも対応します。

検証では、三回目の平面で立方体の6面を10面へ分割した閉接続、曲がった暗黙sectionと余分な投影イベント、斜め分割、重み付き円柱、逆向きの空洞壁と島、負側の親、反射・拡大、平面上のsource面、共有辺全体の接触、capなし・空の境界を検査します。親native全区間被覆、全辺の逆向き2使用、入力表との対応、全辺中点の両有限面への境界所属、親有限面への所属、Euler標数と殻数の保持も照合します。

これは両側を保持した既存境界の細分化です。片側の選択と三回目の新キャップはまだ追加しません。閉接続は大域的な埋め込みや材料の認定ではありません。新境界の接触検査・埋め込み、殻包含・実際の向き・材料サンプル、任意回数の構築recordと共通Bodyへの採用を引き続き接続する必要があります。一般NURBS BooleanとSolidCraft全体の純粋TypeScript再実装は未完了です。
