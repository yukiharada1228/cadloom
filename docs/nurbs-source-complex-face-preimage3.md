# 認定NURBS面の空間点所属と逆像

`nurbsSourceComplexFacePointPreimage3` は所有された準備済み面複体、元の面ID、厳密な3D点から、その有限面への所属を調べます。支持曲面への投影だけでは所属と認定しません。

## 計算と検査

アフィン逆射影の証明がある面では、一意のUV候補を直接計算します。非線形の三角射影証明の場合は、その証明が保証する閉長方形の内部側パッチ極限に逆像計算を制限します。各座標の代数的根多項式から有理係数方程式を作る既存処理を再利用し、共役による余分な候補は3D全成分の厳密比較で除外します。

候補を面ごとの厳密UV照会へ渡し、トリム、穴、別の面、不連続な継ぎ目の反対側を除外します。UVと全ての面側パッチ像を返します。複数パッチに由来する同じUVは一つにまとめます。認定面は単射なので、異なるUVが二つ残る場合は不変条件違反です。対象長方形内に実際の正次元の点ファイバーが残る場合も、各パッチ側の階数2に反するため失敗します。未準備やUV照会の未解決は未解決として返します。

## 長方形内の一般逆像計算

`nurbsSurfaceRectanglePointPreimages3` は厳密な正の有界長方形を受け取り、その内部と正の面積で交わる各パッチを閉区間で切り詰めます。同次多項式・元のspan番号を保持し、逆像点、曲線グラフ、全パッチ領域のいずれも切り詰めた範囲で計算します。長方形の外側だけにあるパッチのノット値は含みません。

既存の全域 `nurbsSurfacePointPreimages3` の呼び出しと出力は維持します。新しい長方形版の返すpatchは範囲が部分区間になるため、元のNURBS span全体と同じ範囲だとは解釈しません。

この制限は重要です。例えばS=(u,uv,0)をu≥1/4にトリムした面は正則ですが、支持パッチ全体では原点の逆像がu=0の曲線です。長方形へ制限すれば対象面の外として判定でき、対象外の退化によって有限面の逆照会を未解決にしません。

## 範囲

最近点、距離、任意の非認定面の一意逆像、面群の大域的非交差、閉じた立体や材料は認定しません。新しいTypeScriptコードの形式証明でもありません。

新規回帰は、穴・外部・微小な面外点、非線形面の有理／代数的入力と共役除外、対象外の潰れたファイバー、不連続継ぎ目の面側、連続ノットの重複UVの統合、長方形の検査、全パッチ・曲線逆像の切り詰め、内側ノット極限を含みます。
