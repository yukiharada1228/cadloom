# NURBS面境界の完全な区間交差

`intersectAffineNurbsFaceBoundaries3` は、所有された二つのアフィンNURBS面の全外周・穴のlift済み片を交差させる。支持面内部どうしの交差（SSI）ではない。各対について、3つの有理空間座標の分母を払った二変数多項式の同時零点を解く。

## 有限解と重なり

有限解は両方の実際の閉区間で選別し、元の境界の3座標の厳密な再評価で一致を確認する。同じ空間点の異なる片・パラメータ対応は由来を保持する。共有因子は単なる点列へ近似せず、二つのパラメータ間の代数曲線グラフとして保持する。境界像は非定数なので、全パラメータ平面の関係にはならない。

グラフは元のパラメータ曲線spanの有理矩形で構築し、実際のlift片の代数的な閉矩形へ切り詰める。u側境界と、v側境界に多項式を特殊化した全実根で各グラフ辺を分割する。全区間の分類が一定となる開区間を残し、孤立点、角だけの接触、境界線との重なりも保持する。水平成分と垂直辺も扱う。サンプル点だけで切断位置を探すのではなく、全境界イベントを列挙した後で開区間を分類する。

`points` は有限解と保持した関係グラフの全頂点であり、重なりの端点も含む。純粋な孤立交点の配列ではない。`relations` は元のring/curve/pieceへの対応と、制限されたグラフを持つ。共有曲線の像を直線近似しない。

`affineNurbsBoundaryRelationPoint3` は所有された交差結果と選択した制限グラフ辺から、元の両パラメータと空間点を返す。所有、番号、区間、両境界の厳密な一致を検査する。座標軸は元のグラフ辺に従い、通常辺は最初の境界のパラメータ、垂直辺は二番目のパラメータである。

## 接続との統合

`sewAffineNurbsFaces3` は、異なる入力面の全対の境界交差を計算し、有限交点と関係グラフのイベント点も全端点分割へ渡す。結果の `boundaryIntersections` に完全な対ごとの報告を保持する。端点として与えられていない境界内部の交差も同じ頂点へ揃える。交差する面の境界を分割しても面内部が分割されるわけではなく、重複面や非多様体は接続診断に残る。

非線形な再パラメータ化による境界の一致は関係として検出できるが、共有辺の統合は現時点では有理アフィン対応の恒等式を使う。一般の曲面内部の交差、面分割、殻全体の埋め込み・材料、共通Bodyへの採用は残る。保存復元時にも既存の定義幾何からこの交差・分割を再生成する。

## 検証

端点以外の8交点を持つ境界の分割、別平面上の投影交差の除外、接線接触、非線形パラメータ関係、無理数のpatch境界での関係制限、両面の厳密な評価と順序交換、所有・範囲検査を試験する。矩形制限は放物線の二つの無理数切断、水平成分・垂直辺、孤立した角接触も直接試験する。従来の境界・接続・面の保存復元も回帰する。この新実装の機械証明や一般ソリッド認定の完了を意味しない。
