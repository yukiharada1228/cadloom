# NURBS曲面上の空間点の全逆像

`nurbsSurfacePointPreimages3(surface, point)` は、空間点へ写るパラメータを全ての閉じた一側パッチで求めます。有理数・代数的実数の点に対応し、単一の逆変換値や数値最適化の初期値へ縮めません。

```ts
const inverse = nurbsSurfacePointPreimages3(surface, target);
for (const p of inverse.patches) {
  const isolated = p.points;
  const completePatch = p.wholePatch;
  // p.locusVertices / p.locusEdges は p.locus の選択済みID。
}
```

`surface` と対象の `point` はスナップショットします。`patches` は非空の逆像を持つパッチだけを元の順で保持し、`empty` は全パッチに逆像がないことを表します。同じ節点のパラメータが複数の一側パッチで解になる場合は、その由来を別々に保持します。不連続な反対側の値を参照して一致を否定したり、空間自己重複からパラメータを1つへまとめたりしません。

## 多項式条件と共役根の除外

パッチの各成分をN/Wとします。対象座標aが有理数なら `N-aW=0`。代数的実数なら、その実根を囲む多項式Pについて `W^degree(P) P(N/W)=0` を有理係数の二変数多項式として構成します。3成分の連立条件を同時に解きます。有効パッチでは重みWが正なので、分母のゼロによる候補はありません。

Pには別の共役根や、最小多項式ではない余分な因子が含まれる場合があります。多項式条件だけで採用せず、元のパッチへ正確に写した3座標が指定された点に一致するかを検査します。

## 有限点・曲線・全パッチ

各パッチの逆像は次の和集合です。

- `points`：共通多項式零点集合の外にある有限解。u・vと、実際に写した空間pointを保持します。
- `locusVertices`・`locusEdges`：共通零点集合を矩形内で追跡したグラフ `locus` のうち、指定点へ写る頂点・辺のIDです。共有多項式があっても実曲線があるとは限らず、孤立した実頂点だけの場合も保持します。
- `wholePatch:true`：閉パッチ矩形全体が指定点へ写ります。

**locusそのものは候補グラフであり、別の共役座標へ写る枝も含み得ます。必ず選択済みIDを使います。**

共有零点集合上では各座標がPの有限な実根集合に入ります。元のパッチ写像は連続なので、連結な開グラフ辺の像はその有限集合の1点へ固定されます。その前提で正確な内点を検査して辺全体を選択し、閉端点の一致も検査します。全パッチが多項式条件を恒等的に満たす場合も、矩形の連結性と有限な候補値集合を使って一定像を判定します。一般の曲面の1点を評価しただけで、面全体が一定と推測する方法ではありません。

## 所有された結果の評価

`nurbsSurfacePreimageEdgePoint3(report, patchIndex, selectedEdgeIndex, parameter)` は、report.patches内のパッチと、その `locusEdges` 配列内の順番を受け取ります。rawなlocusの辺IDではありません。元の辺と同じuまたはvの閉範囲で評価し、u・vと実際の空間pointを返します。

`nurbsSurfacePreimagePatchPoint3(report, patchIndex, u, v)` はwholePatchの場合だけ受理します。両評価は所有されたreportを要求し、コピーした結果、不正なIDや範囲外を拒否します。評価後も対象点との一致を確認します。

これは逆像の計算であり、単射・埋め込み・正則な面・Bodyの認定ではありません。トリム領域による逆像の切り出し、節点をまたぐ全体の逆像位相、BRep・Bodyへの採用、保存交換レコードは残ります。時間・メモリの固定上限は未保証です。
