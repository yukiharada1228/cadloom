# 認定NURBS面B-repの構築入力保存と再検証

`encodeNurbsSourceBRep3` / `stringifyNurbsSourceBRep3` は所有された構築済みB-repから、元のsource/target曲面、両方のNURBSトリム領域とそのsense、B-repのsenseを保存します。全数値は有理数文字列です。面・辺の近似データ、認定済みフラグ、WeakSet所有、共有辺や殻の成立の主張を保存しません。

`readNurbsSourceBRepRecord3` / `parseNurbsSourceBRepRecord3` は未知フィールド・バージョン・種類・数値形式を検査して不変な構造スナップショットを返します。この時点では幾何を認定しません。既存の項目数・数値文字数の予算も適用します。

## 復元経路

`decodeNurbsSourceBRep3` / `restoreNurbsSourceBRep3` は曲面・境界を再構築し、次を再実行します。

1. targetの全域アフィン逆射影と両トリム領域の成立検査。
2. 支持曲面の交差と両有限トリムへの制限。
3. 継ぎ目の処理、微分イベントでの分割、UV共通境界、回転順序と面分類。
4. 面境界の片側リフト、面から近づけるパッチ側の選択。
5. 面内・境界・頂点の閉階数、位置連続性、埋め込みの十分条件。
6. 全区間の一致に基づく境界複体と、共通B-repエンジンによる接続。

未解決・未認定の面を含む結果は復元成功とはしません。復元したオブジェクトは新しいfactory所有を持ち、元の面照会・逆照会・有限境界評価を使えます。B-rep senseは明示的に保存し、loop方向とともに復元します。

保存入力を変更した場合は新しい幾何として全検査を受けます。幾何として有効な変更まで改ざんとして拒否する仕組みではありません。派生した面・辺IDは再計算され、将来の実装変更をまたぐ永続的な履歴IDは保証しません。

## 範囲

これは当該構築経路のレシピです。任意の輸入B-repのデコーダー、一般target NURBSの交差、複数source複体の縫合、殻の大域的埋め込み・材料・共通Body採用、商用形式やフィーチャー履歴を実装したものではありません。保存した殻フラグで材料を認定する経路はありません。

回帰は、穴と交差分割・負のsense、非線形面の復元後の代数的逆照会、暗黙SSI曲線、不連続継ぎ目と別shell、構造コピーと偽の認定フィールドの拒否、項目／文字予算、不正重み・壊れたトリム・アフィン逆射影を持たないtarget・閉階数が失敗するsource、targetトリムと逆向きsenseを検査します。復元後の再エンコード入力、頂点の厳密な値、接続件数も照合します。
