# 再切断の境界ゼロ辺と共有区間の対応

`analyzeNurbsRecutBoundaryZeroArcs3` は、所有された再切断B-repについて、元NURBS面の全平面ゼロ辺を面内部の曲線、残存面境界の区間、開区間に残存セルのない辺へ分類します。元の内部曲線・孤立点監査と接触証拠も `interior` に保持します。

## 区間全体の由来

残存面の境界にある各セル辺を、次の所有された全区間対応で追跡します。

1. 元セル辺から、元辺全体を順序付きで覆うnoded辺。
2. noded辺から、有限面へ採用された辺。
3. 採用辺から、元の共有曲線へパラメータ対応を持つ縫合辺群。
4. 縫合辺から、旧キャップとの共通分割も反映した結合辺群。
5. 結合辺から、選択半体と最終B-repの辺。

各層のfactoryが構築時に保証する全区間対応を使用し、noded区間の被覆、選択面への所属、各断片の向きと連結も検査します。逆向きの縫合では断片の順序と方向を両方反転します。端点一致は連結性の追加検査であり、異なる曲線の同一視には使用しません。

各証明書は全層の辺番号と入力・有限面を保持します。最終共有曲線のnativeパラメータは元セル辺のパラメータと異なる場合があり、`lower` / `upper` は最終曲線の値です。`direction` は元セルの正方向に対する最終曲線の向きです。

## 新キャップ別の分類

最終辺を同じ位相辺として使用するキャップには `declaredBoundary: true` を保持します。その開区間・両端点がいずれもキャップ境界にあることを照合します。別キャップの境界については、旧境界の埋め込みとcanonicalな全区間分割により、最終辺の開区間内部と交差しません。この条件で厳密な内点照会から開区間全体のinside/outsideを分類し、両端点は別に照会します。未宣言のboundary結果や連続性と矛盾する端点は未解決です。

`nurbsRecutBoundaryZeroArcPoint3` は所有された証明書に対する任意の厳密パラメータから、空間点と開区間／端点のキャップ分類を返します。

## 残る範囲

`coverage` は元の全ゼロ辺を列挙します。`discarded` はその開区間に残存セルがない意味であり、端点まで接触しないという主張ではありません。全ゼロ頂点の残存面とキャップへの対応、旧平面キャップと新キャップの接触、立体全体の埋め込み・材料再認定は残ります。結果は常に `certifiesAbsence: false` です。TypeScript全体の形式検証や一般の曲面交差の完成ではありません。
