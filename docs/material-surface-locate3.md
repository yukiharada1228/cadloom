# 直接構築した材料境界の位置判定

`locateMaterialSurfaceBoundary3(boundary, point)` は、実際の統合材料境界について `inside` / `boundary` / `outside` を返します。有理座標と既存の正確な代数的座標を受理し、旧材料境界を構築しません。

全プリミティブの境界から離れた点は材料式で判定します。プリミティブ境界上の点では、まず選択済みの有限な面領域を調べます。支持面上にあるだけでは境界とみなしません。

どの選択面にも属さないプリミティブ継ぎ目は、方向 `(1,k,k²)` に沿う正の微小変位の符号で判定します。平面の一次式と円柱の二次式の最初の非零係数を正確に評価し、全述語が決まる方向まで再試行します。数値epsilonは使いません。これは支持面分類を行った所有された材料族の正則化境界に対する照会であり、任意の復元B-repの一般位置判定器ではありません。

証人専用の `strictCylinderMaterialProgramLocation3` は別に維持し、プリミティブ境界上ではnullを返します。シェル領域解析がその点を再試行する契約は変えません。
