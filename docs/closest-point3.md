# 直線・線分・解析支持面の最近点

`closestPointOnLine3` / `closestPointOnSegment3` は有理点から直線または閉線分への最近点を返します。軸の正規化は不要です。線分ではパラメータを[0,1]に制限し、退化した線分はその点とt=0を返します。t=0は退化時の規約であり、全てのパラメータが異なる点を表すという意味ではありません。

`closestPointOnSurface3` は平面または無限の円柱支持面に対応します。平面は法線の長さの二乗を使った直交投影です。円柱は軸への足qと半径方向wを分け、wが非零なら `q + sqrt(r²/|w|²) w` を返します。距離の二乗は `|w|²+r²-2 sqrt(r² |w|²)` です。点と距離の二乗の共通する代数的依存を保持し、浮動小数や単位軸の近似を使いません。

円柱軸上では最近点が一意でないため、`kind: 'circle'` と最近点全体の円を返します。その他は `kind: 'point'` と厳密な代数的座標・距離の二乗を返します。距離の二乗も常に有理数とは限りません。

入力は有理点と有理な支持定義です。不正な平面法線・円柱半径・直線方向は既存の幾何ファクトリーで拒否します。トリムされた面や有限円柱・共通Body全体への距離ではありません。面の支持への足が有限領域外にある場合には、別途トリムや辺の最近点を検査する必要があります。

## 空間円と有限円弧

`closestPointOnCircle3` は入力点を円の平面へ直交投影し、その半径方向を円周へ伸縮します。法線方向の距離も距離の二乗へ含みます。円の法線軸上では `kind: 'circle'` と円全体を返します。

`closestPointOnCircularArc3` は円の最近点が弧に含まれることを検査し、含まれなければ両端点の距離を厳密比較します。最近点が二つの端点なら `kind: 'points'` の二点を辞書順で返します。弧の向きを逆にしても最近点集合は変わりません。法線軸上では `kind: 'arc'` と弧全体を返し、零長の点弧は一つの点として扱います。完全な円弧も明示的に区別します。

円上の端点qへの距離は、中心cを使って `|p-c|²+r²-2(p-c)·(q-c)` と評価します。qの座標を個別に二乗して合成せず、元の代数的パラメータを保持した線形式を使います。無理数端点の同距離判定もepsilonではなく厳密な代数的比較です。
