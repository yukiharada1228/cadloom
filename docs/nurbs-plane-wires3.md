# NURBS断面の材料向きの認定

`certifyNurbsBoundaryPlaneWires3` は、所有された境界断面の組立て結果を受け取り、各曲線辺の向きが材料を左側に置く閉路を認定します。認定は十分条件です。`not-certified` は入力立体が不正であるという意味ではなく、元の断面をそのまま返します。

平面を `n·x + offset = 0`、パッチの同次座標を `P/W`、`F = n·P + offset W`、元の面の向きを `s` とします。断面上では

```
n × (s (Su × Sv)) = (s/W) (Fv Su − Fu Sv)
```

です。したがって native parameter が u の辺には `sign(s Fv)`、v の辺には `sign(−s Fu)` を採用します。標本点で微分の符号を求めるだけでなく、完全な多項式零点分割により辺の開区間にその微分の零点がないことを検査します。偶数重根も検査対象です。端点では、近づく全パッチの `Fu` と `Fv` が同時に零でないことを検査します。

対象は単一パッチの有限面内部を通る辺と、組合せ的に閉じた成分です。共面領域、境界に沿う区間、パッチ継ぎ目上の区間、UV頂点との接触、射影微分の内部零点などは未認定として保持します。閉路を反転する場合は辺の順番と各辺の向きをともに反転し、全辺の幾何学的な向きと端点の接続を再検査します。入力のグローバル埋込み・材料向きの認定を前提とし、複製された入力は拒否します。

辺は元の暗黙曲線と代数的な端点への参照を保持します。多角形近似による判定や許容誤差は使いません。この処理は切断面の充填、平面領域の包含階層、子立体の生成・縫合・認定までは行いません。新たなLean証明やTypeScript全体の形式検証も主張しません。

検証: ビルドと新規テストのstrict型検査が成功。断面・有限面断面を含む3ファイル20テストが成功（失敗・キャンセル・スキップ0）。立方体、法線反転、空洞と材料島、重み付き円柱の両パラメータ方向、反射と保存復元、接線・共面・頂点接触、空集合、入力の所有確認を含みます。これは作業ツリーでの対象テスト結果であり、全リポジトリの検証完了ではありません。
