# 有限NURBSキャップと次の切断平面の交差

`intersectNurbsPlaneCapFacePlane3` は所有された有限キャップと有理平面を受け、平面同士が平行・同一か、有限領域との厳密な交差を返します。再切断で既存キャップを分割するための境界部品です。まだ再切断した面・立体を生成するAPIではありません。

非平行の場合は有理原点・方向の共通直線を作り、外周と直属の穴の全境界辺を既存の完全な平面イベント分割へ渡します。交点と全辺重なりの端点を直線パラメータで厳密に整列・統合し、各イベントに元のループ・辺・ネイティブパラメータを残します。共有頂点では両辺の由来を保持します。材料の島は別の有限面です。

この全イベント分割の開区間だけを既存の有限面所属判定で分類します。穴で途切れる閉区間、境界に含まれる区間、孤立した接点を保持し、連続する受理区間をまとめても各区間のinside/boundary分類を残します。有限サンプリングから境界根の有無を推定しません。巻き数探索の予算で解決しない場合はunresolvedを伝搬します。平面が同一の場合はcoplanarを返し、二次元の重なりを線分へ縮退させません。

一般の再切断には、元の分割NURBS面の再分割、キャップの面領域再構築、共有辺の再noding、新しい縫合・埋込み・材料認定が残ります。SolidCraft全体の互換性や実行コード全体の形式証明を主張しません。
