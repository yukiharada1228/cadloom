# 有限な平面Body境界の最近点

`closestPointOnPlanarBodyBoundary3(body, point)` は有理な直線辺・平面面から成る所有されたBodyの境界全体を調べ、最小距離の二乗と全ての同距離の最近点を返します。`closestPointOnPlanarSolidBoundary3` は所有された平面ソリッドを直接使う入口です。

各凸な面片で、平面への直交投影が有限領域内にあるかを世界座標の正確な半空間で検査します。領域外なら全ての辺の閉線分への投影を比較します。穴や非凸面は既存の正確な平面分解を使い、面の支持上にあるだけの点を採用しません。この分解は元の平面領域と一致し、表示用メッシュの近似ではありません。

全てのシェルと成分で距離を比較し、同じ幾何点は重複を除去して辞書順で返します。入力も出力も有理値で、距離の二乗も有理数です。空境界は `kind: 'empty'`、それ以外は `kind: 'points'` です。Bodyの検査済み平面表現はWeakMapで再利用し、構造コピーを所有されたBodyとはみなしません。

これは境界への距離です。材料の内部点にも正の境界距離があり、単位箱の中心では六つの面への足が同距離になります。材料内部を距離0とする「閉じた材料への距離」とは異なります。

曲面・曲線辺・有理でない頂点は明示的に拒否します。任意の曲面Bodyの最近点へこの結果を流用しません。円弧などの厳密な最近点処理を有限面の候補検査へ組み込む作業は後続です。
