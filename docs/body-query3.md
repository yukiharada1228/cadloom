# 共通Bodyの厳密な直線・レイ交差

`intersectBodyLine3(body, origin, direction, shell?)` は直線 `origin + t * direction` の全境界イベントを、厳密なtの順で返します。`intersectBodyRay3` は同じ直線の `t >= 0` のイベントを返し、始点の境界イベントも含みます。方向は非零の有理ベクトルで、単位長とは限りません。tは距離ではありません。

交点・パラメータは厳密な代数的数です。有理な値でも必ず有理数専用の表現で返るとは限らず、値の比較には代数的比較を使います。各イベントは元のBodyの面番号、有限面内での位置と支持面交差の重複度を持ちます。接線の二重根を横切りとして扱いません。

所有された `Body3` または `CellularBody3`（`BodyQuerySource3`）を受理し、有限面領域を記録から復元して完全な境界と共有辺の対応を検査します。復元結果はBodyをキーにWeakMapで保持し、以後の照会で再利用します。構造コピーや変更したレコードにキャッシュ所有を付与しません。

共有辺・頂点で複数の面が当たる場合や、直線が支持面に含まれる場合は `kind: 'degenerate'` を維持します。`containedSupports` はBodyの面番号です。支持面への包含は、その有限面が前方レイと重ならない可能性があっても保守的に報告します。これを「交点なし」や一意な最初の面へ置き換えません。

空洞・分離成分・空Bodyも同じ入口で扱います。任意の復元B-repや未対応曲面に認定を付与する入口ではありません。既存のBody所有と有限領域の受理範囲に従います。


CellularBodyでは、明示的な材料領域を持つ保存境界を復元して照会します。`shell` はその境界の辺接続シェルIDであり、開いた材料成分IDではありません。接触成分であっても一般位置の直線には正確な交差を返し、特異な接触そのものを通る場合は退化を保持します。配置による有限面の分割線上に当たる場合も、現在は保守的な退化を返す場合があります。
