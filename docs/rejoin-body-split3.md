# 共通平面切断の再結合

`rejoinBodyPlaneSplit3(split)` は、所有された共通平面切断だけを受理します。新しい界面を除いた実際の子の境界を縫い合わせ、それとは別に両子の材料の和から新しい共通Bodyを生成します。親Bodyをそのまま返すショートカットではありません。同じ切断への結果はキャッシュします。

```ts
const split = splitBodyByPlane3(body, plane3(1n, 0n, 1n));
const joined = rejoinBodyPlaneSplit3(split);
const saved = serializeBody3(joined.body);
const provenance = joined.faces[sewnFaceId];
// joined.sewing.sourceUses[sewnFaceId][loopIndex][coedgeIndex]
```

## 二つの構築結果

- `body`：両子の和から独立に生成・認定した共通Body。保存復元と後続操作にはこれを使います。平面経路は既存の再結合を呼び、元材料との正則化XORが空であることも検査します。曲面経路は共通材料Booleanの和を使います。
- `sewing`：子の実際の境界から、新しい界面面群だけを除いて再sewingした結果です。切断によって細分された外側の面を保持します。親オブジェクトの境界を返すだけではありません。
- `faces`：`sewing` の面ID順に、由来する `side:-1|1` と実際の子の `face` IDを返します。`sewing.sourceUses` は、この入力面のループ順・coedge順から新しい辺使用への対応です。各ループ内の配列順は子の実際のcoedge巡回と一致します。

`body.topology` と `sewing.topology` は面の分割・番号・並びが異なる場合があります。両者のIDを混ぜて使ってはいけません。縫合表をそのまま任意BRepとしてBodyに採用する入口を作るものではありません。

## 界面の打ち消しと成立条件

まず `bodySplitInterface3` で有限界面と両側の向き付き境界を照合します。その界面の面だけを両子から除き、元の有限境界と使用方向を取り出して縫合します。元の空洞壁が切断平面と一致して片側だけへ残る場合、その壁は新しい界面に含まれないため除去しません。

曲面経路では、縫合結果に閉じた向き付き多様体の接続を要求します。平面経路では接触保持CellularBodyを扱うため、その多様体条件は要求せず、全辺が2つ以上の使用を持ち、向きの和が0であることを検査します。辺を4面が使う結果を、多様体であるとは宣言しません。材料の領域認定は独立した `body` の構築を通します。

所有された切断の両子は、元材料と両閉半空間の正則化された積です。両子の和は元材料と一致します。両側で一致し物理的な向きが逆の新しい界面だけを取り除くので、残る有限面は元の物理境界の分割です。この由来と既存の材料認定を使う処理であり、任意に与えられた閉じた接続表の埋め込みを認定するものではありません。

片側だけの材料や空集合にも対応します。曲面の一般接触保持、親境界への全面的な由来、永続名、縫合表自体の保存復元、一般NURBSの切断、任意Bodyの接着・healingは対象外です。速度とメモリの上限は未保証です。
