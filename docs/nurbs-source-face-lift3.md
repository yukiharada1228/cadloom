# source UV面境界の片側空間像

`liftNurbsSourceFaceBoundaries3(faces)`は所有されたUV面分類から、境界・交差辺をsource曲面上へ対応付ける。未解決の面分類は未解決のまま返す。

## ノット分割と片側パッチ

各共通辺について、単調に変化するuまたはvを増加パラメータとする。曲面の全u/vノットとの有限な逆像を求め、その全位置で分割する。開区間を支える全ての閉じた片側パッチを保持し、閉端点もそのパッチ範囲にあることを検査する。両UV座標が単調で全ノットで切れているため、途中でパッチ範囲から出る区間を点サンプルだけで受理しない。

必要な境界または頂点が曲面の有効範囲外なら`outside-active-domain`、有限UV像を一意に求められなければ`uv-fiber`として未解決を返す。UV面分類だけを根拠に無効な曲面領域を採用しない。

## 位置の連続性

ノット線上の開区間で複数の片側パッチが残る場合、3座標の同次差を固定u/vで制限し、全多項式の恒等零を検査する。端点や中点の一致では代用しない。各切断点には隣接区間の全パッチからの像を保持し、元のUV頂点でもincident辺からの全像を保持する。孤立頂点にはそこに入射する全閉パッチを保持する。

`continuous`は保持した境界像全体の位置一致である。曲面内部の全seam、C1/G1、単射性、面の埋め込みや材料を認定しない。また、全閉パッチを保持するため、トリム領域の内側に必要な側だけを選択済みという意味でもない。相違する像を平均しない。

## 巡回と照会

元の各UV巡回を、空間像のedge/piece/directionへ展開する。directionは選択したUV軸の増加方向に対する巡回方向。外周・穴のface対応は元のUV分類から参照する。位置の不連続が残る巡回を、閉じた空間面として認定しない。

`evaluateNurbsSourceLiftPiece3(report, edge, piece, use, parameter)`は明示された片側パッチ、閉区間の範囲、所有を検査し、UV・パッチID・正確な3D点を返す。一般のNURBS曲線へ近似変換しない。元の有理NURBS境界または選択された陰関数枝とパッチの対応を使用する。

テストは鞍形の独立式z=uv、連続crease、不連続ノット、重み付き曲面の独立した商式、曲面有効範囲外、端点の像が一致しても区間内が異なるseamを扱う。

target側の対応、曲面内部の正則性・全seam・埋め込み、実際の面側の選択、保存表現、材料分類と共通Bodyへの採用は残る。
