# 多角形・完全円ループの押し出しを材料定義へ変換

`prepareExtrudeMaterialProgram3(body)` は、実際に所有された押し出しBodyに保持された正規化済みプロファイルを使います。公開された構築レシピの寸法やラベルから形状を推測しません。対応するループは有理頂点の多角形、または一つの円のディスクを正確に囲む円弧列です。

多角形ループは有理な平面押し出しの定義へ、完全円ループは有限円柱の定義へ変換します。正規化された材料境界の全ループをパリティで合成するため、多角形の板の円形貫通穴や、その内側の材料島、分離した成分を同じ表現へ渡せます。各ループの向きから未正規化のnonzero入力を再解釈することはありません。元の正規化済み境界が根拠です。

円ループは同一支持だけで受理せず、完全な円ディスクとの差の2D XORが空であることを検査します。多角形ループは全頂点が有理であることを要求します。直線・部分円弧や複数の円支持が同じループ内で接続する場合は、[支持条件の領域照合](supported-profile-program3.md)へ渡し、候補と元の充填領域が一致する場合だけ受理します。円弧の三角形近似で受理範囲を広げません。

共通の `booleanMaterialBodies3` はこの定義を直接使います。高さは実際の押し出しのzMin/zMaxを保持し、負の高さと非ゼロの基準高さも扱います。旧円形押し出しの境界入口は同じ円ループ検査を使い、従来の対応範囲と境界列挙・レシピを維持します。
