# source開UV面の内部正則性

`analyzeNurbsSourceFaceInteriorRegularity3(selection)`は所有された面側パッチ選択から、各inside UV面の**開いた内部**に階数低下があるかを調べる。境界辺・頂点での階数や、面の閉包全体の正則性をこの結果で認定しない。

全閉片側パッチのdu×dvの正確な3分子と、既存の退化集合の解析を再利用する。パッチ全体が正則なら、その面との共通部分も正則である。有限解、または共有多項式の実零点が孤立点だけの場合は、全点を実際のUV面へ照会する。曲線・領域の退化は、完全な多項式分割配置で非空性を検査する。

## 分割の完全性の条件

配置には3法線分子、全トリム境界の支持式・span端点・両軸の射影イベント、全選択交差グラフの支持式、全共通UV頂点の両座標の定義多項式を含める。代数的座標の共役による過剰分割は許容する。有限枝の始終と枝切替を含むため、各stratum上で実際の面への所属は一定となる。

全slab・イベントfiberの根と開区間を代表する既存の分割処理を使い、3法線分子が同時にゼロかつ対象の開UV面に属する点を探す。所属は支持式だけで推定せず、厳密な面照会により確認する。穴の中の閉じた退化成分も、境界との交差がなくても除外できる。

各face/patchはregular・singular・unresolvedを持つ。singularには正確なUV・3D位置の証拠点を返す。有限面照会が未解決なら、証拠点が見つからないことを正則性へ読み替えない。面と交わらないパッチのregularは、面内部に退化点がないという空虚な成立も含み、パッチの使用証明ではない。

## 検証と保証の範囲

内部の退化線、トリム外または境界だけの退化、退化線で分けた二つの正則な開面、有限系と共有多項式の孤立退化、rank-one領域、無理数の退化線、穴に完全に入る閉退化成分、所有と未解決伝播を検査する。

位置連続性とは独立した検査である。境界・頂点の片側階数、C1/G1、単射性・自己交差、面の埋め込み、target側、保存表現、材料と共通Bodyへの採用は残る。内部が正則でも閉じた空間面または立体の成立を主張しない。
