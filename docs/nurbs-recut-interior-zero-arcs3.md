# 再切断の面内部ゼロ曲線を全区間で分類

`analyzeNurbsRecutInteriorZeroArcs3` は、新キャップと残存NURBS面の接触検査で保留していたゼロ曲線のうち、一つの残存面の内部にある開区間を分類します。所有された再切断B-repと、その構築に使用した旧境界の埋め込み認定が前提です。一般の曲面交差を標本だけで推測するAPIではありません。

## 区間全体を分類できる条件

1. 完全な平面ゼロ集合の辺で、両側のセルが同符号である。
2. 二つのincidentセルが同じ残存有限面の領域に属する。符号の一致だけでは、非連結な兄弟領域を同一視しない。
3. その元辺に属する断片が、残存面の境界に一つも残っていない。
4. 旧境界の所有された埋め込みと、完全な同一面の配置により、開区間内部は他の旧境界面にも同一面の別の切断境界にも接触しない。
5. 新キャップの境界は、その旧境界を切断した辺の集合である。したがって開区間は新キャップの境界と交わらず、連続で連結な曲線のキャップ内外は途中で変化しない。

この条件を確認してから厳密な内点照会を行い、`openLocation` に開区間全体のinside/outsideを保持します。内点がboundaryなら条件との不整合として未解決にします。閉端点は各々別に照会し、`lowerLocation` と `upperLocation` に保持します。端点が開区間と反対の開領域にある場合も未解決です。端点が境界上にある場合は許容し、閉区間全体を内部と誤認しません。

各証明書は元の入力・辺・有限面・ネイティブ区間・新キャップ別の分類と構築由来を保持します。`nurbsRecutInteriorZeroArcPoint3` は所有された証明書と区間内の任意の有理数・代数的パラメータを受け付け、厳密な空間点と対応する全区間／端点分類を返します。

## 残る範囲

元の孤立点監査と接触証拠は `inspection` に保持します。条件を満たさない全ゼロ辺は `pendingEdges` に残し、面境界上の辺や、開区間に残存セルのない辺を暗黙に検査済みとはしません。結果は常に `certifiesAbsence: false` です。宣言済み共有境界の全区間対応、旧平面キャップと新キャップの接触、全接触不在、埋め込みと材料の再認定はまだ対象外です。

## 固定回帰

- 放物線の谷形屋根：開区間はキャップ内部、両端はキャップ境界。
- 山形屋根と離れた切断箱：屋根のゼロ曲線は別成分のキャップ全体から外部。
- 孤立した接触点：曲線へ創作せず、元の接触監査に保持。
- 非線形なnative写像と負の平面スケール：空間像と区間分類を保存。
- 四次屋根の閉じた接触円：全投影イベント区間を分類し、内部の端点を境界と誤認しない。

複数の有理数と無理数パラメータで、証明書の分類を独立した既存のキャップ位置照会にも照合します。これらは回帰テストであり、TypeScript全体の形式検証ではありません。
