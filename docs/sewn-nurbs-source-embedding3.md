# 縫合NURBS面複体の十分条件による大域的埋め込み認定

`certifySewnNurbsSourceEmbedding3` は、所有された縫合結果に対し、個々の面の認定だけでは防げなかった面内部同士の不正な一致を排除する正の証明を試みます。閉じた向き付き局所多様体の接続を先に要求し、全ての異なる面の組について分離証明を検査します。

## 面の組の証明

面A,Bに対して有理平面L(x)=n·x−cと符号sを探し、面全体でsL(A)≥0かつsL(B)≤0を検査します。さらにAまたはBのゼロ断面が、両面に宣言された共有辺・共有頂点の像だけで覆われることを検査します。

共通点ならL=0なので、ゼロ断面被覆により、二面の一致は共有された接続の上に限られます。逆に共有辺の全区間の一致と端点所属は、所有された縫合経路ですでに検査されています。したがって、面の像の交わりが宣言された共有接続の像に一致します。境界箱の重なりや一つのサンプル点の符号だけではこの証明になりません。

平面候補は面の厳密な内部サンプルで得た有理法線・位置と有限個の有理方向から発見します。候補探索は完全ではありません。認定失敗は `not-certified` であり、実際の自己交差が存在するという判定ではありません。一般SSIを使う完全な代替検証器は未実装です。

## 面全体の半空間とゼロ断面

パッチS=P/WでL(S)の符号はG=n·P−cWの符号と同じです。正のNURBS重みから閉パッチでW>0であり、数値許容差は使いません。認定長方形との正の面積の交わりを持つパッチを対象にします。

まずパッチ長方形全体で厳密な反例点を探します。長方形で証明できない場合は、既存の有限面分割支持・端点・臨界座標とGによる完全な符号配置を使い、実際の面所属と近づけるパッチ側を検査します。これにより、トリム外の反例だけを根拠に実際の面の半空間条件を否定しません。

ゼロ断面では、元のsource複体辺の全子辺が相手の面にも使われる場合だけ、その元辺の有限UV区間全体を被覆として採用します。一部の子辺だけが共有される元辺を、丸ごと共有済みとは扱いません。相手側のゼロ断面で証明できる場合も試します。

共有頂点は空間点の厳密逆照会でUVへ戻します。そのUVの両座標の根多項式を分割に追加します。これが必要なのは、追加された共有頂点とたまたま一致するサンプル一点を使い、その周囲の未共有なゼロ曲線まで被覆されたと誤認しないためです。配置の各層で有限面・共有辺・共有点への所属が一定になるように分割した上で、未被覆のゼロ点が存在しないことを検査します。未解決の面照会は認定へ読み替えません。

## 大域的な結論

各閉面は既存の正の埋め込み証明を持ちます。有限個のコンパクトな面の非交和から、宣言された共有辺と頂点を同一視した商空間Xを考えます。縫合の全区間一致により自然な写像X→R³は連続です。面内部の単射性と上記の全組検査により、同じ空間点を持つ点はすでにXで同一視されており、この写像は単射です。コンパクト空間からHausdorff空間への連続単射なので、像への同相写像、すなわちこの面複体の埋め込みが従います。

接続の全頂点リンクも検査するため、別の殻が一点で触れて複数のリンクを作る入力は受理しません。C1/G1の滑らかさ、向きが外向きであること、殻の包含深さ、空洞／材料の役割、体積、共通Bodyへの採用までは認定しません。入れ子の離れた殻の幾何学的埋め込みは認定できても、どちらを材料境界にするかは別です。

## 回帰

非線形立方体、重み付き円柱、斜めせん断した非線形立方体、曲がった上面、入れ子の殻を検査します。負例として、接続だけは閉じた食い込み立方体、開いた面、頂点接触、未解決縫合、所有コピーを扱います。上面を二面へ分けた閉立方体では、共有頂点の追加と一部だけ共有された元辺を含めても、広すぎるゼロ断面を誤認定しないことを検査します。三角形8面の八面体では、面同士が頂点だけで会う有効な接続と、支持長方形では成り立たず三角形トリムで成り立つ半空間条件も検査します。これは新規TypeScript全体の形式証明ではありません。
