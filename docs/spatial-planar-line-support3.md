# 空間の平面分割で支持直線を保持する

傾いた有理の面座標系では、面上の縦辺も世界座標の複数成分が同時に変化します。座標軸に平行な線分だけの高速化では、代数的端点の不要な体の合成が残りました。

平面分割の構築時に、その辺の実際の有理方向と、必要なら代数的な位置を持つ支持直線を保持します。登録前に、方向と独立な二つの有理法線を作り、両端点が指定した支持直線上にあることを厳密に検査します。投影の一致から二つの構築直線を同定する場合も同じ二つの法線を使います。点の公開プロパティやコピーした付加情報は採用しません。記録は凍結した点の組をキーとする内部のWeakMapに保持します。

線分／楕円の交差では、確認済みの有理方向を使って二次係数を有理数に保ち、端点間のパラメータを作るための大きな体の合成を避けます。有限範囲と始点から終点への順序を保持し、支持が確認できなければ一般処理を使います。

線分同士では、有限座標区間が離れていれば先に除外します。確認済みの非平行な支持直線は交点を高々一つしか持たないため、元の端点が他方に属する場合はその点を保持します。平行・同一直線上の重複も有限区間で処理します。新しい交点が必要な場合の一般計算を削除していません。

検査対象には、軸 `(1,2,2)` の非単位円柱、三つの世界座標が変わる面基底、端面の斜め半空間切断、元セルへの対応と独立した材料不等式を含みます。誤った支持方向の拒否、コピーした情報の拒否、代数的位置と空間方向を持つ線分／楕円、重複線分の有限範囲も検査しました。新規4件を含む関連54件が6768 msで成功し、型検査と既存133宣言の限定監査も成功しました。新しい機械検証やTypeScript全体の形式証明ではありません。
