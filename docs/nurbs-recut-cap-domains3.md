# 旧埋込みの引継ぎと再切断キャップの有限領域

`certifyNurbsRecutAssemblyEmbedding3` は、所有された旧キャップ付き境界の埋込み証明と、新しい分割線を含む一括接続結果を対応付けます。全旧有限面の完全な再分割・元共有辺noding・全区間照合と、旧キャップの両側の完全な分割により、旧境界の幾何学的像と共有境界を維持します。前回の元面集合が同一で、旧キャップの包含証明が同一、全キャップ面番号がちょうど一度含まれることを検査します。閉じた接続構造だけから埋込みを推測しません。

引継ぎ対象は旧境界全体の有限な分割です。まだ存在しない新しい切断面のキャップの埋込み証明ではありません。旧埋込みの所有権や、実際のキャップ領域との同一性が確認できなければ証明を発行しません。同じ幾何に見えても、別のキャップ証明を構造比較して代用しません。

`analyzeNurbsRecutCapDomains3` は同じ一括接続結果を指す埋込み証明と、側別の新キャップ境界からループの包含を求めます。完全な平面分割と共有nodingを持つ埋め込まれた旧境界の部分グラフであり、半面の有効な境界では各頂点が入出次数1なので、互いに交差しないJordanループとなります。この幾何学的条件の下でのみ、各ループ境界上の一点と他ループの厳密な巻き数から包含を判定します。

包含の非循環性・推移性・親の深さを検査し、偶数深さを外周、その直属の子を穴へ分類します。穴の中の材料の島は別の有限領域になります。`locateNurbsRecutCapFace3` は外周内かつ穴の外をinside、曲線上をboundaryとして問い合わせます。探索予算、予期しない接触、包含矛盾は未解決であり、幾何学的条件のない曲線配列を認定しません。空の旧形状・新断面では空の領域を保持します。

これはキャップの有限領域と、そのための旧埋込みとの対応です。新しい面のB-rep採用と再閉鎖、キャップ内部と残存元面の接触検査、新しい閉立体のシェル包含・実材料方向の再認定、保存復元を含む再切断Body APIは残ります。材料認定や実行コード全体の形式証明の完成を主張しません。
