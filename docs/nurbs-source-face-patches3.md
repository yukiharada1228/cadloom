# source面の内側パッチ選択と内部seam

`selectNurbsSourceFacePatches3(lift)`は所有されたsource境界持上げ結果から、トリム領域のinsideに分類されたUV面について、境界の各使用方向に対応するパッチを選択する。元の持上げが未解決ならパッチを割り当てない。

## 面の内側の片側

各巡回は左側に対応面を持つ。固定uの辺ならv増加方向の左はu減少側、v減少方向の左はu増加側。固定vの辺ではu増加方向の左がv増加側となる。これを閉パッチの範囲と厳密に比較し、ちょうど一つの局所パッチを選ぶ。一定のUV値は無理数でもよく、有理ノット値と同一視しない。両座標が変化する開区間は前段で全ノットにより分割済みで、一つのパッチに属する。

選択パッチで各pieceの始終点を評価し、隣接pieceとの3D閉接続を全て検査する。`boundaryClosed`はこれらの巡回の位置閉接続を表す。トリム領域の外側にしか必要ない別の片側像が異なっていても、実際に選択した面側と混同しない。

## 面内部を通るノット継ぎ目

境界が閉じているだけでは面全体の位置連続性は保証しない。全ての隣接パッチのseamを列挙し、その線と全共通UV辺・頂点との交点で有限区間へ分ける。各開区間の所属は厳密なUV面照会で判定する。穴の中やトリム外の区間をinside面の内部へ数えない。

seam上の両側が同じ面なら`interiorFaces`に記録する。別の面を隔てる場合は各面の境界であり、一方の面の位置連続性のために他方のパッチの像の一致を強制しない。wire上で同じ面が両側にある場合は面内部として扱う。全区間の位置一致は既存の同次多項式恒等式で検査する。

`interiorContinuous`はその面内部を通る全seamの位置一致、`positionContinuous`はこれとboundaryClosedの両方を表す。これは正則性、C1/G1、単射性、自己交差の不存在、材料や一般BRepの認定ではない。

検証は、未使用側の像だけが異なるトリム境界、閉外周の内側に隠れた不連続、u/v両方向のcreaseの面側、無理数の一定座標、穴に制限した全seamと未解決結果の伝播を扱う。

次は面内部の正則性・特異点集合の制限、埋め込み、保存表現と共通Bodyへの採用が必要。target側の一般対応と材料分類も残る。
