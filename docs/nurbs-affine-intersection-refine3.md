# 微分イベントによる交差グラフの細分

`refineNurbsAffineIntersectionComplex3(complex)`は、所有された両トリム交差のseam complexを新しいグラフへ細分する。元complexは変更しない。微分イベントを解析するだけの前段と異なり、同期した全イベントを頂点、隣接する全区間を辺として保持する。

元の頂点を同じIDで先に保持するため、孤立接触、seamContactsの元頂点への参照、元の由来を失わない。新しい内部イベントはsource UV・target UV・3D座標の全ての厳密な一致で共有する。同じ3D像を持つ別のsourceパラメータは統合しない。各イベントの全incident useについて、同じ交差点を指すことも確認する。

`sourceEdges`は元辺から子辺への順序付き対応である。最初と最後の範囲は元辺の閉範囲に一致し、隣接する子辺は同じ端点を共有する。各子辺は元辺ID、正のパラメータ範囲、patch/edge/useの由来、全開区間の微分分類を保持する。頂点には各useの点での微分状態を保持し、特異な端点の状態を開区間へ延長しない。

グラフ成分は元成分の辺を子辺へ展開し、追加頂点を含める。孤立頂点の成分を保持する。暗黙の重なりregionは別集合のまま参照し、境界を推測して追加しない。このグラフは元パラメータのseam同一視を保持した曲線グラフであり、全空間像の埋め込みや材料認定ではない。

`refinedNurbsAffineIntersectionEdgePoint3`と`refinedNurbsAffineIntersectionEdgeDifferential3`は新しいグラフの所有・子辺範囲・明示されたuseを検査する。元辺の範囲に収まっていても、指定した子辺から外れたパラメータは拒否する。片側法線・局所orientationを平均しない。

新規テストでは、既存の境界イベントでは切れていない垂直枝の内部階数低下、等しい空間像の別逆像、子辺の完全被覆・連結・成分分割、creaseの全use、範囲と所有、孤立接触、重なりregionを検査する。

次はこのグラフと元面の境界を同じUV配置に置き、向き付き面片の閉ループを抽出する必要がある。特異枝の接線分離、重なりregionの全境界、一般target曲面、面の埋め込みと材料分類、共通Bodyへの採用は未完了。
