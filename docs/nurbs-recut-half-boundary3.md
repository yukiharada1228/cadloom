# 再切断の側別面抽出と新しいキャップ境界

`selectNurbsRecutHalfBoundary3` は所有された一括接続結果から、新しい切断平面の負側または正側の有限面を抽出します。元NURBS面はそのセル配置のplaneとsign、旧キャップは分割平面とsideを参照し、共通平面に対する法線の向きで符号をそろえます。係数の負スケールでも同じ側を抽出します。平面に含まれる二次元の面はcoplanar-faceとして未解決であり、両側へ重複採用しません。

抽出した面は元の所有された有限面と曲線オブジェクトを保持し、共通B-repへ採用し直します。入力辺・頂点・面から出力への対応を持ち、除外要素はnullです。方向、頂点リンク、境界ループを検査し、新しい境界辺ごとに、切断前の正側面と負側面の二つの親を保持します。これらの閉領域が辺全体を含むため、全曲線が平面上にあることを導けます。端点や有限サンプルから全曲線の平面所属を推測しません。

`nurbsRecutHalfCapBoundary3` は開境界を反転してキャップ向きのループを作り、新しい切断平面に法線をそろえた直交有理チャートとsense:-sideを保持します。`nurbsRecutHalfCapBoundaryPoint3` は元の曲線のネイティブ区間で評価してチャートへ厳密に逆写像します。NURBS由来の曲線、旧キャップ上の直線、代数的な端点が混在しても折れ線近似へ変換しません。

空の側や、次平面が旧形状を外れて元の閉境界が丸ごと残る側では、人工的な新ループを作りません。複数の材料成分のループは別々に保持します。任意の配列・構造をコピーしたレポートには所有権を発行しません。

これは側別の開いた面集合と、まだ外周・穴へ分類していないキャップ境界です。新ループの厳密な巻き数と包含分類、有限キャップ面、再閉鎖、幾何学的埋込み・シェル包含・材料方向の再認定、保存復元を含む再切断Body APIは残ります。
