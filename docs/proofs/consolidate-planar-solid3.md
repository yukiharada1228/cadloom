# 平面材料の同一平面上の面の統合

## 所有と支持面

入力はpreparePlanarSolid3で検証済みの有理凸多角形材料です。支持平面を法線の最初の非零成分で正規化し、物理法線方向が一致する面だけを一群にします。異なる平行面や反対向きの面を許容誤差でまとめません。群ごとの有理平面チャートは単射で、全ての投影と復元は有理数です。

## 外周と穴

各群の面の領域を既存の厳密な平面多角形和で統合します。内部の共有線が消え、外周・穴の向きが正規化されます。前進する同一直線上の余分な頂点を除き、残る境界だけで配置を再構築します。選択された各配置面が、連結した一つの有界面領域を与えます。点で接するだけの成分は別に扱います。

検証済み入力には面内部の重なりがなく、各入力凸面の内部は和の一つの連結成分に含まれます。入力面の厳密な内部平均点でその成分を選び、全入力面が一度ずつ出力へ割り当たることを確認します。外周または穴の境界が一点でつながる成分は、単一の多様体面にできません。同じ境界頂点が複数回現れることを検出して、その成分の元の有効な面を残し、retainedFacesへ報告します。形状を変えて修復する処理ではありません。

それ以外の成分はpreparePlanarFace3で有界領域・境界・向きを再検証し、全体を共有辺へ再接続します。閉じた向き付き多様体接続を要求します。各出力面の元の全入力面が同じ元シェルに属すことと、元と新しいシェルが一対一に対応することを検査します。統合は支持面上の同じ領域の和であり、境界点集合と物理向きを保ちます。

## 共通Bodyと復元

consolidatePlanarBody3は現在の入力Bodyの面IDに対する由来を返します。非凸面と穴を内部で分解する場合も、その各片から現在の入力面への対応を保持します。過去の内部キャッシュの面IDを公開の由来に流用しません。境界が一点でつながる成分を元の分割へ残す場合、同じ入力面の一部が複数出力の由来に現れることもあります。

元の材料の包含・空洞・内部点を維持し、新しいシェルIDへ領域の参照を写します。保存するplanar-consolidated構築レコードは検証済み凸多角形群です。復元時は材料を再検証して同じ統合を実行し、有界面領域と全レコードを既存の照合で確認します。由来一覧はこの操作の入力に対するもので、永続的な履歴ではありません。

## 検証と限界

三方向で分割した箱が24面から6面・12辺・8頂点へ戻り、独立な箱の不等式と一致することを検査します。空洞付きBodyの60面から12面への統合、保存復元、再充填、再統合の境界レコードの冪等性を含みます。穴付きの柱は穴を持つ二つの面と八つの壁へ統合されます。別成分や極小の隙間を保持し、シェル参照を再割当てした場合も材料点を保つことを確認します。

境界が一点でつながる平らな屋根と、その部分を覆う角錐状の突起を持つ有効な立体を用い、単一の平面領域にできない面の保持と、全体の埋め込み・独立に求めた体積33/2も検証します。出力境界を再度厳密に分解してpreparePlanarSolid3へ渡し、埋め込み・包含・体積の再検証も行います。

これは構成の説明と実行テストであり、新しいLean証明やTypeScript全体の実行証明ではありません。一般曲面、接触材料のBody領域、最適な面分割の選択、由来履歴の永続化、大規模形状の加速は今後の開発です。
