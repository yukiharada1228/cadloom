# 平面B-rep境界の分割と接続

## 契約

入力は有理座標の凸な平面多角形群と、有理係数の切断平面群です。各多角形は独立に平面性・凸性・正面積・境界順序を検査します。入力頂点順が物理法線を定めます。穴や非凸面は対象外です。これは多角形群の接続操作であり、立体の認定ではありません。

## 分割から接続への対応

既存の厳密な半空間分割により、各片の面積と向きと内部符号を維持します。各片の辺の両端が元の境界線分内なら、その元の辺を記録します。それ以外の辺は少なくとも一つの切断平面に含まれなければならず、違反は内部不整合として拒否します。辺全体を含む入力平面は元の支持平面と一致するものも含めて全て記録します。

各片の法線は、第一頂点を基準にした外積和で構築します。このため大きな平行移動による値の膨張を避け、先頭の三頂点が同一直線上でも対応します。境界を既存の厳密なsewBRepFaces3へ渡し、全ての供給端点で線分を分割し、一致する線分を共通辺へまとめます。sewn.sourceUsesを介して、細分された共有辺の各使用へ面・境界辺・切断平面の対応を移します。

requireClosedは既存の向き付き接続と頂点リンクの検査です。面の大域的自己交差、シェルの包含、空洞、材料領域の成立は保証しません。面間交線が入力切断平面で与えられていなければ、この処理で発見するとは限りません。内部の分割辺は別の面片同士で共有しますが、立体を切断した蓋を生成する操作ではありません。

## 検証

二方向に分割した箱は16面・32辺・18頂点を持ち、Euler特性2、体積8、全辺の逆向き2使用を保ちます。再分割後も同じ体積と閉じた接続を保ちます。非一致の元の辺分割によるT接続、斜めの切断、極小有理数、反転、重複切断、共面を検査します。各出力辺の全使用について元の境界と平面への所属を照合し、全ての元の境界辺が向き付き長さで正確に一度被覆されることを検査します。有理アフィン変換した斜めの四面体についても、独立した行列式から得る体積と一致します。開いた入力と多使用辺は診断され、requireClosedで拒否されます。

これは実行テストと構成の説明であり、新しいLean証明やTypeScript全体の形式検証ではありません。
