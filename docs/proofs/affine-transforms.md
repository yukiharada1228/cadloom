# 厳密アフィン変換

対象は有理数係数の`affine2`、点・線分・環の変換、合成、逆変換の数学的モデル。TypeScript実行全体の形式検証ではない。

## 定義と合成

変換は`x'=a*x+b*y+tx, y'=c*x+d*y+ty`である。有理数の加減乗除に閉じているため、出力も有理数になる。`composeAffine2(outer,inner)`はouterの式へinnerの式を代入した係数と定数項を返し、outer(inner(p))と一致する。

## 幾何学の保存

`AffineGeometry.lean`では次を検査する。

- 変換後の二方向の外積は、元の外積に行列式ad−bcを掛けたもの。
- 線分上のパラメーターtの点は、変換後も同じパラメーターtの点。
- 行列式が非零なら、明示した逆行列と逆平行移動で元の点へ戻る。
- 行列式が非零なら、変換前後の線分所属は必要十分に一致する。

従って非特異変換では交点・接触・重複が保存される。向きは行列式正なら保存、負なら反転する。逆写像を持つ連続なアフィン写像は領域の内部・境界・外部を対応させるため、正則化集合演算や点の所属判定も整合する。この位相的結論全体はLean検証の対象とはしていない。

閉じた環の靴紐和では平行移動に由来する項が隣接頂点間で相殺され、符号付き面積は行列式倍になる。材料の面積はその絶対値倍になる。これにより集合演算後の面積を変換の前後で照合できる。

## 特異変換と制約

行列式0の変換も点・線分・環への適用は許すが、面は線・点に潰れ得る。逆変換はRangeErrorで拒否する。特異写像について、差・共通部分・点の内外が可換とは保証しない。変換後の環を集合演算へ渡す場合は既存の正則化規則が適用される。

係数は有理数に限る。例えば90度回転やcos=3/5,sin=4/5の回転は正確に表せるが、一般の角度の正弦・余弦は有理数ではないため、このAPIは任意角度の厳密回転を提供しない。

テストは合成順序、特異変換の拒否、200組の種付き有理数行列での逆変換、交点・面積・点の所属の整合性、巨大座標と微小係数を確認する。モデルとTypeScriptの係数式との対応はレビュー対象であり、証明済みコンパイラによる生成ではない。
