# 点のポリゴン所属判定

対象は`preparePolygon`と`locatePointInPolygon`の数学的アルゴリズム。既存の線分所属判定と[集合演算](polygon-booleans.md)の正当性を前提とする手書きの説明であり、TypeScript実行コード全体の機械検証ではない。

## 対象となる集合

入力環を指定の塗り規則で正則化した領域に対して、inside・boundary・outsideを返す。元の入力線上にあることだけではboundaryとはしない。例えば偶奇規則で同じ環を2回入力すれば領域は空であり、その輪郭上の点もoutsideである。非零規則で同方向に入れ子にした環の内側の輪郭も、領域内部にあるためinsideである。

最初に`booleanPolygons(region, [], "union", fillRule)`で領域境界のみの環に正規化する。これは領域と空集合の和なので正則化領域を保存する。ゼロ面積の線分や打ち消された輪郭、両側が内部となる共有辺は境界環に含まれない。

## 境界上の点

正規化された各辺について、外積0かつ端点の辞書順閉区間内にあることを厳密に検査する。この条件と線分への所属の同値性は既存のLean線分所属モデルで証明済みである（実行コードとの全体的な精緻化とは区別する）。いずれかの辺に属せば境界上である。接触頂点は辺の端点に含まれるため同じ判定で扱う。

## 境界以外の点

右向きの水平半直線を使う。上向き辺では`start.y ≤ p.y < end.y`、下向き辺では`end.y ≤ p.y < start.y`を用い、水平辺は計数しない。半開区間により頂点を横断する交差は一度だけ計数され、極値での接触は加減が相殺する。

非水平辺a→bの水平線との交点をqとすると、

`cross(b-a, p-a) = (b.y-a.y)*(q.x-p.x)`

が成り立つ。従って上向き辺では外積正、下向き辺では外積負であることが、交点がpの右にあることと同値である。上向き交差を+1、下向きを−1として足すことで巻き数を得る。境界点は先に除外しているので交点一致の曖昧さはない。

正規化後の環は材料が左になる向きであり、穴は逆向きである。従って巻き数が非零なら内部、0なら外部となる。元の塗り規則が偶奇・非零のいずれでも、正規化済みの境界では同じ判定を使える。

## 繰り返し問い合わせ

入力は集合演算時にスナップショットされ、正規化された環と点は凍結される。準備後の呼び出し元の変更は所属判定に影響しない。準備は既存の平面分割・集合演算のコストを要するが、各問い合わせは正規化後の辺数に対して線形であり、毎回分割を繰り返さない。

テストでは正方形格子の独立した閉区間判定、穴、内部共有辺、重複環、自己交差、接触頂点、退化領域、巨大平行移動と微小有理数の境界両側を検査する。
