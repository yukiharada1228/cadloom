# 円柱・平面半空間の共通Body切断

## 構築来歴と永続化

有限の円柱と有理平面半空間の共通部分は、既存のclipCylinderBRep3による凸な材料の構築を使います。所有モデルの内部にこのfactory由来の幾何オブジェクトを保持し、切断の対象を判定します。公開のconstructionラベルや構造のコピーを見て来歴を認定しません。復元時も構築から来歴を再確立します。

clipped-cylinderレコードは軸・半径二乗・軸パラメータ上下限と、保持した全ての正規化半空間を記録します。実際に面を作らない冗長な制約や、空集合の原因になった制約も含みます。空だったというフラグだけではなく、再構築から正則化された空集合を再計算します。有限円柱の外で拒否する条件、対向する半空間、純粋な多面体へ切り込んだ後の角への接触も検査します。復元後に共通の面領域・境界照合と全レコードの照合を行います。

## 分割と共有面

既存のsplitClippedCylinderByPlane3で境界の頂点と楕円弧の停留点から平面の両側の存在・接触を分類します。真の分割では曲面のトリムと新しい平面の蓋を構築・接続し、子同士で反対向きの共有面と辺の細分対応を認定します。一方に体積がない場合は、その側を空とし、もう一方は元の所有された材料です。

子を共通Bodyへ変換する際は既存の面順序・辺ID・コエッジ順序を保ってレコードを復元します。共有面のIDと辺対応は、この復元された子に対して有効です。テストでは面数だけでなく、各共有コエッジの辺ID・向き・面IDと、共有辺の細分をたどった始点から終点までの一致を確認します。子の各外部面から親面への由来も、共通Bodyの有界面判定で照合します。

子を単独で保存・復元して再分割できます。共有面や由来一覧は直前の分割に対する実行時の証明書であり、永続的な編集履歴ではありません。

## 逆操作

rejoinCylinderBodySplit3は所有された分割オブジェクトだけを受け付け、既存の逆分割処理で内部の蓋を対で除いて外側の境界を再接続します。材料は元の親Bodyで、独立に再接続した境界と由来を別に返します。無関係な子の和や、保存から復元した任意の対応表を信頼する処理ではありません。

## 検証と限界

独立な半円柱の不等式を有理格子で照合します。共有面と辺のID、斜めの楕円断面、任意の有理非単位軸と無理数半径、平面の負の倍率による左右交換、子の保存復元と再切断・再結合を含みます。接触・非交差・空集合、円柱壁が消えた多面体の角への接触、浮動小数点では識別できない薄い子、代数的端点上の境界判定、改ざんされた構築レコード・面向きと所有権の拒否も検査します。

これは既存の正確な解析幾何演算と共通Bodyの接続に関する説明・実行テストです。新しいLean証明や全TypeScript実行の形式検証ではありません。任意のB-repの平面分割、円柱同士の交差、一般曲面ブーリアン、非凸な曲面材料、分割証明書と由来履歴の永続化は未実装です。
