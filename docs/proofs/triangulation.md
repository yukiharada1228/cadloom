# 有理数スラブ三角形分割の正当性

対象は`triangulatePolygon`の数学的アルゴリズム。領域の正規化・境界の正しさを既存の集合演算に仮定する手書きの説明であり、新アルゴリズム全体の機械検証ではない。

## 帯への分割

正規化された全境界頂点のx座標を重複除去して整列し、隣接座標の間を開いた縦帯とする。帯内部には境界頂点が存在しない。垂直辺は帯境界上にしかなく、帯を横切る他の辺は一次関数y(x)である。正規化された辺は内部で交差しないので、これらの上下順は帯内で変わらない。

帯の中点xで交点を下から整列すると、外部から始まり境界を横断するたびに内部・外部が交互に切り替わる。従って連続する2本ずつを組にすることで、帯内部の全材料領域を重複なく得る。正規化前の塗り規則が非零でも、正規化後は材料境界だけなので同じ組分けが使える。

## 台形と三角形

各組の上下は一次関数で、帯の端での上下差は非負、中点では正である。その閉領域は凸台形または片端が潰れた三角形になる。中心を中点xでの上下yの平均に取ると、xは帯の内部、yは上下の厳密な間にあるため中心は厳密な内部点である。

台形の境界を反時計回りに並べ、内部中心から各非零境界辺へ扇状に結ぶ。凸性により各三角形は台形内に収まり、向きは正、内部は互いに重ならず、台形全体を覆う。潰れた端では同じ点間の辺だけ除く。補助点・交点・中心は全て有理数の四則演算で得られる。

## 適合するメッシュ

全ての帯境界xにおいて、全領域境界辺との交点yと垂直辺の端点yを集める。各台形の左右辺には、その区間内の全ての切断点を挿入する。従って隣接帯は同じ直線区間を同じ点列で分割する。帯端で始まる境界・穴の端・点接触もこの集合に含まれる。

同一帯での台形同士は内部が離れており、隣接帯での三角形の接続は共有壁の同一分割に沿う。台形中心は帯内部なので他帯の辺上にはならない。従ってメッシュ頂点が他の三角形辺の厳密な内部にあるT字接続を生じない。接触頂点で複数の成分が一点を共有する可能性はあり、頂点で多様体になることまでは保証しない。

## 面積と検証

帯内部の材料を台形で重複なく覆い、各台形を三角形で重複なく覆うため、三角形の符号付き面積の和は材料面積に等しい。境界の共有は面積0なので加算へ影響しない。

テストは各三角形の正向き、面積和と正規化領域の面積の一致、重心が内部にあること、全頂点に対するT字接続の不在、辺が1枚または2枚の三角形に接続することを検査する。凸図形の分離軸条件を使い、異なる三角形の内部が重ならないことも独立に確認する。凹形状・穴・入れ子・自己交差・接触・退化と、種を固定した環、せん断・巨大移動・微小有理数スケールを含む。

## 制約

入力頂点だけを使う分割やDelaunay分割ではない。補助頂点を追加し、三角形の枚数・角度の最適化はしない。配列を走査して各壁と辺の交点を求めるため、大規模入力向けの掃引線・空間索引は未実装である。面積0の入力は正規化時に除かれ、空メッシュを返す。
