# 厳密な3D向き判定と線分–平面交差

対象は有理数座標の3D点・ベクトル・平面と閉線分である。数学的モデルの重要な定理をLeanで検査するが、TypeScript実行コード全体の精緻化証明ではない。

## 向きと平面

`orient3d(a,b,c,d)`は`((b−a)×(c−a))·(d−a)`の符号を返す。a=(0,0,0), b=(1,0,0), c=(0,1,0), d=(0,0,1)の順は正である。別の行列式の並べ方では符号が逆になる場合があるため、この順序をAPIの規約とする。同一平面・退化した四点は0になる。

`Plane3`は`normal·p+offset=0`を表す。法線は非零であり、単位化しない。単位化は一般に平方根を要するが、所属・側判定・交点に法線の長さは不要である。評価値は符号判定用の式の値であり、ユークリッド距離ではない。

3点からの平面ではn=(b−a)×(c−a), offset=−n·aとする。`plane_through_endpoints`は3点がこの式を満たすこと、`plane_through_orientation`は第4点の評価値が向きの行列式と一致することを示す。n=0の場合は3点が平面を一意に定めないため、TypeScriptの構築関数はRangeErrorで拒否する。`orient3d`自体は退化した入力にも0を返す。

同じ式を非零定数倍した平面は同じ点集合を表す。正の倍数は側の符号を保存、負の倍数は反転する。交点とパラメーターは変わらない。

## 線分への制限

閉線分をp(t)=a+t(b−a), 0≤t≤1とする。平面の評価をf、端点の値をu=f(a), v=f(b)とすると、`plane_lerp_value`により

`f(p(t))=(1−t)u+tv`

である。`plane_segment_meets_iff`は、線分上に平面所属点が存在することとuv≤0の必要十分性を、全ての有理数端点について証明する。

u≠vなら、零になるパラメーターはt=u/(u−v)に一意に決まる（`plane_zero_parameter_iff`）。`plane_parameter_unit_iff`はこのtが[0,1]に入ることとuv≤0の同値性を証明する。

u=vの場合は線分上の評価が定数である（`plane_constant_on_parallel`）。従って両値0なら線分全体が平面上、同じ非零値なら交差しない。

## 実装の分岐

1. u=v=0で端点が異なる場合、`coplanar`として線分全体を返す。
2. u=0なら始点、v=0なら終点を返す。パラメーターはそれぞれ0、1。
3. 残りで端点の符号が同じなら`none`。
4. 符号が逆なら、上記の一意なtとp(t)を厳密に計算して`point`を返す。

零長線分では、所属するなら`point`（規約としてt=0）、所属しなければ`none`である。零長の場合、同じ幾何学的点に複数のパラメーターが対応するため、tの一意性を主張しない。全体が平面上の非零長線分では、一つの任意の交点へ縮約せず、共通部分全体を返す。

入力のコピー・返却値の凍結は実装とテストで扱う。これらのJavaScript意味論や、Rational実装・コンパイラーとLeanモデルとの対応までを、この証明の結論に含めない。

## 検証

- 立方体頂点の4,096通りの向き判定を、独立した4×4行列式のLeibniz展開と比較する。
- 整数係数平面と立方体頂点の線分4,992組について、端点値の符号、独立した平面所属式、パラメーターによる座標式と照合する。
- 種を固定した300組の有理数点は、各行の分母を正の整数で払った独立した行列式と照合する。
- 平面の非零倍、線分反転、退化、端点接触、平行、同一平面、巨大平行移動・微小距離を確認する。

これは平面の切断・面同士の交差に必要な基礎であり、BRep、ソリッドの内外判定、3D集合演算、曲面の交差を実装済みとするものではない。
