# 半辺と境界巡回の正当性

対象は`buildHalfEdges`の数学的アルゴリズム。実行コード全体の機械検証ではない。

## 前提

`splitSegments`が重複辺・辺内部の頂点・未分割交差のない平面直線グラフを生成すること。異なる辺が同じ頂点から同方向に出れば、近い端点が遠い辺の内部に入るため、この前提に反する。したがって各頂点の出辺の方向は異なる。孤立頂点は許す。

## 方向順序

非零ベクトルを上半平面（正のx軸を含む）と下半平面（負のx軸を含む）に分ける。同じ半平面の二方向は角度差が厳密にπ未満なので、外積の符号が反時計回り順序と一致する。外積0は同じ向きである。半平面番号を先に比較すれば、正のx軸から始まる全周の順序を得る。実装の算術は有理数であり、角度・三角関数・丸めを必要としない。

## 巡回の完全性

半辺集合H上で、反転Tは各無向辺の2本を交換する全単射。各頂点の出辺リストで一つ前へ移る写像Rも、互いに素な循環の和であり全単射である。次半辺はN=R∘Tなので全単射である。よって有限集合HはNの互いに素な周期に分解される。

未訪問半辺からNを繰り返すと必ず出発半辺に戻る。途中で他の既訪問周期に入ることは全単射性に反する。したがって実装の巡回は停止し、全半辺を重複なく列挙する。各N(h)の始点はhの終点であり、閉じた歩道になる。previousはNの逆写像である。

反転後の方向から時計回りで最初の出辺へ進むので、平面埋め込み上では左側の同一領域に接する境界をたどる。橋では同じ無向辺の両向きが同じ巡回に現れ得る。孤立頂点には半辺がなく巡回を作らない。

## 面積と限界

各巡回のΣ(x_i*y_{i+1}−y_i*x_{i+1})を厳密に蓄積する。全半辺で合計すると反転した辺の項が打ち消し合うため0になる。単純な反時計回り閉路では面積の2倍になる。一般の巡回は橋や重複頂点を含むため、単純ポリゴンとは限らない。

境界巡回と面は同一ではない。非連結・入れ子の場合、同一面に複数巡回が属する。今回のAPIは境界成分を返し、穴の所属や面の構築は次段階とする。
