# 円柱交線と平面の交差・閉集合切り取り

## 所有と対象

入力はintersectCylinders3が返した非平行軸の有界交線片または、その所有を引き継いだ分割片・部分グラフです。任意の構造コピーは認定しません。平面は非零の有理法線と有理オフセットを持ちます。これは曲線集合の操作であり、正則化された立体の切断ではありません。

## 軸に平行な切断面

第一軸方向dに対して平面の法線NがN·d=0なら、p=q+h dの平面評価は基準円上のqだけに依存します。既存の円・平面交差から高々二つの基準点を求め、片に含まれる点をその高さの枝へ持ち上げます。第一円柱の正の半径と非零法線により、この場合に基準円全体が切断面と一致することはありません。

## 横断平面と四次消去

N·d≠0なら、平面上の高さはh=-(N·q+offset)/(N·d)です。第一円柱の基準円をq=A+U x+V yと表します。U,Vは直交する有理ベクトルで、円の式は

    y² = R(x) = RA²/|V|² - |U|² x²/|V|²

です。平面へ第一軸方向に射影した点も有理アフィン式p=O+u x+v yになります。これを第二円柱の式へ代入し、円の式でy²を消去すると

    L(x) y + M(x) = 0

となります。Lは高々一次、Mは高々二次です。有限解は高々四次の

    M(x)² - L(x)² R(x) = 0

の全実根を調べます。R(x)<0を捨て、L(x)≠0ならy=-M(x)/L(x)で一意に復元します。この復元により二乗消去の余分な符号選択は残りません。L(x)=0かつM(x)=0なら、R(x)の符号に応じてy=0またはy=±sqrt(R(x))を別々に保持します。両方のyが同じxを持つ場合も一方を失いません。

LとMが共に零多項式なら、平面上の楕円が両円柱へ含まれます。正の半径の円は実一次因子を持たず、その他の場合に上記の消去式が恒等的に0となることはありません。共有楕円の場合、既存の交線片の開いた内部には高さの根の合流点がないため、片は平面上に全部含まれるか、反対の高さの枝として臨界端点だけで交わります。内部点の厳密な評価と端点評価でこの二つを区別します。

## 座標の有理式と符号

Lが非零の根では、一つの代数的パラメータxと共通分母L(x)を持つ三つの座標有理式を構築します。分母が選択した根で非零であることを検査します。パラメータの定義多項式が最小多項式でなく、別の共役根で分母が0になる場合も、既存の正確な有理像の処理を使用します。

factoryで構築した不変な点の非公開レジストリに、この有理式を保持します。線形形式は共通分母上の分子多項式へ、円・円柱の二次式は分母二乗上の分子多項式へ展開します。これにより、一つの根の座標を独立な共役根の直積として扱いません。平面符号では分母の符号を掛け、分子が0ならJavaScriptの-0ではなく0を返します。未登録のコピーの追加メタデータは信頼しません。

## 分割と半空間

全交点の基準円への射影で円弧を分割します。新しい端点は検証済み交点の表示をそのまま保持し、入れ子の平方根から再構成しません。各開片に平面の零点が残らないので、厳密な内部点で決めた符号は片の内部で一定です。重なる片は符号0で残ります。

複数半空間は順に適用します。各平面の支持面ペア候補を一度だけ求め、全ての枝へ共有します。保持する片の端点が除外側にないことを確認し、曲線を失っても閉半空間に属する接点は孤立点として保持します。次の制約は孤立点にも適用します。共有端点は再度厳密に統合して接続を作り直します。

グラフの価数によるsingularVerticesとは別に、元の支持面の法線の従属性をsupportSingularVerticesへ記録します。円柱交差の臨界点では第二法線はd×eに平行です。第一法線もそれに平行になるのは、基準円と帯境界の接触、すなわち臨界点構築の残りの半径二乗が0の場合です。この条件は切り取り後の価数に依存せず、二価や孤立点へ変わっても保持します。

## 検証と限界

独立なz=±xの交線とPythagoras列挙、四交点・四次の無理数座標、正負の分母、線形復元係数が0となる二重射影座標、共有楕円と反対の枝、接点だけを残す切り取りを検査します。順序を変えた複数半空間で有限な高さの制約を照合し、一般のずれた軸では両支持面と保持半空間の式を端点・内部点で確認します。極小幅、価数が変わった特異点、非最小の根証明書、分母0と偽のメタデータの拒否も含みます。

これは構成の説明と実行テストであり、新しいLean証明や全TypeScript実行の形式検証ではありません。有界面の任意角度境界、曲線の微分・曲率、パラメータ曲線と共通B-rep辺の結合、永続的なSSIレコード、一般曲面ブーリアンは今後の課題です。
