# ポリゴン集合演算の正当性

対象は`booleanPolygons`の数学的アルゴリズム。[面構築](faces.md)が正しい平面分割を返すこと、有理数演算・所属情報が正しいことを前提とする手書きの証明であり、TypeScript実行全体の機械検証ではない。

## 入力と集合の意味

入力は有限の閉じた折れ線の集まりで、各環は暗黙に最後から最初へ閉じる。自己交差・重複・退化も許す。偶奇規則では巻き数が奇数、非零規則では巻き数が0以外の開領域を内部と定義する。

演算結果は選択された2次元領域の閉包（正則化）である。面積0の線・点だけの共通部分は出力しない。したがって閉集合の通常の共通部分と、接触点・共有辺において異なる。非有界面の選択はどの対応演算でも偽になる。

## 巻き数の伝播

入力辺を交点・重複端点で分割すると、分割辺の開いた内部に交差や頂点はない。正方向（辞書順）半辺の右面から左面へ横断したとき、同方向の入力辺は巻き数を+1、逆方向は−1だけ変える。重複した入力はそれぞれ加算する。入力元集合から得たこの差分は、元の閉曲線の巻き数の跳びと一致する。

全ての閉曲線は有限なので非有界面の巻き数は0。面の双対グラフは連結である。面内の点から十分遠方への経路を頂点・辺に沿わないよう選べば、有限回の横断により非有界面に到達できる。穴を隔てる非連結輪郭も面の双対グラフでは接続する。橋の両側が同一面なら差分の総和は0である。

従って面0から幅優先で差分を加えると、到達した面の値は実際の巻き数に一致するという不変条件が成立する。全ての面に到達し、別経路からの値も一致する。実装では到達不能・値不整合を検出した場合に例外を送出して前提の破綻を検出する。

## 面の選択と境界

各面の内部では各入力の巻き数が一定なので、指定規則の真偽に和・共通・差・排他的論理和の真理値関数を適用するだけで、面ごとの選択が決まる。

ある辺の左右面が両方選択、または両方非選択なら、辺の開いた内部は結果の境界ではない。左右が異なる辺だけを採り、選択面が左になる向きにする。全ての面選択の境界がこれに尽くされる。元の分割線を残したまま面だけ列挙するのでなく、この境界を再巡回することで内部の辺を除く。

頂点近傍の各角領域は選択・非選択のいずれかである。入ってきた境界の反転方向から時計回りで最初の出ていく境界を選ぶと、同じ選択扇形の端同士を接続する。選択状態の変化は円周上で交互に現れるので入辺と出辺は一対一に対応し、後続写像は置換になる。よって有限の境界半辺は重複しない閉じた巡回に分解される。点接触では同じ頂点を複数の巡回が共有してよく、出力環を常に単純とする保証はしない。

外側は反時計回り、穴は時計回りになり、出力環は偶奇規則・非零規則の両方で同じ内部を表す。面積の2倍は選択した有界面の面積の2倍の総和である。内部辺は反対向きで打ち消されるため、出力環の靴紐和とも一致する。

## 検証範囲

既知の交差・穴・共有辺・点接触・自己交差・重複入力を検査する。整数長方形は区間重なりだけを使う独立の面積式と比較する。種を固定した任意環は、交点x座標を直接計算する独立の半直線判定と比較し、結果の内部の一致を検査する。巨大移動・反射・微小有理数スケールでも面積と靴紐和が保たれることを検査する。

既存のLean検証は厳密演算・交差・分割モデル等を対象とし、この文書の双対グラフ・巻き数・境界巡回全体を機械検証したものではない。
