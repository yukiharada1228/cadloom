# 境界成分の面への割り当て

対象は`buildFaces`の数学的アルゴリズム。前提は[半辺の証明](half-edges.md)と同じ平面直線グラフである。以下は手書きの幾何学的説明であり、平面位相全体やTypeScriptの機械検証ではない。

## 左側の標本点

半辺a→bの中点mから左法線n=(-(b.y-a.y),b.x-a.x)へ正の有理数tだけ進む。外積は

`cross(b-a, m+t*n-a) = t*((b.x-a.x)^2+(b.y-a.y)^2) > 0`

なので必ず半辺の左側にある。これは`FaceSampling.lean`で任意の相異なる有理数端点について機械検査する。

中点は他辺や頂点と接触しない。法線半直線と各辺の交点パラメーターt>0を求め、stepをmin(step,t/2)へ縮める。初期値は1。非平行な交点には2×2の外積による解を使い、辺側パラメーターが[0,1]のものだけ採る。同一直線の辺には端点のパラメーターを使う。中点をまたぐ辺は平面グラフの前提に反するためない。

有限個の候補に対しstepは正の有理数のままで、全ての正の交点より小さくなる。この縮小操作の正値性・交点より手前であること・以前の上界の維持をLeanで検査する。実装の条件t≤2*stepはminの選択と同じである。

従って中点から標本点への開いた区間には辺との交差がない。標本点はその境界巡回の左側の面内にある。橋の両側でもこの性質は変わらない。孤立点は平面の領域を分割しない。

## 境界と包含判定

有限の平面直線グラフにおける標準的な境界の性質を用いる。各有界面は正向きの外側境界巡回を一つ持つ。橋の往復は面積・巻き数に寄与しない。各連結成分の外側巡回は負向き、木のみなら面積0である。異なる正向き境界の内部は互いに素か、非連結成分の入れ子になる。

正面積の巡回ごとに有界面を作る。そのほかの巡回は左側標本点の所属先を調べる。半開区間の上向き・下向き交差を外積の符号と組み合わせて巻き数を計算することで、水平辺や頂点で二重計数しない。標本点は境界上にないため、巻き数が非零なら内部にある。

包含する正向き境界が複数あれば、最小面積のものが最も内側である。厳密な入れ子では差領域に開集合があり面積差が正なので同面積の曖昧さはない。候補がなければ非有界面0に属する。孤立頂点も同じ包含判定で割り当てる。正向き境界自身には標本点を用いず、対応する面を直接割り当てる。

## 面積と検証

有界面の面積の2倍は、所属する巡回の符号付き面積の和である。負向きの穴が差し引かれ、木や橋の項は0になる。非有界面には有限面積を設定しない。

テストは既知の交差四角形の各面積、入れ子・橋・離れた木・孤立点の所属、反射・巨大平行移動・微小有理数拡大縮小での不変性を検査する。さらにランダム線分集合に対してV−E+F=1+Cと半辺所属の整合性を検査する。Euler公式だけでは面所属の正しさ全体を証明できないため、既知の所属・面積テストも併用する。
