# 多角形境界を保持する平面立体ブーリアン

## 対象

入力はfactoryで検証したPreparedPlanarSolid3か、本演算が生成した所有済みの材料境界です。任意のオブジェクト・差し替えたlocate関数を信頼しません。有限の有理平面境界に対して、和・積・差・排他的和の正則化された材料を計算します。一般曲面や無理数の面は対象外です。

## 分割の完全性と同一平面上の被覆

入力の全支持平面を法線の最初の非零成分で正規化し、同じ支持面をまとめます。各支持面の入力多角形は、両入力の全支持平面と、その支持面内の全境界線の延長で分割します。境界線用の切断平面は辺と支持法線の外積で作ります。同一平面上の境界の部分重複も、この分割へ含まれます。

凸な各入力面と共通の直線配置の交わりは凸なセルです。入力面の被覆は各セル内部で変わらないため、同じセルを覆う複数の入力面は、極頂点集合をキーに重複排除できます。同一直線上の追加頂点・巡回の開始位置・逆向きの頂点順はキーに影響しません。覆う入力面は全て由来として残します。

全体を三角形化して既存の三角形ブーリアンへ渡す方式ではありません。元の多角形の面を直接分割し、三角形は最終的な検証・点照会用の厳密な分解にのみ使います。

## 面の両側の材料と向き

セルの厳密な内部点から支持法線の両方向へ進んで、両入力の内外を照会します。移動量は1と、他の各支持平面までの非零交差パラメータ絶対値の半分のうち最小を取ります。平行な平面は交差せず、共面の支持面は移動直後に離れます。分割済みセルの内部点が別の非共面支持面にあれば不整合として拒否します。

この移動量では別の境界支持面を越えないので、サンプルは元のセルの直近の両側を代表します。両側でブーリアン真理値を計算し、異なる場合のみ境界を残します。負側だけが材料なら正法線、正側だけなら逆法線を外向きにします。両側が一致する面は内部面または外部面として除きます。薄い隙間や薄い積集合を許容誤差で潰しません。

## 接続と接触

残る凸多角形を全端点で再分割し、共有辺へ接続します。全辺が少なくとも二つの使用を持ち、向きの総和が0であることを検査します。既存の厳密な三角形交差検査により、境界分解の不正な面交差も拒否します。向き付き体積は非負でなければなりません。幾何学的な接触は、面の支持平面群と境界線の分割により接続の頂点・辺として保持します。

正則化で体積のない単独の積集合は残しません。体積を持つ材料の成分間の接触は残すため、結果が辺または頂点で非多様体になることがあります。これは接続診断に示しますが、閉じた材料境界の内外判定と次の材料演算は継続できます。入力検証の厳密な多様体立体と、所有済みブーリアン接触境界は型と所有権を区別します。

## 検証と限界

独立した箱の不等式と体積、立方体・八面体の角の単体体積、非凸L柱の分離した長方形面積から求めた体積で四演算を照合します。向きを反転する有理アフィン写像、行列式による体積倍率、浮動小数点では解像できない隙間・積集合、同一面の異なる分割・巡回始点・同一直線上の端点、空集合、空洞の作成と再充填、辺・頂点・頂点対面の接触と再演算を含みます。

この文書は構成の説明と実行テストの範囲であり、新しいLean証明や全TypeScript実行の形式検証ではありません。由来は直前の入力の面IDです。共通Bodyへの採用、曲面や無理数の面、面の統合、空洞情報の永続化、大規模形状の空間加速は今後の開発です。
