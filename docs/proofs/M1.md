# M1 の証明対応表

M1で`formal/CadloomFormal/`に追加したLeanの定理（`NurbsSurface.lean`、`Curve.lean`、`Surface.lean`）と、TypeScriptの実装・テストの対応表です。M0と同じく`node formal/scripts/verify.mjs`（`npm run prove`）で確かめます。このスクリプトは`lake build`を実行し、全定理の公理を監査して、`propext`・`Classical.choice`・`Quot.sound`の3つ以外に依存しないことを確かめます。Mathlibは使っていません。

## 読み方（共通の前提）

- 前提は[M0.md](M0.md)と同じです。Leanのモデルは**有理数（`Rat`）上の厳密な数学**で、TSの関数と同じ式・同じ添字・同じ再帰構造で書いてあります。TSは倍精度浮動小数点で計算します。**丸め誤差の上界は証明していません。** テストでは許容誤差つきで同じ性質を確かめています。
- **三角関数と平方根**: core Leanには実数がないので、`cos θ`・`sin θ`は有理数の変数の組`(c, s)`と仮定`c*c + s*s = 1`で表します。定理はこの仮定を満たす全ての組について成り立つので、真の値についても成り立ちます。ただし倍精度の`Math.cos`/`Math.sin`の値は、この仮定を近似的にしか満たしません。円には有理パラメーター化`((1-T²), 2T, (1+T²))`も使います。
- **正規直交の座標系**`(X, Y, Z)`は、内積の仮定（`X·X = 1`、`X·Z = 0`など）として与えます。TSの`createCurveFrame`が作る座標系は、丸めの範囲でしかこの仮定を満たしません。
- 配列の範囲外アクセス、`Result`のエラー経路、入力検証（有限性・オーバーフロー・アンダーフロー判定）、凍結（`Object.freeze`）、縮退の閾値はLeanの対象外です。これらはテストで確かめます。
- 「テスト」列の名前は`tests/*.test.ts`の`test(...)`名です。定理名と同じ名前のテストが、実装に対して同じ性質を確かめます。
- 「補題」は、他の定理の証明のための補助的な定理で、対応するTSの関数はありません。
- 全ての仮定は満たすことができます（空虚な定理ではありません）。例: `(c, s) = (3/5, 4/5)`、`k = 25/18`、ノット`U = id`とスパン内の`u`。

## 統合時の変更（M1）

- **名前の衝突の解消**: M0の`topology`のB-rep用の幾何タグ`LineCurve`・`PlaneSurface`を`EdgeLine`・`FacePlane`に改名しました。M1の解析曲線・曲面の`LineCurve`・`PlaneSurface`と衝突しないためです。M0の評価関数`evaluateCurve`（NURBS曲線）・M1の`evaluateSurface`（NURBS曲面）と、解析形状も含む`Curve3`・`Surface3`の評価関数`evaluateCurve3`・`evaluateSurface3`は、接尾辞`3`で区別します。
- **1つの仕事は1か所で（POLICY §3.5）**: `binomial`、`finiteOr`、同次座標の射影（`projectHomogeneous`）、制御点の検査（`checkPoints`）は`src/nurbs/curve.ts`の1か所に置き、M1の曲面・次数上げはそれを使います。単位法線の計算と縮退判定は`unitNormalFromPartials`（`src/nurbs/surface.ts`）の1か所で、NURBSの`surfaceNormal`と解析曲面の`surfaceNormal3`が共有します。円弧のNURBS形式は`rationalQuadraticArc`（`src/curve/conic.ts`）だけが作り、回転面はそれを使います。導関数の次数の上限は`MAX_DERIVATIVE_ORDER`（64）の1つで、M0の`curveDerivatives`にも適用しました（巨大な次数でメモリを使い果たさないため）。

## 既知の限界（M1全体）

- 全ての定理は有理数の厳密計算についてのものです。三角関数・平方根は`c² + s² = 1`の仮定で表し、倍精度での誤差の上界は証明していません。
- 偏微分（A3.6/A4.4）、基底関数による評価、ノット挿入（曲面）、次数上げA5.9は、Leanでモデル化していません。テストで確かめています。
- 次数上げはクランプされたノットベクトルだけを受け付け、次数の上限は32です。
- NURBS曲線・曲面への最近点・射影は、サンプリングとNewton法によるもので、大域最小は保証しません。
- 法線は極や縮退辺で極限を取らず、`degenerate`エラーを返します。半径が約`1e-5`より小さい球も縮退と判定します。
- 円錐は片側（1つのnappe）だけです。horn/spindleトーラスは拒否します。非一様な変換は解析曲面では拒否するので、先にNURBSに変換してください。
- 主方向は計算しません（主曲率のみ）。NURBSの陰関数による「曲面上にある」ことの証明書（upstreamの`implicit.rs`）はありません。
