# 凸な平面多角形の支持平面分割

入力は有限の有理座標列です。異なる頂点、非零の支持法線、全頂点の共面性、全ての有向辺の左半平面への所属、連続辺の後戻りの不在を検査します。凸性を仮定して処理するだけでなく、非凸・交差・重複の入力を拒否します。

各平面について、頂点評価に正負が両方ある場合だけ二つの閉半空間で切ります。線形評価の符号が変わる辺の交点パラメータは f(a)/(f(a)-f(b)) であり、厳密な有理数です。交点を同じ順序位置で両方の境界へ挿入します。凸集合と半空間の共通部分は凸で、両側に厳密な符号の頂点があるため両片には面積があります。一側のみ、接触、共面の場合は元の面積を一度だけ保持します。

帰納的に各片は元の多角形と閉半空間群の共通部分です。全片の和集合は入力で、異なる符号を持つ片の相対内部は交わりません。正の面積を持つ凸多角形の全頂点の平均は相対内部にあり、各入力平面の内部符号を判定できます。列の循環順序が変わらないので向きも保持します。

検証は独立した半平面境界直線の全組合せ交点列挙との一致、面積ベクトル保存、内部符号、斜めの支持平面、反転、極小有理数、共面・接触・重複切断、不正な境界の拒否を含みます。既存の三角形分割と立体ブーリアンの回帰テストも同じエンジンを通ります。この説明はLeanによる証明やTypeScript全体の実行意味論の証明ではありません。一般の非凸面・穴の分割、B-rep接続、シェルの埋め込み・立体認定は含みません。
