# 平面多角形立体の成立検査

## 対象と表現

凸・有理座標・穴なしの平面多角形を面として持つ、有限な材料立体を対象とします。シェル全体は非凸でもよく、複数シェル、空洞、入れ子の材料、貫通穴に対応します。面ごとの凸性・共面性と境界順序を既存の分割エンジンで検査し、全ての辺端点をそろえて共有辺へ接続します。閉じた向き付き接続は最初の必要条件です。

## 厳密な分解による幾何学的検査

接続後の各面のコエッジ起点をたどって、端点をそろえた多角形を取り出します。正の面積を持つ凸多角形の全頂点の平均は厳密な相対内部点です。この点と各境界線分から三角形を作るため、同一直線上の辺の細分も失わず、面を隙間・内部重複なく覆います。全ての値は有理数であり、近似・許容誤差を導入しません。

既存のprepareSolid3で、この正確な分解の閉じた多様体接続、全三角形対の適正な交差、シェル同士の非接触と包含、包含深さに応じた向きの交代を検査します。三角形のシェルの各面を元の多角形IDへ戻し、元のB-repシェルの面集合と一対一で一致することも検査します。検証内部の分解は多角形B-repの面IDを変更しません。

材料体積と有理点の内外判定は、この厳密な境界分解に対する既存の実装を使用します。空の材料は体積0、境界なし、全点が外部です。返す構造は不変にし、後続の材料演算に向けてfactory所有権も登録します。

## 検証と限界

独立した箱の不等式、アフィン変換した四面体の重心座標不等式と行列式による体積で判定を照合します。空洞・材料島・離れた成分、T接続、再分割した面、極小有理数と巨大平行移動、貫通穴、空集合を含みます。接続だけなら閉じている交差した箱が幾何検証で拒否されることを明示的に検査します。

これは新しいLean証明ではなく、既存の正確な三角形検証への構成上の帰着と実行テストです。曲面、無理数の面頂点、任意のBodyレコード認定、共通Bodyの材料演算は含みません。二次計算量の交差検査を含み、大規模形状への加速は今後の課題です。接触する別シェルや非多様体材料も許可しません。
