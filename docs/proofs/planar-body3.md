# 平面材料と共通Bodyの接続

## 所有と復元

createPlanarBody3はpreparePlanarSolid3で検証した多角形材料だけを採用します。保存するplanar構築レコードは有理多角形群であり、実行可能な分類関数や検証済みフラグではありません。restoreBody3は多角形から埋め込み・包含・向きを再検証し、面領域と境界を復元して全ての保存レコードと照合します。既存のBox・Cylinder・Extrudeの構築レコードと古い面領域省略形式も既存の照合条件を維持します。

共通Bodyの平面演算は、所有を確認した上で、既存の平面・直線・有理頂点の境界を取り出します。凸面は保持し、非凸面と穴は有理平面チャート内で厳密に分解します。平面ブーリアンの結果を再度検証して採用するため、閉じた接続だけで任意の入力をBodyへ昇格させません。非多様体の接触結果は共通Bodyへはまだ採用せず、明示的に拒否します。低水準の所有済み材料演算では接触を保持して継続できます。

## シェルと領域

検証済みの各シェルについて、他のシェルによる包含深さと、深さが一つ小さく内部に含む一意の親を再計算します。三角形と多角形シェルの面ID対応を用い、保存するIDは多角形B-repのシェルに合わせます。

無限領域は最外殻を参照します。各シェルに対して、その殻を外周、直接の子の殻を空洞境界とする一つの有界領域を作り、深さが奇数の領域をvoidとします。各殻は外側と内側の二領域で共有します。材料島がある場合、空洞領域はその島の殻も参照します。材料領域だけに、外周面の内部から物理法線の負方向へ有理距離を縮めて求めた厳密な内部点を保持します。埋め込みと非接触により、十分近い内側には必ず該当領域の点があります。候補をその領域・子・材料の実際の所属判定で確認します。

## 代数的座標の所属

検証済み有理三角形境界の各支持平面と辺の半平面境界を含む有限の有理平面配置を作ります。この配置の同一符号セルでは、全三角形の所属と材料の所属は一定です。代数的入力点について各平面の符号を厳密に計算し、同じ符号セル内の有理点を選んで、既存の厳密な有理材料照会へ帰着します。

符号0の平面は等式として有理Gaussian消去し、自由変数の有理近似から従属変数を厳密に解きます。符号0の条件を近似で壊さないため、面や辺上の点も扱えます。自由変数の代数的隔離区間を細分し、残る全ての厳密符号が一致するまで続けます。等式の解は自由変数に対して連続な有理アフィン写像であり、有限個の非零な線形評価には正の余裕があるため、反復は終了します。有理入力は既存の有理照会へ直接渡します。登録された相関以外の、入力オブジェクトのorigin等の付加情報は信頼しません。

## 検証と未対応

空洞・材料島・離れた成分・空集合の領域表と保存復元、復元後の再充填、穴付きの直線押し出しとの積、面領域の照会、改ざんした役割・領域・支持面・構築多角形の拒否を検査します。代数的照会は独立な平方根の座標、面・辺上の相関した座標、極小の正符号、偽の相関情報を含みます。元のBody構築と面境界の回帰テストも実行します。

これは構成の説明と実行テストであり、新しいLean証明や全TypeScriptの形式検証ではありません。接触複体の共通Body領域、曲面・無理数頂点、一般CAD形式、演算木・由来履歴の永続化、空間加速は今後の課題です。
