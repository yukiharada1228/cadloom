# 円柱同士の支持面交差

## 対象

二つの無限の円柱面を対象とします。軸の原点・方向は有理数、方向は非零、半径二乗は正の有理数です。方向を単位長へ近似しません。有限の面領域や材料の積ではなく、支持面の交点集合を求めます。

## 平行軸

第一軸に垂直な断面へ第二軸の原点を有理射影します。同じ平面の二円の厳密な交差を解き、各点を共通軸方向へ伸ばします。二円の一致なら円柱面の一致、交点なしなら空、二交点なら単純な二母線、接点なら二重の一母線です。

## 非平行軸の完全な二枚の高さ表示

軸方向をd,e、原点をA,B、半径二乗をRA²,RB²とします。D=d·d、E=e·e、n=d×e、a=n·n>0と置きます。第一円柱の任意の点は一意にp=q+h dと表せます。qは中心A、法線d、半径二乗RA²の円上にあり、hは実数です。

w=e×(q-B)、v=e×d、b=w·vとすると、第二円柱への所属は

    a h² + 2 b h + |w|² - RB² E = 0

です。L=n·(q-B)と置くと、外積の恒等式から半判別式は

    b² - a (|w|² - RB² E) = E (a RB² - L²)

となります。したがって実根がある条件は円上の帯 |L|≤sqrt(a RB²) だけです。高さは

    h± = (-b ± sqrt(E (a RB² - L²))) / a

で与えられます。全ての円柱交点がこの表示へ写り、逆にこの表示の点は両円柱へ属すため、この帰着は交点を取りこぼしません。

## 臨界点と曲線グラフ

帯の両境界L=±sqrt(a RB²)と基準円の交差は高々四点です。k=n·(A-B)、lambda=±sqrt(a RB²)-k、u=d×nとすると、候補は

    q = A + n lambda/a ± u sqrt((RA²-lambda²/a)/|u|²)

です。平方根の中が負なら候補なし、0なら一点、それ以外は二点です。判定と平方根は全て厳密な代数的実数です。

全臨界点と二つの対向する補助的な継ぎ目で円を分けます。各開いた円弧内では判別式の符号は一定です。内部点で負の片を捨て、正の片へ二つの高さの枝を作ります。開いた片の内部で0が検出された場合は、未分割の臨界点がある不整合として拒否します。対向する補助点により、円全体を表す任意の継ぎ目が孤立接点に一致する場合でも、その点を開区間の代表として誤用しません。

正の片では高さの二根は異なります。異なる開円弧は射影が異なるので、その内部の3D曲線は交差しません。根の合流は判別式0の臨界端点だけで起こります。端点を厳密な代数的座標で統合して辺の始点・終点ポートを構築し、辺に属さない臨界点を孤立点として保持します。四価の頂点は特異頂点として報告し、通過経路を任意に選びません。有限な円と連続な平方根から得る二枚の高さ表示は有界で、これらの片と臨界点が交点集合全体を覆います。

## 評価と所属

評価は所有された曲線片と、その基準円弧上の厳密な点を要求します。所属判定は第一軸方向へ射影した基準点の円弧所属、第二円柱の式、枝の符号を使います。

m=E d-(e·d)eとすると、m·(p-B)=a h+bであり、その符号が高さの枝を指定します。0の臨界端点は両方へ属します。評価から得た不変な点だけは非公開の構築レジストリを使います。構造をコピーした曲線や、入力オブジェクトに追加した相関らしいプロパティは認定しません。評価の任意の入力点を強参照のキャッシュへ蓄積しません。

## 二つの代数的パラメータの演算

一般の臨界点や高さには二つの代数的値が現れます。o+u s+v tという有理アフィン表示を、factoryで構築した不変な点の非公開レジストリへ保持します。パラメータ間の関係を仮定せず、線形・二次式を係数で展開して厳密に評価します。これにより、各座標を独立な高次数の値として再合成する不必要な終結式の次数増大を避けます。円と円柱の判定では、完全な c+a s+b t+A s²+B s t+C t² を評価します。直交する方向や軸に平行な方向による0係数も有理演算で消えます。

## 検証と限界

平行軸の一致・非交差・一つ／二つの母線、等半径直交円柱の独立なPythagoras列挙とz=±x、異半径の二つの閉じた成分、孤立接点と四価の特異点を検査します。一般のずれた有理軸では全端点と内部点を両支持面の式へ代入し、入力交換による所属も照合します。軸の倍率・軸上原点の変更、極小の接触近傍、ほとんど平行な軸での非常に長い枝と短い枝、偽の構築情報の拒否も含みます。

これは構成の説明と実行テストであり、新しいLean証明やTypeScript全体の形式検証ではありません。有界面の切り取り、曲線片と平面の交差、パラメータ曲線とB-rep辺の結合、特異点での曲線経路の選択、永続化、一般曲面ブーリアンは今後の開発です。
