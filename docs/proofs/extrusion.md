# 有理数押し出しメッシュの正当性

対象は`extrudePolygon`と`inspectMesh`。正しい適合2D三角形分割を前提とした数学的説明であり、TypeScript実行全体や任意3Dメッシュの埋め込みを機械検証するものではない。

## 立体と入力制約

正規化領域Pと非零の有理数高さh、基準z座標bから、P×[min(b,b+h),max(b,b+h)]の境界を構築する。高さの符号にかかわらず返す面は外向き、体積は非負とする。正規化領域が空なら空メッシュを返す。高さ0は空メッシュへ変換せずRangeErrorで拒否する。

入力の点接触は、押し出すと2つの立体が線で接する非多様体を生む。2D分割の境界頂点に接続する境界辺数が2以外の場合は明示的に拒否する。離れた複数の成分、穴、穴の内部の島は許す。

## 面の構成と方向

2Dの各三角形は反時計回りなので、上面はそのまま、下面は2頂点を交換して使う。従って上面法線は+z、下面は−zを向く。三角形分割内部の辺は同じ面内で逆向きに2枚へ接続する。

2D分割のうち1枚の三角形だけに属する辺a→bは材料を左に持つ境界である。側面を(a0,b0,b1)と(a0,b1,a1)に分けると、法線の水平成分は正の高さ倍の(dy,−dx)となり、材料の右すなわち外を向く。穴の辺は時計回りなので同じ式で穴の内側へ外向きになる。

上下面の境界辺は側面に逆向きで接続し、側面の対角線も逆向きの2枚に共有される。垂直辺は境界頂点の隣り合う側面に共有される。2D境界の次数が2であることがこの対応を保証する。頂点のリンクが単一閉路であることも実装で検査し、辺接続だけでは分からない頂点のピンチを検出する。

## 体積

向き付き三角形(a,b,c)の体積寄与の6倍をdet(a,b,c)とする。閉じた外向きメッシュではこの和を6で割った値が符号付き体積になる。

`PrismVolume.lean`の`prism_volume_eq_area_height`は、任意の有理数三角形・基準z・高さについて、三角柱8三角形の行列式寄与の和が「3×高さ×2D外積」であることを機械検査する。基準zへの依存も相殺される。

各2D三角形を一旦三角柱として考えると、三角形間の側面寄与は逆向きで打ち消される。残る上下面と外側・穴の側面が実装のメッシュである。従って全体の体積は2D三角形面積の総和×正のz幅、つまり底面積×abs(h)となる。この和の議論と実装対応は手書きの説明で、Leanによるプログラム全体の精緻化ではない。

## 検査器の保証範囲

`inspectMesh`は次を検査する。

- 各三角形のインデックスが有効で、外積が非零であること。
- 各無向辺にちょうど2枚の面が接続すること。
- 共有辺の向きが逆であること。
- 各使用頂点のリンクが次数2の連結グラフ、すなわち単一の輪であること。未使用頂点はこの条件を満たさない。
- 行列式和による厳密な符号付き体積。

空メッシュは空の閉曲面としてこれらの条件を満たし体積0になる。検査器は空間的な自己交差、重複座標の別インデックス、異なる閉成分の衝突や包含を検査しない。共有辺が逆向きであることは全成分の外向きを単独で証明しない。例えば全ての面を反転すると整合した内向きになり符号付き体積が負になる。一般のメッシュに対して体積が幾何学的体積になるのは、非自己交差・閉じた適切な向きの境界という前提の下である。

押し出しでは正しい平面領域とその積から形状を作るため、この前提を構成で満たし、最後に接続・非退化・リンク・公式体積との一致を実行時にも確認する。

テストでは穴と島・複数成分・負の高さ・巨大z座標・微小高さ・有理数の底面、Euler標数を検査する。故意に穴を開けたメッシュ、反転した面、潰れた三角形、不正インデックス、頂点だけを共有する2つの四面体を使い、検査器の検出範囲を確認する。
