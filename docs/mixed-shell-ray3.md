# Exact rays and parity queries on mixed curved boundaries

`intersectMixedBoundaryRay3` accepts only factory-restored mixed faces and a rational ray, optionally restricted to one shell. It intersects each analytic support exactly, discards negative parameters and tests each algebraic hit against the reconstructed bounded face domain. Equal ray parameters are grouped and sorted exactly. Each use retains its face ID, strict-interior/boundary location and simple/double root multiplicity. No mesh or epsilon is used.

A ray is explicitly degenerate if it hits a face boundary, coincident face interiors, or is contained in any relevant supporting surface. Supporting containment is conservatively degenerate even if that bounded domain may miss the forward ray; this avoids falsely treating an uncomputed overlap as no intersection. These results retain the finite hits and contained-support IDs. They require a different ray, rather than assigning an arbitrary owner to shared edges or vertices.

`locatePointInMixedShell3` first requires closed, oriented, locally manifold shell incidence and tests whether the query is on any of its bounded faces. Otherwise it uses the supplied rational direction (default positive x). A degenerate ray returns `retry`; a regular ray counts only simple roots and returns even/odd inside/outside with the ray evidence. A tangent double root cannot switch sides because the quadratic ray pullback has the same sign on both sides of that root. A simple interior root crosses a regular support transversely. For an embedded closed shell, finite transverse crossings therefore give the usual bounded-side parity from infinity. No bounded retry count or approximate fallback silently asserts an answer.

This is a parity query and a prerequisite for shell containment/nesting work, not a shell embedding or material certificate. Restored faces and closed local incidence do not rule out intersections between different face interiors. A regular result does not certify that absent global condition. Queries currently require rational origins/directions; arbitrary algebraic origins and overlap interval extraction remain outstanding. A caller must choose another direction on `retry`.

Tests cover ordered/forward hits, exact simple and tangent-double roots, rim contacts and contained supports, boundary origins, ownership/index rejection, rational-grid comparison against independent cylinder inequalities, orientation reversal, restored SSI-bounded Boolean shells, and offsets of 10^-30 around tangency. Existing selected Lean proofs are unchanged; the ray/domain composition has no new machine-checked refinement proof.
