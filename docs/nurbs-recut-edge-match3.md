# 旧切断曲線と再分割境界の区間照合

`matchNurbsRecutSectionEdge3` は所有された旧section辺と新しい有限セル境界の全区間対応を検査します。新しいセルのrestrictionが旧辺に接続する同一の所有された有限面であり、同一の元UV曲面・面番号に属することを要求します。新区間は旧辺の閉じたネイティブ区間に含まれる必要があります。

定数uまたはvの経路は固定座標とネイティブ座標が同じことを検査します。陰的な曲線同士はUV多項式の共通因子を求め、選択した分岐がその因子に属し、旧・新で同じUV値を取ることを確認します。両者は既存の認定された配置の、内部に投影イベントを持たないグラフ分岐区間なので、共通因子上で一致する分岐は区間全体で連続します。端点の一致だけから対応を決めません。定数vとグラフ分岐の対応では、固定座標を多項式へ代入した恒等式を検査します。

対応するパラメータは同じネイティブ座標でdirection:1です。境界のcoedge方向は別に保持され、ここでは変更しません。`nurbsRecutEdgeMatchPoint3` は所有された照合証明と認定区間だけを評価し、旧曲線と新区間の空間点一致を検査します。異なる所有面、区間のはみ出し、異なる支持曲線・分岐はnot-certifiedです。

対象は以前の切断で生成したsection曲線です。通常のsource辺の照合には既存の共有元辺・有理曲線区間照合を使う必要があります。旧辺端点を越える新区間はまず共有nodingで区切る必要があります。新旧断片の全被覆、キャップ側の区間対応、全体の再縫合と閉立体の埋込み・材料認定は残ります。再切断Body APIの完成や実行コード全体の形式証明を主張しません。
