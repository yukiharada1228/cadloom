# 平面分割領域からのNURBS面BRep

`buildNurbsPlaneSplitFaces3` は所有されたセル境界の節点化結果を受け、各連結領域の閉路を共通のBRep接続エンジンへ渡します。領域の外周・穴の向き付きループ、元の有限面番号、符号ラベルを保持します。符号は元の開セルに対するもので、閉包には平面上の点も含まれます。

同じ領域内部の人工的なセル継ぎ目は採用しません。異なる符号の領域の間の切断辺は、二つの分割面から逆方向に使われる共有辺になります。元の面のsenseが負なら、全ループの列と各使用方向をともに反転します。各辺は元の節点化辺とnative intervalを保持し、暗黙曲線を弦や三角形へ置換しません。

`sourceEdges` は節点化辺から採用された辺への対応です。採用しない内部継ぎ目はnullです。`sourceVertices` も採用された頂点への対応を残します。面上の全辺の所属は、所有された領域境界の区間全体に基づいて検査し、標本点だけから推測しません。

`nurbsPlaneSplitFaceEdgePoint3` は所有された辺の有限区間だけを、元のセル曲線として厳密に評価します。複製された辺や節点化結果、区間外のパラメータは拒否します。未解決の節点化結果や単純な閉路が得られない領域では、元の報告を保持した未解決結果を返します。

これは一つの元の有限面に対する分割面BRepです。BRepの頂点・辺の問題報告は保持し、グローバルな埋込み・材料・閉じた立体の認定を新たには与えません。別の元面の分割面との共有辺の統合、切断面のキャップ生成と縫合、子Bodyの生成・認定は引き続き必要です。テストの円柱キャップは元から存在する面であり、新しい切断面を生成したものではありません。

独立スナップショットでビルド、関連2ファイルのstrict型検査、関連13ファイル47テストが成功しました（8226.17325 ms、失敗・キャンセル・スキップ0）。非線形立方体6面から10個の分割面を組み立て、元の共有子辺の二つの逆向き使用、内部切断辺の共有、人工継ぎ目の除去を確認しました。穴と負のsenseの二つのループ、元の円形キャップの厳密な曲線評価、未解決入力と所有・区間ガードも含みます。257ソースのハッシュとステージ済みソース・テスト534ファイルの一致を確認しました。全リポジトリの検証や新規形式証明は主張しません。
