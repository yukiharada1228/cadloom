# 認定NURBS面から共通B-rep接続への橋渡し

`buildNurbsSourceBRep3` は所有された準備済みNURBS面複体を、既存の `buildBRepTopologyWithGeometryAdapters3` へ渡します。新しい接続エンジンやメッシュ近似を作らず、頂点・辺・coedge・loop・face・shell・頂点リンク・境界ループ・接続上の問題を共通形式で得ます。

曲線ハンドルは元の複体と有限辺ID、曲面ハンドルは元の複体と実際のUV面IDを保持します。非線形NURBS面と代数曲線グラフを経由するSSI境界も、この参照を通して厳密なまま保持します。ハンドルはfactory所有で、構造コピーでは評価できません。

## 根拠と向き

辺の面所属は、認定面複体が検査した全区間の空間像一致と面使用を根拠にします。面上の端点やサンプル点だけで辺を受理しません。別の複体の辺や面を混ぜる経路はありません。

既定のsense=+1はパラメータ曲面の正向きです。sense=-1を指定すると、全loopの順序と各辺使用方向を反転して面のsenseも反転します。穴とwireを含む元のサイクルを保持します。各有限UVアトムは認定面の単射性により非閉区間曲線なので、周期辺とは宣言しません。共通エンジンの端点検査でも正の空間的広がりを確認します。

`nurbsSourceBRepEdgePoint3` は元の認定された有限区間を評価します。範囲を広げたコピー、区間外パラメータ、不正なsense、未準備の複体を拒否します。

## 対応と制限

`sourceVertices` は複体頂点からB-rep頂点への対応です。共通エンジンは3D点が厳密に同じ頂点を共有するので、異なるUV頂点が一つの空間頂点に対応する可能性を元の複体側で保持します。`sourceFaces` はB-rep面順から元の面IDへの対応です。辺順は元の複体の辺順と同じで、各ハンドルにもそのIDを保持します。

新しい空間的な辺一致や内部同士の交差は発見しません。不連続な継ぎ目は複体で分離されたままです。面ごとの埋め込み認定は、面同士の空間非交差や殻全体の埋め込みではありません。`closedOrientedIncidence` は従来どおり接続条件であり、材料・空洞・内外・体積・共通Body採用を認定しません。保存形式もこの変更では追加しません。

回帰は、単独の開いた面、SSI分割面の共通coedge twin、穴とsense反転、非線形支持面と非NURBSの暗黙SSI境界、不連続継ぎ目の別shell、所有・範囲検査を含みます。既存B-rep・NURBS辺・アフィンNURBS縫合の回帰も検査対象にします。
