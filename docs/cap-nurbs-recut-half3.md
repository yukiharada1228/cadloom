# 新しい有限キャップ面による再切断半面の閉鎖

`capNurbsRecutHalf3` は所有された再切断キャップの有限領域証明を受け、外周と直属の穴を新しい平面キャップ面として採用します。材料の島は別のキャップ面になります。元の開境界にある厳密な曲線オブジェクトとネイティブ区間をそのまま使い、境界ループを反転したcoedgeで接続します。新しい近似辺・頂点や折れ線は生成しません。

残存するNURBS面と旧キャップの向き・有限領域を保持し、共通B-repエンジンで全辺の逆向き双対、閉鎖、頂点リンクを再検査します。closedOrientedIncidenceを満たさなければ未解決です。元の辺・頂点・面から出力への対応と新キャップの面番号を保持します。空の側や、次平面が旧形状を外れて新ループがない場合には人工的なキャップを追加しません。

`locateNurbsRecutClosedSurface3` は所有された残存面または新キャップについて空間点の有限面所属を問い合わせます。新キャップの支持平面外はoutsideであり、穴・島・境界を厳密に区別します。結果のpointは空間座標です。方向予算は新キャップと保持した旧キャップの巻き数へ伝搬し、未解決を成功扱いしません。`nurbsRecutNewCapPoint3` は有限領域内・境界上のチャート点だけを空間へ写します。

閉鎖は接続構造の認定です。新キャップ内部と残存面の隠れた接線接触などの検査、新キャップを含む幾何学的埋込み、シェル包含・実材料方向・内部サンプルの再認定、保存復元を含む再切断Body APIは残ります。新しい面を加えた閉立体の材料認定を、旧埋込みの引継ぎだけで代用しません。
