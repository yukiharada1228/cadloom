# Shared quadratic planar ellipse endpoints

When an arrangement endpoint has chart abscissa `x`, the old fallback constructed `x` and the independently computed ordinate as a biparametric world point. Although the ordinate was derived from `x`, subsequent quadratic support checks could treat their source fields independently and form unnecessarily large resultants. A diagnostic on the consolidated tetrahedron/cylinder case identified this path in ellipse endpoint validation.

The fallback now keeps one actual source parameter. Write the ellipse equation in the arrangement chart as `K y² + L(x)y + M(x) = 0`, where `K > 0`. For branch `b = ±1`, set `R = L² − 4KM` and `y = (−L + b√R)/(2K)`. For world chart `o + u x + v y`, each coordinate is `(2K(o_i + u_i x) − v_i L + b v_i √R)/(2K)`. This is passed to the existing genuine quadratic point constructor, preserving one source parameter and one common radical. Each coordinate degree is at most twice the source degree. Substitution into the ellipse equation gives zero exactly; there is no approximation or tolerance.

`K`, `L` and `R` derive from the actual rational ellipse frame and the actual arrangement frame. Existing known-event and validated affine reflection paths remain; segment graph endpoints retain their previous construction. The quadratic constructor still checks denominators and radicand signs. Curve creation and imported geometry continue checking actual support and bounded domains rather than trusting public chart claims.

The 18 existing planar partition/finite-cylinder/quadratic-extension cases pass. The previously expensive consolidated tetrahedron Body case passes in approximately 16 seconds under concurrent diagnostic conditions. This is an observed run, not a controlled speedup benchmark. A new low-level regression uses irrational events from one disjoint circle as abscissae on the other: it checks genuine shared charts, actual ellipse membership, preserved abscissae and the degree bound without timing assertions.

The initial 824-test convex-Body run and its diagnostic were explicitly superseded after the shared-field issue was identified and the corrected connected case passed. They are not reported as successful runs. The corrected integrated source is running 827 non-hard tests plus the additional new endpoint regression separately, and the unchanged slow two-test oblique-cylinder integration is also running. Existing source correspondence checks and the 133-declaration scoped audit pass. No new Lean theorem or full execution proof is claimed.
