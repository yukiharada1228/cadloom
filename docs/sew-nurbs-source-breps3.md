# 異なるsourceの認定NURBS面B-repの境界縫合

`sewNurbsSourceBReps3` は複数の所有されたsource B-repを受け取り、境界の空間交差を分割点として追加し、同じ有限境界像を持つ片を共有辺へまとめます。単独source内の辺IDをそのまま別sourceの一致の根拠にはしません。

## 現在取り出せる有理写像

元のNURBSトリム曲線に属する辺では、向きと有限区間の単調なUV座標から元の曲線パラメータを厳密に復元します。選択済みのパッチ側へ同次多項式を合成し、空間の有理写像を得ます。代数的な切断パラメータは有理NURBSノットに丸めません。

元のトリムに属さないSSI辺では、現在は有理な固定UV座標を持つ軸平行線を扱います。グラフ多項式の全直線恒等式と、交差のない選択分枝の厳密な内部点を確認してからパッチを制限します。端点の弦へ置き換える処理ではありません。

抽出できない辺が一つでもあれば `unresolved / rational-map-unavailable` を返し、部分的なB-repを完成結果として返しません。この理由は曲線が数学的に非有理であるという判定ではありません。一般の非軸平行SSIを再パラメータ化する経路は未実装です。

## 交差分割と全区間共有

全境界写像の組について3成分の同次等式を二変数で解き、孤立した交差とパラメータ関係を求めます。正の重みを持つ実際の有限区間へ制限し、全3D成分の一致を再確認します。交差・重なり関係のイベントを両方の元パラメータへ挿入して、部分的に重なる境界も共通片へ分けます。

同じ端点を持つ候補でも、それだけで共有しません。パラメータ関係を両候補区間へ制限し、関係の向きが整合し、両方の座標射影がそれぞれの閉区間を隙間なく覆うことを要求します。関係上の全点は空間の全成分の等式を満たすため、両側被覆から有限な像全体の一致が従います。元の認定面上の境界は単射な区間像なので、向きを持つ共有辺使用を作れます。非線形の再パラメータ化もこの条件で扱います。

共通B-repエンジンでcoedge・loop・shell・頂点リンクと接続上の問題を構築します。各入力B-repの元の辺から、元の進行方向に並んだ子辺使用への `sourceUses` を返します。面は元のsource B-repと実際の面IDを保持し、元のsenseとloop方向を維持します。

`sewnNurbsSourceEdgePoint3` は所有された辺ハンドルのネイティブパラメータ区間で厳密に評価します。これも元のsourceのUV座標や別の共有使用のパラメータと同じとは限りません。

## 到達点と未完了

独立した6枚のNURBS面、および全6枚が非線形パラメータを持つ面から、頂点8・辺12・coedge24の閉じた向き付き立方体接続を構築できました。曲がった放物線境界の異なるパラメータ化、部分重複、代数的な切断位置も扱います。

これは全ての面内部同士の交差・殻の大域的埋め込み・包含・材料領域・共通Body採用の認定ではありません。入力間の検査は境界曲線の交差です。閉じた接続だけで材料とは扱わず、一般SSIの有理写像抽出、空間面交差と材料の統合が引き続き必要です。計算量は境界片の組合せに対する二次の検査を含みます。
