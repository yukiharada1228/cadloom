# NURBS符号セルの閉境界

`nurbsSourcePlaneCellBoundary3` は、所有された開セルの報告から、そのセルの閉包の境界をUVの正方向に並べます。下辺はu増加、右辺はv増加、上辺はu減少、左辺はv減少です。一点に縮む側は辺として作りません。全ての辺の接続を検査します。

上下の曲線辺は元の配置グラフの枝を保持します。左右の射影イベント上では、上下の枝の厳密な極限の間を、そのイベントにある全ての曲線頂点で分割します。折り返し点で隣接するセルの境界が途中から分かれる場合も、端点の座標を推測しません。矩形境界は正確な定数uまたはvの曲線です。

頂点と辺の評価には元の有限面の閉集合への所属と、近づくパッチを適用します。実際の空間点での平面式は、元のセルと同符号または零であることを再検査します。曲線を端点間の直線へ置換しません。辺のnative parameterは増加順に保持し、閉路での使用方向は別フィールドです。

`nurbsSourcePlaneCellBoundaryPoint3` は閉区間の辺を厳密に評価します。複製された報告、不正な辺番号、区間外のパラメータは拒否します。

これは各セル単位の閉境界です。隣接セル間の共有辺の同一化、人工継ぎ目の除去、全パッチ間の縫合、キャップのBRep面化、子立体の認定はまだ行いません。UVの正方向は元の面の物理的なsenseとは区別します。

独立したステージ済みスナップショットでビルド、新規テストのstrict型検査、関連4ファイル25テストが成功しました（6653.081042 ms、失敗・キャンセル・スキップ0）。穴のある面、放物線の曲線評価、一点に縮む側、射影の折り返し点での境界分割、正のUV向き、接続と入力ガードを含みます。249ソースのハッシュとステージ済みソース・テスト514ファイルの一致を確認しました。全リポジトリの検証や新規形式証明は主張しません。
