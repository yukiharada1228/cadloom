# 交差頂点によるトリム境界の分割

`nodeNurbsIntersectionBoundary3(refined, side)`は、所有された細分交差グラフからsourceまたはtargetのUV頂点を取り出し、対応する検査済みトリム領域の外周・穴を分割する。元の交差グラフは変更しない。

各境界NURBS spanについて、交差点の座標値の最小多項式を有理座標関数へ同次代入して全実根を求める。閉span範囲、実際の座標値、もう一方の座標の全てで照合し、共役根や別枝を除外する。xが一定ならyを使用する。ノット端点に加え、x/y座標微分の全零点も切断点として保持する。各境界片は両座標について単調になる。

境界の頂点はUVの厳密な一致で共有する。各頂点は対応する細分交差グラフの全頂点IDを持つ。特にtarget側の同じ境界点が、異なるsourceパラメータから到達される場合、その逆像を失わない。`intersectionVertices`は交差グラフの頂点から境界頂点への対応で、境界にない頂点はnullとなる。

各辺はring/curve/spanと正のパラメータ範囲、始終頂点を保持する。`rings`は元の外周・穴の進行方向のまま辺IDを並べ、最後から最初までの閉接続を検査する。domain senseを勝手に反転しない。

検証はsource/target両側の双曲線端点、無理数の境界逆像、穴、同じtarget UVへの複数source逆像、重み付き曲線境界と挿入ノットを扱う。これは境界と交差頂点の対応を作る段階であり、面分割の完成ではない。

交差辺と一致する境界区間の全体同一視、交差辺を含むUV配置、分岐の接線順序、面片の閉ループと穴の割当て、一般曲面の埋め込み・材料認定は次の処理として残る。辺の端点が一致するだけで、境界辺と交差辺を共有化しない。
