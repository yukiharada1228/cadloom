# NURBS Bodyの厳密な相似変換

`transformBody3` は所有された `NurbsBody3` と `SimilarityTransform3` を受け取り、NURBS Bodyを返します。有理数の平行移動、回転、一様な非零拡大縮小、鏡映に対応する経路です。従来の解析曲面Body・CellularBodyの分岐も維持します。

source B-repを構築した元曲面と交差相手曲面の制御点を両方変換し、次数・重み・ノットとUVトリムを保持します。NURBSの同次評価とアフィン変換の可換性により、変換された支持面上の位置は元の位置を変換した値です。交差相手も同時に変換するため、元のUV交差を別の曲面との交差に置き換えることはありません。

線形部の行列式が負なら各sourceの面senseを反転します。鏡映されたUV法線は物理的な外向き法線と逆になるためです。材料の空洞や島の役割は、変換されたsourceから包含と向きの認定を再計算して確認します。

元の埋め込みの分離平面 `n·p=c` も、`n'=L n / scaleSquared`、`c'=c+n'·t` に変換します。相似変換ではこれが逆転置による平面変換です。これらを探索候補として渡し、両面全体の半空間所属と、零断面が宣言された共有辺・頂点だけで覆われることを再検証します。座標軸に依存した既定の探索候補だけに頼りません。

NURBS文書の任意フィールド `separators` は、この探索候補を保存します。候補の面番号・非零法線は検査され、偽の平面から認定を生成することはありません。幾何的に不適切な候補は採用せず、既定探索へ進みます。候補を持たない既存文書も読み取れます。項目・文字数予算はレシピと候補を合わせて適用します。

出力は共通復元経路で全認定を実行した新しいBodyです。幾何演算や認定が未解決なら例外を返し、未認定のBodyを公開しません。一般アフィン変換、非一様拡大縮小、任意の代数的行列係数、完全な認定探索はこのAPIの対象外です。

三角射影で認定した有限面の逆照会には、認定済みの二つの射影法線とその外積からなる有理座標系を使用します。行列式は外積の長さの二乗で非零なので、この座標変換で逆像は増減しません。一方の射影座標の一変数構造を一般の空間座標の混合で隠さずに解き、最後は元の有限面への所属と元XYZの一致も確認します。これは逆像計算の座標の選び直しであり、形状の近似や許容誤差ではありません。

円柱などの積構造では、第二の射影も第一パラメータに依存しない方向を優先します。微分多項式の恒等式と全閉領域での厳密な符号を確認し、見つからなければ従来の第二射影候補を使います。回転だけで不要な二つの代数的パラメータの混合を導入しないための選択です。

曲線境界の縫合、有限面の直線交差、曲面の逆像では、有理行基本変形で方程式の基底を整理してから二変数消去を行います。非零の有理数倍、他の行の有理数倍の加減、零行の除去だけなので、点も共有曲線も含めた同時零点集合は変わりません。二通りの辞書式順序の一意な行簡約形から、一変数の制約を露出できる基底を優先します。

縫合には、曲線を含む有理平面の恒等式を用いた除外も加えています。相手曲線の有限パラメータ区間に平面式の零点が全くなければ、両曲線は交わりません。零点がある場合や同一平面の場合には除外せず、従来の全交差・区間被覆検査へ進みます。これは近似的なバウンディングボックスによる省略ではありません。

連立方程式のファイバーには既存の `bivariateFiberRoots` を用い、一次のファイバーでは第二座標を第一座標の有理関数として構築します。二次では実数判定と二重根も扱い、高次は従来のノルムによる候補列挙へ進みます。残余の両方程式・共有因子の除外検査は維持します。混合多項式の評価には既存の共通根を保持する積和計算を用い、同じ代数的根から得た座標を無関係な根として繰り返し拡大しません。独立な根では従来の完全な算術へフォールバックします。

最終の独立スナップショットで、関連18ファイル149テストが成功しました（44923.238375 ms、失敗・キャンセル・スキップ0）。三軸が混ざる有理回転、非線形立方体と重み付き円柱、変換後の保存復元、鏡映と逆変換、空洞と材料島、代数的な境界点、曲面の交点パラメータ、不正な探索候補・交差する幾何の拒否、既存の逆像・ファイバー・共有曲線・直線重なり・相似変換を含みます。ビルドと関連5テストファイルのstrict型検査も成功しました。新規のLean形式証明、TypeScript全体の形式検証、リポジトリ全テストの完了は主張しません。
