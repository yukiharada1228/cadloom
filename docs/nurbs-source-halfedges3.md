# 元面UVの枝順序と半辺巡回

`buildNurbsSourceHalfedges3(complex)`は所有されたsource境界・交差辺の共通原子から各辺の正逆の半辺とtwinを作る。source UV内の処理であり、空間像や材料の認定を付与しない。

## 厳密な枝の循環順序

各原子は境界の座標微分イベントまたは交差辺の陰関数微分イベントで分かれ、開区間上で両座標が単調である。始終のUV差から、軸を含む8方向の区間を決める。角度・atan2・epsilonは使用しない。

同じ左右方向の枝は、頂点とその方向の最も近い別UV頂点のu座標の間に有理数を選び、同じu線で比較する。境界NURBSは有限な単調span上の正確な逆像、交差辺は選択された枝の評価を使用する。右側ではvの増加順、左側ではvの減少順を使う。元の曲線配置は交差・座標イベントで分割されており、この間に別の交差頂点はない。このため接線が一致していても、近傍の枝を区別できる。

同じ方向の軸上の枝、または共通u線で区別できない枝が残れば`kind: 'unresolved'`を返す。未解決頂点とincident半辺を保持し、nextやcyclesを生成しない。sourceの不連続な空間像がUVで重なる場合に、任意の辺ID順を幾何順として採用しない。

## 巡回

全頂点で順序が決まれば`kind: 'ordered'`となり、反時計回りのrotationを返す。各半辺の終点でtwinの直前の枝へ進むことで、左側をたどるnextを作る。全半辺が重複なく閉じた巡回に分かれ、各nextで頂点接続が一致することを検査する。孤立頂点は空のrotationを持つ。

cyclesは境界walkであり、面ID・面積・内外をまだ割り当てない。一つの面に複数walkが属する場合がある。穴の所属、非多様体や重複の解消、target側、特異枝と重なりregion、埋め込みと材料の認定、共通Bodyへの採用は残る。

## 共通の代数的依存関係を保持する微分評価

同じ接線を持つ二枝の回帰で、二階微分・曲率・法線との内積が独立な消去計算に分かれて膨張することを確認した。陰関数の微分はn=Fu,d=Fvならslope=−n/d、second=−(Fuu d²−2Fuv nd+Fvv n²)/d³を多項式の段階でまとめて評価する。座標を交換する場合も同様。

空間座標P/WはD=d∂u−n∂vを使い、R=D(P)W−P D(W)、Q=W²d、S=D(R)Q−R D(Q)からfirst=R/Q、second=S/(Q²d)を評価する。vを独立座標にする場合は偏微分を交換する。垂直枝はd=1,n=0。

速度二乗の分子はΣRi²、曲率二乗はΣ(Rj Sk−Rk Sj)² / (d²(ΣRi²)³)。共通分母のQ⁴を記号的に相殺してから評価する。有限精度の相殺ではない。

`AlgebraicReal.productCombination`は明示された積和について、全因子がfactoryで記録された同じ有理関数の元を共有する場合、分子・分母を元の多項式で剰余化して一度に評価する。異なる元は既存の完全な代数演算へフォールバックする。通常のadd/mulなどの挙動・証明書は変更しない。交差微分の内積・外積とtarget連鎖律の検査に利用する。

共通元での厳密な相殺、他の共役根の分母の極、異なる元のフォールバック、factory所有を別の数値テストで確認する。以前の式による実行は診断後の実装修正で旧版となったため終了し、成功件数へ含めない。
