# 再切断B-repの幾何的な埋め込み認定

`certifyNurbsRecutEmbedding3` は、所有された再切断B-repについて、残存NURBS面と新キャップの接触ゲートに、旧平面キャップと新キャップの接触検査を組み合わせます。成功時の `NurbsRecutEmbeddingCertificate3` は、旧境界の埋め込み、source/new-cap接触認定、old-cap/new-cap接触認定と同じ最終B-repを保持します。

## 旧平面キャップの全接触層

`certifyNurbsRecutOldCapContacts3` は、各旧キャップの所有された完全な有限平面断面を使用します。異なる支持平面の共通部分は一本の直線であり、有限領域との共通部分は既存断面の全spanと孤立イベントに列挙されています。平行で異なる支持面には接触がありません。同一平面や元境界の全区間重なりは、前段の分割factoryで未解決として保持されます。

各内部spanに対し、旧キャップ分割のcut辺がちょうど一つ対応することを確認し、採用辺・全結合断片・選択半体・最終共有辺までnative区間全体を追跡します。全spanの一意な対応、順序付き区間被覆、同じ曲線オブジェクトの保持、選択された旧キャップ面への所属を確認します。端点一致だけで区間を共有化しません。

新キャップが同じ位相辺を使用する場合は宣言済み境界です。それ以外のキャップ境界と開区間が途中で交差しないことは、旧境界の埋め込みとcanonicalな完全分割から従います。この条件で開区間の内外を厳密に分類し、両端点は別途検査します。キャップ内部や未宣言境界との接触には証拠点を返します。

孤立イベント、旧キャップ分割頂点、最終の平面上の全位相頂点も空間点でまとめます。全残存旧キャップ面と各新キャップへ有限面所属を照会し、宣言済み共有頂点または共有曲線の有限区間への厳密な所属を確認します。未解決の照会と不整合は認定しません。

## 全体認定の構成

- 残存面同士は、同じ旧埋め込み境界の有限分割から継承する。
- 残存NURBS面と新キャップは、完全なゼロ層と宣言済み接続のゲートを通す。
- 残存旧平面キャップと新キャップは、完全な有限直線断面と共有区間・全頂点のゲートを通す。
- 新キャップ同士は、所有された互いに交わらないouter/hole/island領域を使用する。
- 共通B-repの閉じた多様体接続が、同じ共有辺・共有頂点として幾何的に実現されることを確認する。

この認定は、現在の所有された構築経路に対する境界の幾何的埋め込みです。材料の内外、殻の包含、幾何的な外向き、体積、共通Bodyへの再採用、任意の商用CAD輸入や一般曲面Booleanの完成は認定していません。新しいLean証明やTypeScript全体の形式検証でもありません。

## 固定回帰

両側の箱、重み付き円柱の代数的旧キャップ端点、旧annulusと島の穴で分かれる全直線区間、隠れた孤立点・接触曲線の拒否、平行支持面、負の平面スケール、空・未切断半体、旧円形キャップへの孤立した接線接触を検査します。
