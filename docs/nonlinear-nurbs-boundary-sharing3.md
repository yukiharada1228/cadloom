# 非線形なパラメータ対応によるNURBS共有辺

`sewAffineNurbsFaces3` は、有理アフィン再パラメータ化の恒等式に加え、[完全な境界交差関係](affine-nurbs-boundary-intersection3.md)の区間被覆でも共有辺を認定する。同じ空間曲線を異なる速度でたどる境界、端点や内部で速度がゼロになる単純な再パラメータ化も対象である。アフィン左逆写像を持つ所有面と、その検査済み単純境界の制限に対する処理であり、一般の不正な曲線を受理する入口ではない。

## 認定条件

全交差イベントで分割した二つの閉じた辺区間A,Bについて、端点が同方向または逆方向に一致することを確認する。元のboundary/pieceに対応する完全な関係グラフを、A,Bのパラメータ矩形へ再制限する。全ての保持された関係点は、3空間座標が厳密に等しい組である。

各保持グラフ辺から、両パラメータ軸への閉区間の射影を作る。区間を厳密に整列・統合し、最初のパラメータ区間も二番目の区間も、端から端まで隙間なく覆うことを要求する。対応するグラフ辺のパラメータ増減が、選択した巡回方向と一致することも要求する。孤立した一致点だけでは正の幅の区間を覆えず、共有辺にはならない。

既存の有理アフィン恒等式が成功すればその結果を使用する。失敗した場合だけ関係被覆を検査する。同じ検査を、共通接続エンジンへ渡す辺の全境界所属にも使用する。少数点の一致へ検査を弱めない。

## 数学的な根拠

関係RがA×B内にあり、全ての(u,v)∈RでC_A(u)=C_B(v)とする。Rの第一射影がAを覆えば、全てのC_A(u)はBの像にも含まれる。第二射影がBを覆えば逆の包含も成立し、二つの空間像は等しい。この双方向の包含が共有の根拠であり、端点・代表点だけの一致ではない。

射影区間の被覆は連続なグラフ辺に対するもので、両端の間の全パラメータ値が中間値性で含まれる。境界は認定済みの単純な曲線の制限であり、共通部分の対応は一対一である。区間の向きは対応するパラメータ増減から決定できる。全閉曲線では同じ空間始終点だけで方向を選ばず、関係の向きも検査する。

以上は実装契約の数学的説明であり、この新実装やTypeScript実行全体の機械証明ではない。

## 結果と制限

共有辺は最初に採用した境界片のパラメータを保持する。元の各曲線のsourceUsesは共有辺番号と巡回方向を保持し、boundaryIntersectionsには元の両パラメータ間の完全な関係も残る。保存形式を変更せず、復元時にも元の定義から関係・分割・共有を再生成する。

曲面内部どうしのSSI、面領域の分割、一般NURBS面の埋め込み、殻全体の幾何・包含・材料検査、共通Bodyへの採用は残る。閉じた接続を立体材料の認定へ拡張しない。

## 検証

非線形二次対応の両入力順、内部に停留点を持つ三次対応、部分重複だけの共有、四次のUV再パラメータ化を持つ曲がった空間境界、非線形な辺を持つ立方体の閉接続と保存復元を確認する。同じ端点と円支持を持つ相補的な上下半円は、完全な関係区間の被覆を持たないため共有しない。
