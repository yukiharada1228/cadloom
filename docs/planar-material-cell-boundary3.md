# 分類済みの平面セルから向き付き境界へ

`boundaryPlanarMaterialCells3(classification)` は、実際の `classifyPlanarPartitionMaterial3` の出力から、法線の両側で材料の有無が異なるセルだけを採用します。コピーした分類結果やセルは受け付けません。未解決セルが一つでもあれば全体を拒否し、部分的な分類を完成した境界として返しません。

負側だけが材料なら入力面の向きと境界を保持し、正側だけなら面の sense と境界の走査順を反転します。両側が同じならそのセルは境界ではありません。出力の `sourceCells[face]` は元の分割セルのインデックスです。`sewn.sourceUses` により、採用したセルの各境界曲線から、分割後の向き付き共有辺を追跡できます。

元の分割のイベントも縫合へ渡し、人工的な縦辺の途中にある有限切断線の端点を共有頂点として残します。出力の面・ループ・曲線ラッパー・由来の配列は凍結します。

このAPIは平面側の境界部分を返すため、出力だけでは開いている場合があります。閉じた接続も、面領域の大域的な埋め込み、材料の完全な被覆、Bodyへの採用の証明とは区別します。曲面側の同じ選択、異なる支持面を横断する重複排除、セル統合、一般ソリッドへの採用は後続です。

検査では、円柱の上下端面を分類・選択して、実際の有限円柱の壁と縫合します。入力の面向きが正負のどちらでも閉じた向き付き接続となり、全辺の使用数が2、シェルが1、接続問題がないことを確認します。元のセルへの対応、未解決・コピーした分類の拒否、内部断面の除外、有限切断の端点の保持も検査します。新規4件を含む関連22件、型検査、既存133宣言の限定監査は成功しました。新規APIのLean形式証明ではありません。
