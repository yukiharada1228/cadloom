# 元面UVの境界walkから領域と穴を分類

`classifyNurbsSourceFaces3(halfedges)`は所有された元面UV半辺の巡回結果を受け取る。枝順序が未解決なら、面を生成せず`unresolved / branch-order`を返す。

## 厳密な面サンプル

各巡回から他の巡回と接する半辺を優先して選び、単調な座標を独立軸とする。他のUV頂点と同じ座標を通らない有理数の軸値を選ぶ。この共通線と全辺の交点を求め、対象半辺の左側で隣接する交点の間の有理点を選ぶ。外側に隣接点がない場合は、厳密な根の上下界の外を選ぶ。epsilonや曲線の折れ線近似を使わない。

NURBS境界は有限spanの正確な逆像を使用する。交差辺は選択グラフを評価し、水平線の場合は転置した多項式の全実根から有限範囲と選択枝で照合する。複数辺の未分離交点や一意な有限逆像を確認できない場合は`unresolved / fiber-collision`を返す。

## 巡回の同じ領域への割当て

サンプルを通る同じ線で各巡回の巻き数を厳密に計算する。線は全UV頂点を避けるため、頂点や水平・垂直の全区間一致を半開規則で推測する必要がない。全巡回についての巻き数ベクトルが一致するサンプルを同じUV領域へまとめる。

各領域はcycles、outerCycles、holeCycles、wireCyclesを保持する。巡回の左側・右側の自身に対する巻き数から役割を分け、内部の孤立した線を偽の穴として追加しない。全ての巻き数がゼロの領域をunboundedとする。既存の検査済みトリムdomainのlocateでサンプルのinside/outsideも付ける。cycleFacesとhalfedgeFacesは元の巡回・半辺から領域への対応を保持する。

## 範囲と残る検証

これは共通原子と順序付き半辺に基づくsource UVの領域分類である。insideはパラメータのトリム領域への所属を意味し、空間材料の内部ではない。特に入力トリム領域が曲面の有効範囲内にあること、各面が空間に埋め込まれていること、空間面の向き・材料が成立することは別の検査が必要。

外周・穴、横断切断、代数的円による円盤/環状領域、穴を横切る複数切断、内部wire、トリムsenseの反転、未解決枝の伝播と所有を検査する。

target側の一般写像、重複と特異枝、暗黙regionの全境界、面の保存表現、空間への持上げと埋め込み、材料分類・共通Bodyへの採用は未完了。
