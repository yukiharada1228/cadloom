# NURBS材料の暗黙的な切断面領域

`nurbsPlaneDomain3` は、所有された横断断面の閉路認定から、切断面の平面座標系と材料所属の照会を作ります。座標系の原点は `−offset n / (n·n)`、独立な方向は `u = axis × n`、`v = n × u` です。したがって `u × v` は平面法線の正の倍数になります。平方根による正規化は不要で、全て有理数です。

`locateNurbsPlaneDomain3` は2Dの有理点または代数的な点をその平面上に厳密に写し、元の認定済み材料に所属照会します。領域は材料の閉集合と平面との共通部分です。空洞・材料島の役割は元の材料の包含認定に従い、閉路の弦や標本面積から推測しません。未解決の照会は未解決のまま返します。

`nurbsPlaneDomainEdgePoint3` は元の曲線辺のnative parameterを受け、元の暗黙的な有限面断面を評価して平面座標に写します。パラメータの向きは元の辺に従い、閉路での使用方向とは区別します。境界を折れ線に置換しません。複製された領域や認定は拒否します。

これは切断面の暗黙的な領域表現です。明示的な平面セルへの分割、閉路の包含木、キャップのBRep面化、元の面の分割、縫合された子Bodyの生成・認定は未実装です。既存の材料照会を再利用しているため、その未解決条件と計算量も引き継ぎます。

作業ツリーでビルドと関連テストのstrict型検査が成功し、断面閉路の既存4ケースと新規2ケースの計6テストが成功しました（8924.802334 ms、失敗・キャンセル・スキップ0）。新規ケースは重み付き円柱の内部・外部・境界、元の曲線端点の座標往復、座標系の向き、所有確認、空洞・材料島を横切る斜め断面の所属です。全リポジトリの検証や新規形式証明は主張しません。

独立したステージ済みスナップショット `/tmp/cadloom-planedomain214-staged` でビルド、関連3ファイルのstrict型検査と22テストが成功しました（17404.917458 ms、失敗・キャンセル・スキップ0）。無理数の円周点と座標往復、材料照会の探索回数上限での未解決保持も検査しています。247ソースのハッシュとステージ済みソース・テスト510ファイルの内容一致を確認しました。ハッシュは同一性の検査であり、正しさの証明ではありません。
