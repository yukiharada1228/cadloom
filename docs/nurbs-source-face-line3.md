# 認定有限NURBS面と直線・半直線の交差

`intersectNurbsSourceFaceLine3` と `intersectNurbsSourceFaceRay3` は所有された準備済み面複体、元の面ID、有理な直線を受け取ります。点だけの `discrete`、正の長さの重なりを持つ `overlap`、検査を完了できない `unresolved` を区別します。空集合は頂点0のdiscreteです。半直線は元点t=0を含み、t<0を除外します。

## 方程式と範囲

直線をO+tDとし、Dの非零成分iを選びます。S=P/Wに対しN=(P_i−O_i W)/D_iと置くと、直線所属は残りの二成分で P_k−O_k W−D_k N=0、パラメータはt=N/Wです。既存の厳密な二変数方程式ソルバーで孤立点と共通因子を分離します。

計算範囲は各パッチと埋め込み証明の長方形の交わりです。正のNURBS重みからW>0なので、半直線条件はN≥0と同値です。各候補で実際の有限面のUV所属、その面から近づけるパッチ側、全3D成分でO+tDとの一致を再確認します。反対側のパッチ像が同じUVに存在するだけでは受理しません。

共通因子は閉長方形で曲線グラフにします。元のトリム支持多項式、有限端点・臨界座標、既存SSI境界支持とUV頂点座標、半直線の原点イベントで全辺を分割します。これらの間では有限面所属と半直線条件が一定なので、厳密な内部点で区間を選択し、閉端点も再確認します。支持曲面内の直線であっても、有限面には角一点で接するだけ、または全く交わらない場合を区別します。

面内正則性検査と直線交差は同じ内部の有限面分割支持を使います。暗黙支持だけで有限境界や分枝を決める経路ではありません。

## 結果の意味

頂点はUVごとにまとめて直線パラメータ順に返します。重なり片はパッチと元のグラフ・ネイティブパラメータ区間を保持し、from/toでイベント頂点を参照します。追加の分割点や連続な継ぎ目の複数使用を保持するため、最小区間への統合や一意の区間分割を保証しません。

`nurbsSourceFaceLineOverlapPoint3` は所有された報告と区間内のネイティブパラメータを要求し、有限面・パッチ側・直線の全成分・半直線条件を再確認して評価します。その引数は直線のtとは限りません。

各点は、近づける全パッチ側について(du×dv)·Dの符号を保持します。零は接線方向を示しますが、偶数／奇数の接触次数や材料の横断回数を断定しません。C0折れ目では片側符号が異なる場合も保持します。これは面の交差集合であり、閉じた殻、面群の埋め込み、材料内外の判定ではありません。

## 回帰

横断・負のt・原点接触、二つの横断、偶数／奇数次接線、穴で分離した重なりと半直線制限、角だけの接触と空集合、非線形面の代数的UVとネイティブ区間、直線／曲線SSIで分割された面、不連続な継ぎ目、C0折れ目の両符号、所有・ID・範囲を検査します。曲線SSIでは余分な分割点を許しつつ、区間和集合と独立した円の不等式を照合します。
