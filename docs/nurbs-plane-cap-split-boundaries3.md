# 再切断用の有限キャップ境界ループ

`splitNurbsPlaneCapBoundaries3` は所有された有限キャップと次の有理切断平面から、負側・正側の閉じた有向境界ループを作ります。既存の辺は完全な平面イベントでネイティブパラメータを分割し、全開区間の符号に従って配分します。切断直線の有限面内区間を新しい辺として追加し、両側で同じ辺を逆向きに使用します。元キャップの向きに従い、切断直線の負側が左になるチャート方向から境界方向を導きます。

頂点は厳密な空間座標で統合し、各側の入次数・出次数がともに1のグラフから閉路を抽出します。穴を横断する切断は内周と外周をつなぎ直します。切断が穴を横切らなければ、穴の閉路をそのまま保持します。接点でゼロ長辺を生成しません。元辺の形状・区間と、新しい直線辺の代数的端点を保持し、`nurbsCapSplitBoundaryPoint3` は所有された辺と閉じたパラメータ範囲だけを評価します。

戻り値は所有されたループ構築結果です。ループの外周・穴への再グループ化や面・立体の認定ではありません。一般の接触で次数条件を満たさない境界はnonmanifold-boundary、全辺が切断平面へ含まれる場合はboundary-overlap、元面と同一平面はcoplanarとして明示的に未解決を返します。平行面と有限面を外れる切断は片側に元のループを保持します。所属判定の探索未解決も伝搬します。

次には新しい面領域の包含グループ化、分割済みNURBS元面の再分割、共有辺のnoding、縫合・埋込み・材料認定が必要です。再切断Body APIやSolidCraft全体の再実装の完成を意味しません。
