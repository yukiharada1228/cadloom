# 元面をまたぐNURBS分割面の縫合

`sewNurbsPlaneSplitFaces3` は、一つの所有された共有辺細分化と、全ての元の有限面に対する所有された分割面BRepを受けます。同じ元面の重複や別の細分化結果の混在は拒否し、未解決の面・欠けた元面は理由付きの未解決結果として保持します。

元の共有子辺ごとに、全ての局所面が使う厳密な区間端点を統合し、共通の細分化を作ります。局所面の区間がそろっていなくても、その子辺列へ各coedgeを展開します。元の共有子辺とその部分区間に基づいて同一化し、端点だけでは曲線を同一と判断しません。局所面の端点が共有曲線上の向きと一致すること、区間被覆も再検査します。

新しい内部切断辺は、元の局所面BRep内で同じ辺を使う分割面の間だけで共有します。別の元面から来た内部曲線は端点だけで統合しません。曲線は元の暗黙または有理曲線とnative intervalの参照を保持します。

`sourceEdges` は局所面の辺から共通子辺列への対応、`sourceFaces` は局所面から出力面への対応です。未選択の項目はnullです。`sharedFragments` は元の共有子辺から出力の細分化辺への対応をパラメータ順に保持します。`sewnNurbsPlaneSplitEdgePoint3` は所有された有限辺だけを厳密に評価します。

sideを省略すると全領域を縫合します。元の共有トポロジーが閉じた向き付き接続を持つ場合、その性質を失っていないことを再検査します。sideに+1または-1を指定すると、その符号の面だけを選びます。新しいキャップは作らず、開いた境界と既存の接続診断を保持します。共面の2D領域がある場合の片側選択は、材料側の所有判断がまだないため未解決として返します。

これは表面の接続であり、閉じた接続が得られても新たなグローバル埋込み・材料・子Bodyの認定を与えません。切断面の材料領域のグループ化、キャップの構築・縫合、子立体の認定と共通Body APIへの採用は引き続き必要です。
