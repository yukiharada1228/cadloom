# 代数的端点の線分と楕円の支持直線による交差

`intersectAlgebraicSegmentEllipse3` の一般経路は、端点から線分のパラメータを作り、楕円へ代入した代数的係数の二次式を解きます。異なる根の体で作られた端点では、実際の直線が有理数で定義できても、不要な体の合成と巨大なBigIntの多項式演算が生じます。

有理な支持直線を確認できる場合は、先に無限直線と楕円を有理係数で交差させ、有限区間で絞ります。候補は、実際の点ファクトリーのアフィン構築情報か、端点間で等しい有理の固定座標から得ます。情報の存在だけでは採用しません。非ゼロの直線方向に対して独立な二つの有理法線を作り、両端点が二つの支持平面上にあることを厳密に確認します。

二つの独立平面の共通部分はその直線です。異なる二端点がそこにあれば線分全体も同じ直線上にあるため、交点の有限範囲は方向の非ゼロ成分の一座標で判定できます。返却順は元の線分の始点から終点へ向かう順を保持します。方向の逆転で交点列も逆転します。支持を確認できない場合は従来の一般経路を使用します。

遅延の診断では、元の環状材料を含む回帰を継続したまま、同じ入力の診断用プロセスを固有のランダムInspectorポートで観測しました。スタックは `intersectAlgebraicSegmentEllipse3` の代数的な除算からSturm列・多項式GCD・BigInt剰余へ到達していました。診断用プロセスは観測終了後に終了し、元の検証ジョブは停止していません。

新版では元の上下端・内部／外部断面・未分割零点・環状材料・半空間の全ケースが通過しました。独立な端点の体、異なる原点と非単位方向、固定座標、逆向きと有限範囲、二端点が別の構築直線にある接線の回帰を追加しました。楕円交差・切断点・材料分類・境界選択を含む22件が6592 msで成功し、型検査と既存133宣言の限定監査も成功しています。元の長時間実行との速度比や、新しい形式証明を主張するものではありません。

低水準の交差計算の変更なので、新版の全体回帰に加え、斜交する第三円柱の重い式の2件も別途実行します。これらの完了までは全体成功と扱いません。
