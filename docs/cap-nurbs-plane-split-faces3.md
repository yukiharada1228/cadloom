# NURBS分割面への平面キャップの縫合

`capNurbsPlaneSplitFaces3` は所有されたキャップ包含証明から、外周とその直下の穴を一つの有限な平面BRep面として採用し、片側の分割面へ縫合します。材料の島や離れた成分は別のキャップ面になります。元の有限曲線オブジェクトとnative intervalをそのまま共有し、境界を弦や折れ線へ変換しません。

既存の面はkind:sourceの面参照として、追加した平面はkind:capの参照として保持します。キャップのチャート・領域・向きは所有された包含証明と境界証明から引き継ぎます。元の面のloop/coedgeを保ち、キャップのloopは既に反転された境界辺を使います。全曲線の面への包含は所有された有限境界の由来から継承し、有限個の点の一致から推測しません。

共通BRepエンジンで全接続を組み直し、全辺の向き付き接続・全頂点リンクが閉じたmanifoldになることを検査します。失敗した場合は診断付きtopologyを持つnonmanifold-incidenceの未解決結果です。成功時のkind:closedは閉じた接続の意味であり、新しい材料Bodyの認定ではありません。sourceEdges/sourceVertices/sourceFaces/capFacesは元の要素や領域グループから出力への対応です。切断境界が空の場合は、不要な面を生成しません。空の選択も空の閉じた接続として保持します。

`locateNurbsPlaneCapFace3` は所有された有限キャップのチャート点をinside/outside/boundaryに分類します。有理・独立した実代数的座標を受け、外周と穴の厳密な回転数を用います。穴の中の材料の島は別の面なので、外側のキャップの内部として採用しません。問い合わせの予算切れは未解決として伝搬します。

`nurbsPlaneCapFacePoint3` は有限な閉じた領域に属する点だけを元の平面チャートからXYZへ写します。外部はoutsideの位置結果、判定不能は未解決結果のまま返します。これによりキャップは境界だけの不透明な面ハンドルではなく、実際の有限領域問い合わせを持ちます。

新しい表面全体のグローバル埋込み、閉じたシェルの包含と材料方向の認定、領域ごとの子立体の採用、共通Body API・保存復元・再切断はまだ行いません。元の材料証明は由来として保持しますが、新しい立体の証明として流用しません。共面の元の2D面の片側所有判断は引き続き上流で未解決です。

独立したステージ内容のコピーでビルドと関連2ファイルのstrict型検査が成功し、関連19ファイル73テストが成功しました（失敗・キャンセル・スキップ0、56110.829208 ms）。264ソースのSHA-256と547個のsrc/testファイルもステージ内容と一致しました。この照合は同一性の確認であり、形式的な同値証明ではありません。
