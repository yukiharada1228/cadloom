# 切断平面による共有NURBS辺の細分化

`refineSewnNurbsSourceEdgesByPlane3` は所有された縫合済みの元BRepを受け取り、各共有辺を切断平面との全ての交点で分割します。同次曲線を `P/W` とすると、平面との交点は一変数多項式 `n·P + offset W` の零点です。元の有限区間内の全実根を厳密に分離し、符号が変わらない重根も分割点に含めます。恒等的に零の場合は元の全区間を共面として保持します。

分割は元のトポロジー辺につき一度だけ行います。各面のcoedgeはその同じ子辺列を使用し、逆方向の使用では列と向きをともに反転します。元の面・ループ・senseを保持したまま共通のBRep接続エンジンで再構築し、元の閉性・向きの整合性・頂点の多様体性が成立していた場合に、それが失われていないことを検査します。

各子辺には元の共有辺番号、元の有理曲線、厳密な区間、開区間で一定の平面符号、区間内の有理な標本パラメータを保持します。`sourceUses` は元の辺から子辺への対応です。子区間に零点がないことは全根の分離に基づき、標本だけで推測しません。正の同次重みも検査します。`nurbsSourcePlaneEdgeFragmentPoint3` は所有された子辺の閉区間を評価します。

この処理は既存の共有辺の細分化です。元の面の内部を切る交線の挿入、セル境界から元の共有辺への全パラメータ対応、キャップ面、子立体はまだ生成しません。入力も境界の縫合結果であり、グローバルな埋込みや材料の認定を新たに与えるものではありません。元の縫合で有理境界写像が未解決なら、この処理も受理しません。
