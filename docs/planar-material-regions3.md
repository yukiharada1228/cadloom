# 接触材料の領域解析

`planarMaterialRegions3(material)` は、所有された平面材料の開いた内部・空洞・外部を、支持平面の厳密な配置から解析します。非多様体の境界接触も受理し、幾何的な接触と開領域の連結性を区別します。

- 面を共有して一体化した二つの箱の内部は一成分。
- 辺・頂点だけで接触する二つの箱の内部は二成分。
- 別の橋でつながる材料は、局所的な辺接触があっても一成分。
- 辺・頂点だけで接触する二つの空洞の開いた内部は二成分。
- 貫通穴は外部につながり、閉じた空洞は独立した有界な空領域。

これは`topology.shells`を数えた結果ではありません。非多様体辺を共有する境界の接続成分と、開いた材料・空領域の成分数は一致しない場合があります。

```ts
const contact = booleanPlanarMaterials3(a, b, 'union');
const analysis = planarMaterialRegions3(contact);
const components = analysis.regions.filter(region => region.material);
const cavities = analysis.regions.filter(region => !region.material && region.bounded);
```

## 結果の契約

`regions[0]` は無界な外部で、`material:false, bounded:false, volume:null`。残る領域はすべて有界で、材料／空領域の区別、厳密な有理体積、厳密な内部点、配置セルID、境界使用IDを持ちます。空材料では外部だけが残ります。

`chambers` は支持平面に対する厳密な符号列、有理内部点、所属領域IDを持ちます。補助境界箱を含む平面の定義は `planes` に保存します。領域IDはこの解析内のIDで、Bodyレコードの領域IDとの一致や、異なる面分割間でのID安定性は保証しません。

`boundaryUses` は元の面ID、厳密に分割された凸多角形、材料側と空領域側のIDを持ちます。元面が複数の配置セルにまたがる場合には複数使用へ分割します。支持平面を越えない両側の有理点を使って対応を調べ、材料側と面の向きが矛盾すると内部エラーとして拒否します。有限領域の体積は向き付き境界から有理数で計算し、材料成分の体積和と元材料の体積の一致も検査します。

結果は凍結し、所有された入力ごとにキャッシュします。構造コピーには認定を与えません。保存復元後は、再構築された所有材料から再解析します。

## 配置と連結性の根拠

1. 全境界を厳密に囲み、各座標に正の余白を持つ有理境界箱を作る。
2. 物理的支持平面と箱の平面について、独立した三平面の全交点を列挙する。箱内の点だけを残す。箱で制限した各全次元セルの頂点は、この列挙に含まれる。
3. 平面の符号で点集合を分け、アフィン次元が三である集合だけをセルとして残す。全点の平均を使い、すべての平面に対する符号が厳密であることと、元材料の境界上でないことを検査する。
4. 他の全符号が同じで、一平面の符号だけが反対の二つの全次元セルは、その平面上の面を共有する。共通の他の開半空間は凸なので、両内部点を結ぶ線分の交点はその面の相対内部にある。同じ材料分類のセルだけを接続する。辺・頂点だけで接触するセルはこの隣接関係では直接結ばれない。
5. 箱の境界へ達するセルが、単一の外部成分になることを確認する。元材料は箱の境界から正の余白を持つため、この外部成分が無界な外部を代表する。

配置セル内に物理境界はありません。内部で接続する経路は配置面を越える接続へ分けられ、辺・頂点を通る経路でも開領域内で微小にずらせるため、同じ開領域のセルは面隣接で接続されます。ここでの根拠は幾何アルゴリズムの説明であり、新しいLean証明やTypeScript全体の機械検証を意味しません。

## 範囲と計算量

有理平面・直線辺の所有材料に限定します。一般曲面の領域分解、非多様体Bodyレコードの採用、接触領域を含む一般BRepの認定は未完了です。

三平面交点の列挙は平面数に対して三次で、配置そのものも多数のセルを生成します。元材料への正確な点分類、境界面の再分割、有理数の桁増大にも時間とメモリが必要です。大きなモデルの性能上限は未保証で、平面数で結果を打ち切ったり近似へ切り替えたりはしません。
