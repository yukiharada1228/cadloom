# 認定済みNURBS材料の境界断面の組立て

`intersectSewnNurbsSourceBoundaryPlane3` は所有された材料境界の認定と平面を受け取り、全有限面の断面を集約します。`intersectNurbsBodyBoundaryPlane3` は同じ照会をNURBS Bodyから実行します。面の交差が未解決なら、その面番号と報告を返し、部分的な成功結果は公開しません。

同じ空間点は三つの代数的座標の厳密な等値比較で統合します。座標の平均や許容誤差は使いません。各頂点には全ての元の面・有限面断面・UV頂点への参照を残します。辺は元の暗黙的曲線、有限パラメータ区間、片側パッチへの参照を保持し、直線の弦には置き換えません。共面領域は別の集合として元の有限面の所属制限とともに保持します。

端点と辺の接続から多重グラフの連結成分を求め、全頂点の次数が2の成分には全辺を一度ずつ通る組合せ的な閉路を記録します。`direction` は元の辺のnative parameterの増加方向に対する向きです。材料側や平面法線に合わせた向きではありません。点だけの接触や分岐では閉路を作りません。

共面領域、有限面の境界に沿う区間、パッチの継ぎ目に沿う区間、有限面のUV頂点での接触、非閉路成分を診断として残します。平面式のUV微分が両方零になる頂点や辺の標本点は、接線接触の証人として記録します。これは見つけた証人の報告であり、診断が空であることを完全な横断性の認定として扱いません。

連結成分と閉路は端点の接続グラフに対する情報です。重なる境界区間の内部の完全な節点化や共面領域の平面配置はまだ行っていません。例えば同じ空間の辺を二面が共有すると、多重グラフには二辺の閉路ができても、切断面の面積は認定されません。空洞・材料島の断面も閉路として分けますが、閉路の平面での内外や材料役割は推測しません。

`nurbsBoundaryPlaneEdgePoint3` は所有された組立て結果から元の有限辺を評価します。Bodyの保存復元や相似変換の後でも、そのBodyが所有する認定済み材料を使います。切断面の材料選択・向き付け・追加境界の縫合・閉じた子Bodyの認定は、引き続き別の処理として必要です。
