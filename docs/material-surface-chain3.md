# 直接構築したBodyの連続演算

`booleanCylinderMaterialPrograms3` は、所有された二つの材料プログラムの円柱・平面配列と論理式を合成します。第二オペランドの参照番号を対応する配列へ移し、局所の切断条件を式の内部に保持します。幾何的に同じという推測で入力を統合しません。`clipCylinderMaterialProgram3` は向き付き半空間を追加し、式との積を作ります。いずれも境界は構築せず、新しい所有された不変の定義を返します。

`booleanCylinderBodies3` と `booleanMixedBodies3` は、入力に新しい材料境界Bodyが含まれると、その定義を取り出して合成し、新パイプラインで境界・領域解析・Body採用を行います。既存の円柱・材料Bodyは所有されたバックエンドから定義を取得します。箱・対応する平面や押し出しは既存の変換器の受理範囲で共通入口へ接続します。未対応の曲面や一般輸入B-repを自動変換するものではありません。

`clipCylinderExpressionBody3` も新しいBodyの定義へ直接半空間を追加します。結果の保存復元は `surface-material-expression` の再構築を使うため、その結果を再び演算へ渡せます。新しいBodyが含まれない既存の入力対は、従来の演算と保存形式を使います。

円柱専用の入口では従来どおり箱・平面Bodyを拒否し、それらは共通入口を使います。結果の多様体接続・有限面の結合・材料領域の検査を省略せず、非多様体の結果はBodyへ採用しません。
