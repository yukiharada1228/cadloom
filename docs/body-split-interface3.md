# 共通切断の有限界面とcoedge対応

`bodySplitInterface3(split)` は、所有された `splitBodyByPlane3` の結果から、新しい切断界面の両側の面群と共通の有限曲線表を作ります。必要時だけ計算して不変の結果を再利用します。コピーした切断オブジェクトは受理しません。

```ts
const split = splitBodyByPlane3(body, plane3(1n, 0n, 1n));
const section = bodySplitInterface3(split);
const map = section.negativeCoedges[0];
// map.uses は section.atoms への辺使用。元coedgeの巡回順です。
```

## 面群の選択

平面経路は既存の `planar.shared` の実際の面IDを使います。曲面経路は、切断平面上にあり、親材料の内部にある新しい面セルを選びます。既存の材料境界生成はすべての元支持形状で面を分割するため、元材料の所属は各セルの相対内部で一定です。その前提で厳密な内点の所属を使ってセルを選択します。任意の輸入BRepや単なる支持面一致へこの推論を適用しません。

既存の空洞壁が切断平面と一致すると、その壁は親材料の境界なので新しい界面へ加えません。選択した負側・正側の面は、入力平面に対してそれぞれ逆の物理法線を持つことを検査します。

## 共通の有限曲線表

`negativeFaces`・`positiveFaces` は実際の子の面IDです。面分割は異なってもよく、面同士の一対一対応を要求しません。

各面の実際のcoedge巡回を取り出し、両側の全境界端点で曲線を分割してsewingします。既存sewingの全支持形状の照合と有限区間の照合を使い、端点だけの一致で異なる楕円弧などを共有しません。`atoms` は共有された有限曲線片の表です。異なる内部の分割線同士のすべての内部交差を追加する平面アレンジメントではありません。

`negativeCoedges`・`positiveCoedges` の各行は、実際の `face`・`loop`・`coedge`・`edge` IDと、そのcoedgeの始点から終点までを巡回順に覆う `uses` を持ちます。`uses[].edge` は `atoms` の番号、`direction` は共通曲線の向きです。各atomにも両側の実際のcoedge使用と向きを保持します。

atomごとに両側の向きの総和を調べ、一方の総和が他方の逆で、大きさが1以下であることを検査します。`boundary:true` は界面の外周または穴の輪郭です。`boundary:false` は各側の内部で打ち消される面の分割線で、片側だけに存在する場合もあります。

各側が同じ平面の有界で内部が重ならない有効な面セル群で、物理的な向きが揃う前提のもと、向き付き境界の一致は面群の巻き数の一致を与えます。平面の無限遠では両方の巻き数が0なので、両側の有限領域は同じです。この検査は元のBodyの幾何認定を利用し、任意の面群の幾何認定を新たに作るものではありません。

## 位置照会と範囲

`locate(point)` は共通切断領域に対する `inside`・`boundary`・`outside` です。穴の中と切断平面外は `outside`。内部の面分割線は、親材料の所属も使うことで `inside` とします。単に両子の物理境界全体の積を返すものではなく、接するだけの元境界は界面へ加えません。界面がなければ空の表と `outside` を返します。

親面・辺の由来、面群間の全面積オーバーレイ、連結成分番号、永続名、メタデータ保存復元、一般NURBSの切断、一般曲面の接触CellularBodyは未提供です。TypeScript全体の形式証明ではなく、時間・メモリの固定上限も保証しません。
