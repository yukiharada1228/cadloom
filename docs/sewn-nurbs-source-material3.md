# 縫合NURBS材料境界の向き

`certifySewnNurbsSourceMaterial3` は所有された包含木を受け取り、各閉殻の実際の向きを検査します。大域的埋め込み、閉じた向き付き多様体接続、殻の包含関係は前段の認定を引き継ぎます。

正の重みを持つNURBSの凸包性から、全ての元制御点よりx座標の小さい有理点は全ての殻の外側です。その点から対象の殻へ半直線を送り、厳密に横断する非退化な交差が得られる方向を探索します。既知の面の標本点へ向かう方向と、その近傍へ向かう有理方向を優先し、その後は全有理方向の整数代表を列挙します。近傍の値は探索候補であり、形状や所属判定を変更する許容誤差ではありません。

交差がゼロの半直線や退化した半直線では向きを決めず、別方向を試します。有限予算内に横断が得られなければ未解決です。外部からの交差数が偶数で、法線符号が入る／出るごとに交互になることも検査します。最初の交差の符号が負なら外向き、正なら内向きです。これは、連結した埋め込み閉殻に一貫した向きが既にあることを前提にしています。

最初の二つの交点パラメータの代数的隔離区間を精密化し、その間の有理数を選びます。半直線の原点・方向も有理数なので、殻の厳密な内点が得られます。この点は子の殻の外にあるとは限りません。材料所属の代表点として無条件には使えません。

包含深さが偶数なら外向き、奇数なら内向きであることを全殻で確認した場合だけ `certified` を返します。空洞の向きが反対の場合や、外殻全体が裏返っている場合は `orientation-mismatch` と該当殻を返し、入力を自動反転しません。幾何演算の未解決、予算切れ、交差の不整合は `unresolved` です。

これは有界な材料の境界モデルの認定です。共通Bodyへの統合、任意の代数的点の材料所属、材料の集合演算、体積計算はこのAPIでは実装していません。Lean形式証明も追加していません。
