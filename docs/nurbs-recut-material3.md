# 再切断材料の実際の向きと厳密サンプル

`certifyNurbsRecutMaterial3` は、所有された再切断殻の包含証明書から、実際の向きと材料領域の厳密なサンプルを検査します。depthから得たexpectedOrientationをコピーして成功にする処理ではありません。

## 材料点の所属

`locateNurbsRecutMaterial3` は所有された埋め込み認定と、有理数または独立した代数的座標を受け付けます。元の材料を、以前と今回の所有された二つの選択半空間で正則化して切り取った材料への所属を返します。

実際の点で両平面の符号を厳密に計算し、明らかな反対側はoutsideです。残存source面・旧キャップ・新キャップの有限面を先に調べ、実際の境界にある点だけをboundaryとします。これにより、切断で捨てた接線的な点・線を元の境界から継承しません。

境界でなければ元の認定済み材料を照会し、半空間の符号と組み合わせます。代数的点に対する元材料の有理enclosure witnessは元材料の所属の証拠だけです。切断符号は元witnessの位置でなく、要求された元の厳密点で判定します。平面上のinside点なのに対応する有限キャップが見つからない場合や、strictな選択領域の元境界が残存面に見つからない場合は、未解決にします。

## 実際の向き

正の重みを持つ元NURBSの全制御点のx下限より厳密に小さい位置を、全境界の外部witnessとして使用します。新しい有限平面キャップの座標の極値も境界にあるため、同じ下限は全キャップを含む新しい殻の外側です。

そこから各新しい殻へのregularな半直線を探し、横断交差が偶数個で方向付き法線符号が交互になることを確認します。最初の符号から実際の外向き／内向きを求め、新しい包含depthの期待値と比較します。ゼロや不定の法線、未解決の照会、予算切れは認定しません。

## 材料領域のサンプル

偶数depthの殻ごとに、同じ半直線を全ての新境界へ問い合わせます。その殻の入口から次の全境界ヒットまでの開いたギャップ内に、厳密な有理パラメータを選びます。殻単体の入口と出口の中点は空洞内になり得るため使いません。

その点が二つの切断を反映した材料にinsideであることを確認し、全ての新しい殻へ偶奇照会します。含む殻が自分と全祖先だけであることを検査してから、材料regionと直下の空洞を保持します。方向のinteriorWitnessは幾何的な殻の内部点であり、材料領域の厳密sampleとは区別します。

成功時だけ所有された `NurbsRecutMaterialCertificate3` を返します。これは現在の構築経路についての材料認定であり、共通Bodyへの採用、保存・復元、任意回数の切断や一般曲面Boolean、全TypeScriptの形式検証はまだ含みません。

## 固定回帰

箱の343点を独立した閉半空間の不等式と比較します。閉じた空洞と島の実際の向き（+1/-1/+1）、開いた空洞と独立した島、代数的円柱点、捨てた接線の正則化、空材料、方向予算切れ、反転した法線と両半体、非線形nativeパラメータを検査します。
