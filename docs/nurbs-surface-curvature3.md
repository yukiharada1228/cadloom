# NURBS曲面の二階微分と曲率

`secondDifferentialNurbsSurface3(surface, u, v, sides?)` は、既存の一階微分・非単位法線・正則性に加えて、`duu`・`duv`・`dvv` を正確な代数的実数の座標で返します。入力は既存の所有されたNURBS曲面、または再検査・スナップショットする構造入力です。節点側のオプションは呼出時に一度読み取り、同じパッチで全微分を計算します。

`curvatureNurbsSurface3` はその微分から、ガウス曲率 `gaussian`、向き付き平均曲率 `mean`、昇順の主曲率 `principal` を返します。

```ts
const c = curvatureNurbsSurface3(surface, '1/2', '1/3');
if (c.regular) {
  const gaussianSign = c.gaussian.sign();
  const [minimum, maximum] = c.principal;
}
```

## 厳密な計算

パッチの各成分を `S=N/W` とし、a・bをuまたはvとすると、二階微分は次の有理式です。

`S_ab = (N_ab W² - N_a W W_b - N_b W W_a - N W W_ab + 2 N W_a W_b) / W³`

分子・分母は有理係数の二変数多項式として構築し、既存の厳密な代数的実数への像で評価します。有限差分や浮動小数のεを使いません。正の重みを持つ受理されたNURBSの有効パラメータ範囲ではWは正です。

`n = S_u × S_v`、`D=n·n`、`E=S_u·S_u`、`F=S_u·S_v`、`G=S_v·S_v` とし、`L=n·S_uu`、`M=n·S_uv`、`N₂=n·S_vv` とします。正則点では次を計算します。

- `K=(L N₂ - M²)/D²`
- `H=(E N₂ - 2 F M + G L)/(2 D sqrt(D))`
- `k_min=H-sqrt(H²-K)`、`k_max=H+sqrt(H²-K)`

平方根も代数的実数です。丸めた近似値や、その近似値から戻した結果ではありません。平均・主曲率の向きはパラメータの `du × dv` に依存し、Bodyの外向きとは限りません。片方のパラメータ方向を反転するとHは反転し、主曲率は符号を反転して順序を交換します。Kは不変です。

## 節点と特異点

`uSide`・`vSide` は既存の一階微分と同じ左右規則です。節点での二階微分・曲率は選んだ側のパッチの値で、節点をまたぐC2連続性は宣言しません。有効範囲外や不正な入力は既存の検査で拒否します。

`du × dv = 0` の場合、二階微分自体は返しますが、曲率の結果は `{regular:false, differential}` で、曲率の値を含みません。ゼロ法線を正規化したりゼロ除算を近似で回避したりはしません。

## 範囲

これは曲面の局所的な幾何照会であり、NURBS曲面の交差曲線の列挙・位相接続、トリム領域の内外判定、NURBS Bodyの採用、フィレット、特異点近傍全体の解析を実装するものではありません。任意次数・代数的入力での実用時間やメモリの上限も未保証です。
