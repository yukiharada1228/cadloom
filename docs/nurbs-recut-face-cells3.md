# 既存の有限NURBS面の再分割

`partitionNurbsSplitFaceByPlane3` は所有された分割済みNURBS面を次の有理平面で分割します。元の曲面全体へ戻して前回捨てた領域を再採用しないよう、以前の全切断平面の零点集合を新しいUV配置へ含め、元の有限領域に属する開領域だけを採用します。同じ符号でも離れた別の連結成分は採用しません。

平面セル分割には`planes`（全祖先と今回の平面）と`restriction`（制限元の所有された有限面）を保持します。通常の初回分割はrestriction:null、planes:[plane]です。再分割でも今回のplaneとセルsignは新しい平面についての符号であり、過去の配置による境界を消しません。正の重みと全境界零点配置の下で開セルは以前の領域境界を横断せず、既存の厳密なUV有限領域判定でセルを選べます。

開セルの評価は制限元の内部、閉セルの頂点・辺の評価は制限元の閉領域への所属も検査します。既存の閉セル境界、パッチ間noding、等符号領域のseam除去を共用でき、対応する元共有辺の照合・分割面B-rep採用へ進められます。採用後の面を再入力すると全祖先平面が継承されるため、三度目以降にも以前の制限を保持します。

これは元面の有限領域再分割です。前の切断でできた曲線とキャップとの全区間対応・共有辺noding、全形状の再縫合、新しい埋込み・材料認定と再切断Body APIは残ります。全立体の再切断完成やSolidCraft全体の互換性を主張しません。
