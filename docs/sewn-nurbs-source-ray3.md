# 縫合NURBS面群の半直線交差と殻の交差偶奇

`intersectSewnNurbsSourceRay3` / `intersectSewnNurbsSourceLine3` は所有された縫合結果から各有限面の厳密交差を集約します。shellを指定すればその面だけを調べ、省略すれば全ての面を調べます。未解決の縫合または面交差は未解決として伝播します。

各イベントを直線パラメータでまとめ、全3D点の一致を確認してから、元の面ID・UV・層・パッチ側を保持します。イベントはt順です。法線の符号はsourceのUV正向きだけでなく、縫合した面のsenseを掛けて返します。重なり区間は元の面交差報告への参照を保持するため、既存の有限区間評価を利用できます。その元報告の法線はsource UV向きであり、集約したhitの法線は縫合面の向きです。

## regularとdegenerate

正の長さの重なり、同じtでの複数面、UV辺・頂点上のイベント、複数パッチ側、直線方向に対する零法線符号、t=0を退化として列挙します。regularは、これらがなく、各イベントが一つの開いた面・一つのパッチ側で厳密に横断する場合だけです。複数パッチでも滑らかな場合を認定する拡張はまだ行わず、再試行を要求します。

接線の偶数／奇数次数を第一微分から推測しません。辺や頂点の使用を任意に片側へ割り当てる規則も使いません。

## 殻ごとの照会

`querySewnNurbsSourceShellParity3` は閉じた向き付き局所多様体の接続を持つshellだけを受理します。まず指定したshellの全有限面へ空間点の逆照会を行い、いずれかの面上なら `on-face` とその面番号を返します。この所属も支持面への投影だけでは決めません。

それ以外では、指定した有理方向（既定は+x）への半直線を使います。退化した半直線は `retry`、未解決は `unresolved` です。regularな場合だけ、横断数、odd/even、向き付き法線符号の和 `orientedSum` を返します。原点は全対象面外であり、以降の各イベントは厳密に横断するので、一イベントが一回の交差として数えられます。

この結果は交差偶奇です。面群の大域的埋め込みや自己交差除去、shell包含、空洞／材料の役割、共通Bodyへの採用を認定しません。特に、複数shellのoddをそのまま一つの材料所属へ変換しません。全体の向きを反転するとorientedSumは反転しますが、odd/evenは変わりません。自己交差がない立体であることの証明とは区別します。

## 回帰

非線形パラメータ立方体の64点を独立した箱の不等式・横断数と照合します。直線と半直線の順序、向き反転と異なる方向、辺・頂点・面上重なり・原点での再試行、面・辺・角の厳密所属、接線とC0折れ目、入れ子shellの対象制限、所有・shell番号・零方向・未解決伝播を検査します。

さらに上面を z=1+u(1−u)v(1−v) とした曲がった閉殻を使い、代数的な半直線交点と法線符号を確認し、15点で多項式の高さの独立不等式と偶奇を照合します。平面の立方体専用の処理ではありません。
