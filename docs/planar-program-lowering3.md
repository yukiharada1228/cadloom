# 平面材料を境界構築前の定義へ変換

`preparePlanarMaterialProgram3(source)` は、所有された厳密な有理平面ソリッドを `CylinderMaterialProgram3` へ変換します。材料境界の分割・選択・縫合を先に実行する必要はありません。

凸材料は実際の支持半空間と厳密に外側の有限ガード円柱へ変換します。凹材料、内部空洞、複数成分、空材料は既存の物理支持平面によるchamberコンパイラーを使い、結果の材料式を所有された不変プログラムとして検査・保持します。従来の内部cone分解や保存された面を幾何の根拠に代用しません。

共通の `booleanMaterialBodies3` は、所有された平面Bodyと全ての面が平面である直線押し出しBodyをこの経路へ渡します。押し出しでは実際の境界を有理平面ソリッドとして検査してから変換します。寸法や構築ラベルだけを信頼することはありません。

旧 `boundaryPlanarMaterial3` と凸境界入口は同じ定義生成処理を呼んだ後に旧境界を構築します。旧構築種別の面数や順序、保存復元経路を新方式へ黙って変えません。円弧を含む押し出しや一般の曲面変換を完成したという意味ではありません。
