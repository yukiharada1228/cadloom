# 全キャップ分割の親辺区間を正準化して縫合

`sewNurbsRecutCapFaces3` は所有された二回切断後の閉境界・次の切断平面・全旧／新キャップの両側分割面を受け取り、キャップ部分複体を組み立てます。各親cap faceはちょうど一度必要です。異なる親、欠け・重複、片側だけの分割、異なる切断平面は受け付けません。

各子境界辺が最終親B-repの同じ所有されたcurveを参照し、元coedgeとfaceへ対応することを検査します。さらに各親coedgeの子区間をnative昇順に並べ、親辺のlowerからupperまで隙間・重複なく覆うことを確認します。端点が同じだけの異なるcurveを共有にはしません。

同じ親edgeの全区間端点を集めて正準分割を作り、旧キャップ側と新キャップ側が同じ子edgeを使うようにcoedgeを置換します。負方向のcoedgeでは子配列の順序と各方向を両方反転します。親の全区間対応が根拠であり、代表点の一致を曲線全体の一致へ読み替えません。各cap内の新しいcut辺も、その両側の面が同じedgeを逆向きに使います。

共通曲線は `NurbsRecutCapAssemblyCurve3` として親閉境界のedge番号・native区間、または所有された子capのcut辺へ対応します。`sourceEdges` / `sourceVertices` / `sourceFaces` は各入力表から組立後の表へ対応し、`sharedFragments` は各親edgeの昇順の正準片を返します。親edgeにcap使用が一つだけの場合、その片はNURBS source面との後続縫合を待つ外周です。

面のsurface object・向き・穴は保持します。等価な切断平面の正／負スケールを厳密に照合し、`faceSigns` は指定した共通平面に対する符号へ揃えます。各正準片のcoedge数は元のcap使用数に一致し、全体の辺向きも整合することを検査します。

これはcap部分複体です。元の閉境界からNURBS source面を除くため、外周や部分的な頂点fanが残る場合があります。診断を含むB-rep接続表を返し、頂点fanの閉鎖・立体の閉接続・材料を認定しません。空のcap集合にも対応します。

検証では、旧・新キャップの共通辺を横断する切断、斜め切断、入力順反転、切断平面の反転とスケール、既存共有辺全体の接触、孤立接触、円弧の代数的端点、空洞と独立した島、負側の親、反射とスケール、空のcap集合、全coedge置換と親native全区間被覆を確認します。

次は残存NURBS面を再分割し、その辺をこの親区間表へ対応・nodingして縫合する必要があります。三回目以降の閉立体切断、全境界の新しい埋め込み・殻包含・材料認定、任意回数の保存record、一般NURBS Boolean、SolidCraft全体の純粋TypeScript再実装は引き続き未完了です。
