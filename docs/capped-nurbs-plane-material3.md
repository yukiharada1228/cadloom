# キャップ付きNURBS材料の向きと内部サンプル

`certifyCappedNurbsPlaneMaterial3` は所有された新シェル包含証明を受け、実際の向きと材料領域の内部点を検証します。包含の深さから得たexpectedOrientationだけを正しい向きとして採用しません。

元の正の重み付きNURBS制御点は全ての保持面を包み、有限な平面キャップの線形座標の極値もその境界にあります。そのため全ての元制御点のxより小さな点を、新しい全シェルの外部として使えます。各シェルの境界サンプル付近へ向かう厳密な有理方向を試し、正則なレイ交差が偶数個で、向き付き法線の符号が入口・出口ごとに交互になることを検査します。最初の交差から実際のorientationを求め、包含の深さが要求する向きと照合します。不一致はorientation-mismatchとして保持し、材料証明を発行しません。

orientationsのinteriorWitnessは幾何学的なシェル内部の点です。子の空洞に入る可能性があるため、その点を材料の内部点として流用しません。偶数の深さの領域では、同じレイを全ての新しい境界面へ交差させ、その領域への入口から次の全境界交差までの間に厳密な有理パラメータを取ります。自分のシェルの出口より手前に空洞への入口があれば、その手前でサンプルします。

そのサンプルについて、キャップ付き材料の位置判定がinsideであること、全ての新シェルへの独立した奇偶判定が期待される包含集合と一致することを検査します。領域のshell、新しい直下のcavities、内部sample、containingShells、全境界レイとentry/sampleParameterの由来を保持します。材料の島は別の偶数深さの領域です。切断で穴が外部へ開いた場合も、元の深さやシェルIDを再利用しません。

正則レイを予算内に発見できない場合、交差列が矛盾する場合、サンプルの位置判定が未解決または不適切な場合は、理由付きの未解決結果を返します。空の材料は向き・領域・サンプルをいずれも空として認定します。入力のコピーや偽の証明オブジェクトは拒否します。

この証明は既存の十分条件の横断的な埋込み証明を前提とします。一般の退化切断、共通Body APIへの子立体採用、保存復元、再切断は引き続き未完成です。新しいLean証明やTypeScript実行全体の形式検証は追加していません。

レイの元データが持つ正確なUV座標は、同じ元の有限面・座標系であることを検査して分割領域へ直接問い合わせます。保持されたヒットのXYZも一致検査します。既知の座標をXYZから再び逆算する必要はありません。公開のUV問い合わせも元の有限面を評価してから閉じた分割領域を調べ、単にUVの矩形だけで受理しません。

二次fiberの非有理な平方根を含む解は、分子・根号・分母の共通係数パラメータを保つ既存のquadraticImageで構成します。独立な代数的値として計算して消去次数を掛け合わせることを避けます。正負の枝と実根の選択は厳密なままです。独立に導いた6次の消去式と逆代入を、3次の係数パラメータを持つ回帰ケースで検査します。
