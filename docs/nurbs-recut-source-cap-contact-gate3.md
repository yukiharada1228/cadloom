# 残存NURBS面と新キャップの限定された接触認定

`analyzeNurbsRecutSourceCapVertices3` は、これまでの全ゼロ辺の区間解析に加え、元の完全なゼロ集合の全頂点、source nodingで追加された平面上の全頂点、最終B-repの平面上の全頂点を検査します。曲線の端点や、開区間に残存セルがない辺の端点も対象です。空間点が等しい記録をまとめ、全ての入力・元頂点・追加頂点・最終位相頂点の由来を保持します。

既知のUVがある入力にはその由来で有限面所属を照会し、他の残存NURBS面には空間点の逆照会を実施します。位相的にincidentでないことだけで幾何的な所属を除外しません。有限面から外れた点は捨て、未解決の逆照会やキャップ照会を成功へ読み替えません。

## 宣言済み接続と接触証拠

各残存面と新キャップの組について、キャップ外部・宣言済み共有頂点・宣言済み共有辺・キャップ内部への接触・未宣言の境界接触を区別します。共有頂点は両面が同じ位相頂点を使うことを確認します。共有辺の途中にある点は、同じ位相辺を両面が使い、点がその有限曲線に厳密に所属することを確認します。座標一致だけで別の辺を溶接しません。

内部の点所属処理は、各XYZ座標の完全な平面ゼロ集合を交差させます。孤立パラメータだけでなく閉じた重なり区間を保持し、他座標でさらに制限します。代数的な共役候補は既存の選択根付き平面イベントで除外します。

## 限定された認定ゲート

`certifyNurbsRecutSourceCapContacts3` は全頂点の検査と全開区間の分類を組み合わせます。キャップ内部や未宣言の境界接触があれば、厳密な点と元面・キャップ面を持つ `contact` を返します。判定できない場合は `unresolved` です。成功時の所有された証明書は次のscopeを持ちます。

`retained-nurbs-source-to-new-caps`

認定するのは、この組の間の接触が宣言済みの共有頂点・共有辺に限られることです。接触そのものが存在しないという意味ではありません。元の平面ゼロ層は完全な有限配置から得られ、孤立点・全開ゼロ辺・全端点と追加分割点を被覆します。同一平面の二次元source領域は前段で未解決のままです。

旧平面キャップと新キャップの接触、立体全体の幾何的埋め込み、向き・包含・材料、共通Bodyへの再採用は、この証明書では認定しません。新規Lean証明やTypeScript全体の形式検証でもありません。
