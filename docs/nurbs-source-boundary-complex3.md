# 元面UVの境界・交差辺の共通原子

`buildNurbsSourceBoundaryComplex3(refined)`は、sourceトリム境界と細分交差グラフを共通のUV頂点・辺へ接続する。所有された細分グラフを要求し、元の空間像や片側微分は元グラフに保持する。

境界と交差辺の全区間一致は`matchNurbsIntersectionSourceBoundary3`の恒等式・選択枝・有限範囲の検査を使う。一致区間の両端で両方を分割し、共通の辺を作る。境界のノット・射影臨界点も、選択された交差枝上にあれば交差辺を分割する。辺の端点が一致するだけでは共有化しない。証明済みの共有区間なのに共通原子が見つからなければ失敗する。

各共通辺は境界からの`boundaryUses`と交差辺からの`intersectionUses`を持つ。ここでのuse.edgeはそれぞれ元の境界辺・細分交差辺のIDであり、lower/upperはその元辺の増加パラメータ範囲。directionは共通辺に対する元辺の進行方向である。逆に`boundaryEdges`と`intersectionEdges`のuse.edgeは共通辺IDで、元辺を覆う順序付きの対応を返す。

共通辺の標準方向は最初の境界使用方向を使い、境界と共有しない交差辺は増加パラメータ方向を使う。外周・穴の`rings`は共通辺とdirectionへ展開し、閉接続を再検査する。

頂点の同一視はsource UVで行う。これはパラメータ配置の接続であり、不連続な空間像の一致を主張しない。同じUVに対応する細分グラフの全頂点IDを`intersectionVertices`へ残す。空間像の正しさや法線を必要とする処理は元グラフの各useを参照する。グラフ同士の全重複、全体の平面埋め込み、分岐点での循環順序をこの段階で認定しない。

新規テストは正逆の境界共有、有限な部分一致、内部を横断する交差辺と境界の接続、曲線境界のノット・射影臨界点を検査する。元辺の完全被覆、隣接する子辺の接続、閉ring、由来、所有も確認する。

次は分岐の枝順序、共通辺の両側の半辺、閉ループと穴の割当てを実装する必要がある。target側の一般写像、特異枝、重なりregionの境界、面の埋め込み・材料分類と共通Bodyへの採用は未完了。
