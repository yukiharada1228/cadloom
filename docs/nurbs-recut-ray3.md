# 再切断B-repの直線・半直線と殻の偶奇

`intersectNurbsRecutLine3` / `intersectNurbsRecutRay3` は所有された再切断境界の埋め込み認定を受け取り、残存NURBS有限面・旧キャップ・新キャップの交差を最終面番号と殻番号へ集約します。直線は負のパラメータも保持し、半直線は原点以降を対象にします。

## 残存面への完全な制限

NURBS側は、実際に対象殻に残る元面だけを問い合わせます。同じ元面から分かれた有限面は元UVの交差結果を共有し、各子領域への所属を照会してからヒット・退化を採用します。UVの元面フレームと空間像の一致も確認します。捨てた領域の境界ヒットは残存境界の退化へ読み替えません。

元面との直線重なりは、元の有限トリム・パッチのイベントに加え、祖先と現在の全切断平面が直線を横切るパラメータと、直線上にある全source noding頂点で分割します。直線全体が切断平面上にある場合も、配置の分岐点・連結成分の切替点を後者で被覆します。連続かつ単射な元の重なり枝は直線上の区間へ写り、完全な有限配置で分けられた開区間では子領域所属が一定です。各開区間と全端点を照会し、残る閉区間と孤立した端点を `overlaps` に保持します。領域から消えた元の重なりは退化として報告しません。

旧・新キャップはそれぞれの有理支持平面と直線の厳密交点を有限領域へ制限します。面のsenseと支持面の向きから方向付き法線符号を返し、元NURBS面の符号も最終面のsenseで方向付けます。

## regularと退化の区別

`regular` では、全境界交差が一意な有限面内部の横断交差としてパラメータ順に得られます。境界・頂点、多重面、原点ヒット、接線、複数パッチ法線、残存source重なり、キャップ支持面上の直線は `degenerate` と理由を返します。キャップ支持面上の直線では保守的に再試行を要求し、有限キャップとの重なり区間の完全列挙をこのAPIで主張しません。未解決の面照会は `unresolved` です。退化の離散hitsを完全な横断列として数えません。

`queryNurbsRecutShellParity3` は、最初に対象殻の全有限面への原点所属を検査し、境界なら `on-face` を返します。regularな半直線だけからodd/even・交差数・方向付き和を計算します。`queryNurbsRecutShellParityAuto3` は退化方向を厳密な有理方向の列で再試行し、予算切れをevenへ変換しません。

方向探索の `maxDirections` と有限キャップ巻き数照会の `maxFaceDirections` は別の予算です。これらの偶奇は幾何的な殻の内部であり、材料の向き・殻包含・空洞の役割をまだ認定しません。
