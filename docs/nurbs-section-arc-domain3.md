# 有限NURBS交差枝のトリム領域による分割

`partitionNurbsSectionArcByDomain3(arc, domain)` は、所有された有限交差枝を、検査済みのNURBSパラメータ領域の内側・境界・外側へ完全に分割します。外周1つと、互いに接触・交差・入れ子にならない穴を持つ既存の領域を使います。

```ts
const partition = partitionNurbsSectionArcByDomain3(arc, domain);
const retainedArcs = partition.pieces.filter(p => p.location !== 'outside');
const contacts = partition.vertices.filter(v => v.location === 'boundary');
```

入力domainの `outer`・`holes`・`sense` から幾何を再検査し、独自の `locate` や `sample` を信用しません。結果のdomainはこの独立した不変のスナップショットです。arcの所有チェックは領域の処理より先に行います。

## 全境界イベントの計算

各トリム境界の有理NURBS spanを `(U(t)/W(t),V(t)/W(t))` とし、元のパッチの平面交差多項式Fへ代入します。正の重みの分母を払った一変数多項式を厳密に構成し、その全実根を境界spanの閉範囲で絞ります。求めた(u,v)を元のグラフ辺の評価と正確に照合し、対象の枝と有限区間にあるものだけを使います。空間点の一致や折れ線近似でイベントを決めません。

代入多項式が恒等的にゼロなら、その境界spanは平面交差の零点集合上にあります。spanの両端点を切断候補にします。元のarcは投影イベントをまたがない単一グラフ辺であり、境界は検査された単純曲線なので、同じ開枝上の境界区間の出入りはこれらの端点または元のグラフイベント端点で捉えられます。元arcの両端点も常に保持します。境界と重なる区間を、孤立した交点列へ置き換えません。

全イベントで分けた後の開区間には、未処理の境界との交点や重なりの端がありません。その前提で正確な中間点を領域照会し、各片の `inside`・`boundary`・`outside` を分類します。一般の未分割曲線について、代表点だけで領域所属を推測する処理ではありません。

## 出力と閉端点

`source` は元arc、`domain` は再検査した領域です。

- `pieces` は正の幅の全断片を元の巡回順で返します。`arc` は元のsection・piece・edge・座標と方向を保ち、`location` は相対的な開内部の分類です。
- `vertices` は両端と全イベントを巡回順で返し、元の `parameter`、正確な(u,v)、空間point、閉点としての `location` を保持します。

全ての開片が外側でも、孤立した境界接触はverticesへ残ります。閉じたトリム領域との交差を取り出す場合、片だけをフィルターして孤立した接点を捨てないよう、verticesも扱います。穴の内部は外側ですが、穴の境界は閉じた面領域の境界として保持します。反転arcは出力の順序を反転し、u/v座標自体は変えません。

## 範囲

領域はパラメータ空間のものです。異なるパラメータが同じ空間点へ写っても所属は別々に判定します。曲面像の自己重複・埋め込み、NURBS BRepの辺や面への採用、Body全体の切断、二次元の平面含有パッチのトリムは認定しません。トリム領域の全境界が元曲面の有効範囲内にあるとの面認定も行わず、この有効arcとの部分集合の交差だけを計算します。時間・メモリの固定上限は未保証です。
