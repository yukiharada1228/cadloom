# 曲面セルの材料分類と円柱境界の選択

`classifyCylinderMaterialWall3(material, cylinder)` は、所有された材料に属する円柱壁の分割を使い、各開セルの法線両側で材料式を評価します。入力は材料ファクトリーの実際の分割です。任意のセル配列・判定コールバック・コピーした属性を証拠として受け取りません。

分割は全ての有限円柱の壁・上下端・追加半空間の零点で細分され、開セルについて有限円柱の内外と平面符号を保持しています。有限円柱の境界とラベルされた開セルは、支持円柱の一致と、厳密な上下高さの内部包含を確認します。接線などの一次元接触を面として扱いません。追加平面の零点が開セル内に残る場合も停止します。

内外が厳密なら両側で同じ述語を使います。一致する円柱壁では入力面の向きに応じて内側・外側を分け、材料式を両側で評価します。`minus`・`plus` は入力面法線の負側・正側の材料の有無で、`orientation` は保持・反転・境界なしを表します。Boolean式の評価関数は、既存材料照会・平面セル・曲面セルで共通化しました。

`owner` は、その開セルを含む一致した有限円柱壁のうち最初の候補インデックスです。無限の支持円柱が同じだけでは重複排除しません。高さ区間を考慮するため、部分的な重複帯だけを一度採用し、他の高さ帯を保持します。これは幾何候補の所有であり、式中の因果的な寄与を示すものではありません。

`boundaryCylinderMaterialWall3` は実際の分類出力だけを受け取り、所有セルの向きと境界を調整して縫合します。内側の空隙に面する壁は反転し、円柱SSI曲線の向きも保持します。`boundaryCylinderMaterialSurfaces3` は全候補壁を処理し、出力面から円柱・分割セルへの対応を返します。

結果は曲面部分です。`boundaryPlanarMaterialSurfaces3` の平面部分と合わせて共通縫合に渡せます。閉じた接続の検査は全体の埋め込み・一般ソリッド採用とは区別します。接線で接する和については非多様体の接続診断を残し、閉じた多様体としての採用を要求すれば拒否します。

新規8件では、単一円柱、内側の穴、反転・非単位軸による同じ円柱、部分的な高さ重複、非平行円柱のSSI境界、空材料、離れた成分、接線の特異接触を検査しました。新規8件を含む関連30件は77597 msで成功し、箱のガード円柱に曲面境界を生成しない追加検査も成功しました。型検査と既存133宣言の限定監査は成功しています。今回のコードのLean形式証明や全TypeScriptの形式検証ではありません。
