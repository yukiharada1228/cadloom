# 材料式から平面境界をまとめて構築する

`boundaryPlanarMaterialSurfaces3(material)` は、所有された有限円柱・半空間材料の全ての候補支持平面について、領域の構築、分割、零点検査、再分割、両側の材料分類、向き付き境界の選択、共有辺の縫合をつなぎます。

候補は各有限円柱の上下端と半空間の平面です。同じ幾何支持を持つ平面は、法線の尺度や向きによらず一度だけ処理します。`supports[i].origins` は、その平面を定義する入力の一覧です。各入力が演算結果に因果的に寄与したという主張ではありません。出力面の `faceOrigins` は支持グループと再分割後のセルを参照し、そこから元のセルと向き付き共有辺へたどれます。

各作業領域は、全入力有限円柱を厳密に囲む有理座標の箱を基に作ります。材料式のファクトリーは有限円柱の外で材料が残らないことを検査するため、この領域で全ての実際の平面境界を覆えます。作業領域の外周を材料境界として採用する処理ではありません。

この結果は平面部分です。円柱壁などの曲面は別に構築・選択する必要があります。閉じた接続だけで大域的な埋め込みやBodyへの採用を認定しません。全体が平面で閉じる場合は既存の平面ソリッド検査を通せます。検査では、6平面の箱についてこの経路から生成した境界の体積1、共通Bodyへの変換と保存復元を確認しました。

斜め円柱の非直交な作業座標では、線分と楕円の交差の平方根を元の共通パラメータと別々に計算すると、不要な体の合成が生じました。共通パラメータ `s` に対する原点 `N(s)/W(s)` と有理方向を保持し、楕円方程式を

```
A*t² + B(s)/W(s)*t + C(s)/W(s)² = 0
```

と表して、`K(s)=B(s)²-4*A*C(s)` と共通の二次像で交点を構築します。`W` が負の場合も両枝と有限範囲を検査し、元の線分方向順に並べます。二次像の次数は元のパラメータ次数の高々2倍です。対応する構築情報がない場合の一般経路も残します。

線分同士では、確認済みの有理方向が非平行で、一方の支持原点が有理なら、まず共面性を厳密に検査します。他方の原点をその有理支持を含む平面へ投影し、既存の構築相関を保持して交点を得ます。有限区間の包含も調べ、ねじれた直線を交差としません。

新規8件を含む関連76件が17968 msで成功しました。端面と半空間の重複、空材料、箱のソリッド化、斜め円柱の曲面との閉じた縫合、重なる円柱の共有端面、有理分母の正負、次数上限、共面性と有限範囲を検査しています。型検査と既存133宣言の限定監査も成功しました。今回のコードの新しいLean形式証明やTypeScript全体の形式検証ではありません。
