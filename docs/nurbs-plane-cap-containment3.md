# NURBSキャップ境界の包含と穴のグループ化

`analyzeNurbsPlaneCapContainment3` は所有されたキャップ境界と、同じ元の縫合表面に対する所有された材料証明を受けます。別の元表面の材料証明や、コピーして作った偽の証明は拒否します。元の証明には有限面の埋込み、面間の接触制限、閉じた向き付き接続、シェルの包含と材料方向が含まれます。

ループ上の一点を他の各ループに問い合わせ、整数回転数が非零ならそのループに含まれると判定します。`queryNurbsPlaneCapLoopWinding3` は指定した一つのループだけを調べるため、問い合わせ点が他のループ上にあっても使えます。元の複数ループ問い合わせAPIの挙動は維持します。代数的な座標、元の曲線とnative parameter、方向の予算付き再試行も維持します。

一点だけで十分なのは、所有された元のグローバル埋込みと完全なセル・共有辺のnoding、厳密にweldされたmanifold境界サイクルを前提とするためです。同じ元面内の交点はUVグラフのイベントとして分割され、異なる元面は認定された共有接続以外で交差せず、異なる境界ループに共有頂点はありません。この前提のもとでループは平面チャート内の互いに交わらないJordan曲線です。点のサンプルだけから曲線同士が交差しないと推測するAPIではありません。新しいLeanによる機械証明は追加していません。

問い合わせが境界を返す場合はunexpected-contact、予算切れならwindingの未解決結果を返します。包含の相互循環・推移律・各包含集合が鎖になること・親の深さを検査し、矛盾はinconsistent-containmentとして残します。

結果のloopsは元ループID、代数的な境界サンプル、包含ループのID、直近の親、深さを保持します。facesは偶数の深さのループを外周とし、その直下の子を穴としてまとめます。穴の中の材料の島は別の外周になります。元の有界な交互材料境界と結び付いているため、無関係な曲線集合に任意の塗り規則を適用する処理ではありません。曲線と向き付き辺はboundary.loopsで元のIDのまま保持します。

これはキャップの面領域のグループ化です。BRepキャップ面の生成、半分の表面との縫合、新しいグローバル埋込み・材料の認定、共通Bodyへの採用はまだ行いません。共面の2D元面は上流の片側選択で未解決のままです。
