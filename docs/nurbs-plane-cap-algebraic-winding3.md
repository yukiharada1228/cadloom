# 代数的な問い合わせ点と平面オフセット

`queryNurbsPlaneCapWinding3` は、有理座標に加えて独立した実代数的座標の点を受けます。問い合わせ点は凍結された代数的座標としてスナップショットします。判定用直線の法線は有理のまま、オフセットを実代数的な値として厳密に計算します。回転数、境界、予算付き再試行の意味は従来と同じです。

`partitionSewnNurbsSplitEdgeByAlgebraicPlane3` は有理法線と実代数的オフセットalphaを持つ平面の全交差イベントを求めます。元の曲線・UVパッチの有理同次座標で平面式をN/W+alphaと書き、alphaの定義多項式PについてW^degree(P) P(-N/W)を構成します。この有理多項式の全イベントには、指定された根の交差も必ず含まれます。

定義多項式の他の共役根、または余分な因子に対応する候補も発生するため、元の曲線の全XYZと指定されたalphaで平面式がゼロであることを厳密に再検査します。他の共役レベルの孤立交点は出力から除きます。ノルム多項式がある開区間全体でゼロの場合も、指定された平面式の符号を直接検査します。連続な有理像が有限個の共役レベルに入る場合、その連結した開区間では一つのレベルに一定なので、別の共役根の枝を真の重なりとして扱いません。

有理オフセットは従来の一次同次平面式を使います。既存の`partitionSewnNurbsSplitEdgeByPlane3`は有理Plane3を返すAPIを保ち、共通の処理へ委譲します。新しい分割結果のplane.offsetはAlgebraicRealです。

これは曲線の交差・回転数の拡張です。包含関係の森、外周・穴のグループ化、キャップ面、子Bodyの認定は引き続き別の処理です。任意の代数的法線はまだ受けません。独立した代数的座標の計算では次数増大の負荷があり、速度の一律保証はありません。

グラフのfiberやイベントで厳密に同じ根の候補を重複除去する場合は、次数が低い既存の証明表現を優先します。例えば円と直線の共通点で、円のfiberから得た4次の表現より、直線のfiberから得た同じ値の2次表現を残せます。近似や未検証な因数分解は行わず、厳密な等値比較を前提に表現を選びます。

トリムUVと共有辺XYZのパラメータ逆算では、各座標の同次ノルム多項式の最大公約数を取り、全座標の条件を満たす候補だけを根の分離に渡します。定数座標の不一致は早期に空集合とし、分母ゼロの候補を除き、最後に全ての指定座標の実際の枝を厳密に検査します。共役な座標の組み合わせを実在する点とみなすことはありません。

元の有理トリムとNURBS面の合成で生じた、XYZとweightに共通する同次多項式因子は除去します。所有された有限区間では元のweightは非零であり、共通因子の除去は曲線像と有限端点を変えません。区間外の分母因子がパラメータ対応の偽の成分として残るのを避けます。統合テストは斜めに切った重み付き円柱の全ての面を処理し、回復した曲線に共通因子が残らないことも確認します。
