# 平面セルの零点検査と材料の両側分類

`classifyPlanarPartitionSurfaces3(partition, surfaces)` は、実際の `partitionPlanarFaceByCurves3` の出力に対し、各開セル内で支持面の符号が一定かを調べます。入力オブジェクトの所有を検査し、コピーしたセルや判定コールバックを証拠として採用しません。対応する支持面は有理定義の平面・円柱です。

各支持面と元の平面との交わりを完全に求めます。交わりは空、直線、円柱の接線に対応する二重の直線、楕円、または平面全体です。直線は元の面の座標範囲を含む区間に制限します。それぞれをセルの全境界曲線との交点・重複端点で分割し、各開区間の厳密な内部点でセル包含を調べます。閉じた楕円全体がセルに入る場合も調べるため、単に境界交差の有無だけで判定しません。

- `cut`: セル内部に残る零点を返します。符号を変えない接線でも内部の零点は未解決です。
- `contained`: 平面の支持が一致し、セル全体がその支持平面にあります。
- `constant`: 開セル内に零点がないことを検査したうえで、符号と法線両方向の局所符号を返します。

工学的な成立根拠は、ファクトリーが構築する開いた縦分解セルの連結性、支持面交線の完全性、全境界イベントで分割した交線の各区間での包含の一定性です。境界だけの零点は許します。穴の中だけにある交線を、材料セル内の零点と混同しません。新しいAPIのLeanによる形式証明やTypeScript実行全体の検証を行ったものではありません。

`classifyPlanarPartitionMaterial3(partition, material)` は、所有された円柱材料式の各円柱壁、上下端の平面、半空間の平面をこの検査に渡します。零点が残るセルは `unresolved` として内部点を返します。検査を通ったセルだけ、各有限円柱の半径・上下高さと半空間の述語を法線の両側で評価し、元のBoolean材料式へ渡します。

`classified` の `minus` と `plus` は入力面法線の負側・正側の材料の有無です。`orientation` は負側だけが材料なら `1`、正側だけなら `-1`、両側が同じなら `null` です。`null` のセルを材料境界として採用しません。これらは開セルについての判定であり、閉じたBRepや埋め込まれた立体の採用ではありません。

現在は全プリミティブ支持を検査するため、Boolean式で無効になる支持の零点でも未解決を返す場合があります。無効な支持の除外、追加の交線による自動再分割、曲面側の同じ分類、分類後のセル統合・全体の縫合は後続です。一般NURBSや商用CAD全般の完了を意味しません。

検査には、内部点から見えない閉曲線、未分割の直線、二重接線、境界だけの接触、支持平面の一致と逆向き、傾いた座標系、穴と共有縦辺、上端・下端・内部の面・離れた面、円柱の差による環状材料、半空間の端面を使います。
