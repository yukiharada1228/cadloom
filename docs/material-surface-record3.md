# 統合材料境界のレコード変換

`bodyRecordFromMaterialSurfaceBoundary3(boundary, regions)` は、実際の `boundaryMaterialSurfaces3` の結果だけを受理し、共有位相に各面の再構築可能な領域を付けます。

平面では支持グループとセルの出自から、基底領域・有限カット曲線・厳密な内部点・材料の向きを記録します。円柱壁では所有セルに対応する円柱分割と全追加支持面、内部点、向きを記録します。面の順序は統合境界の順序を維持します。

JSON往復後に `restoreMixedBRepFaces3` を使うと、各面領域を再計算し、支持面と向き、完全な領域境界と共有辺の使用を照合します。内部空洞の反転面と実際の円柱SSI境界もこの経路を通します。

`regions` は呼び出し側が与えるラベルであり、材料の内外やシェルの包含関係の証明ではありません。この変換は共通Bodyへの採用そのものではなく、面領域を失わずにその検査へ渡す前提です。復元した接続が閉じているだけでは、一般ソリッドの埋め込み認定は付与しません。
