# Exact parity programs for general rational planar material

`compilePlanarMaterial3` compiles an actual factory-owned `PreparedPlanarSolid3` into a bounded cylinder/halfspace predicate program. Unlike the convex support intersection, this handles concave shells, voids, material islands and disconnected components. It creates predicates only; it does not certify a sewn BRep, adopt a Body or claim general mixed Boolean integration is complete.

The source already has exact closed embedding, oriented shell nesting and an exact planar triangle decomposition. A shared rational apex is the vertex-box midpoint. Each validated convex polygon face is triangulated by a vertex fan, and each noncoplanar fan triangle forms a tetrahedron with that apex. This avoids subdividing already-triangular faces again through the embedding checker's face-center decomposition. Collinear boundary-port triangles have zero volume and are skipped by exact orientation. Its four outward negative halfspaces are oriented by the opposite vertex and normalized by a positive rational factor for exact deduplication. Coplanar cones have zero volume and contribute no open material. The tetrahedron predicates combine by a balanced XOR tree. Empty input becomes a bounded false formula.

The construction argument uses mod-two boundary chains: each coned boundary edge occurs twice because the source is closed, so internal cone faces cancel. The remaining boundary is the original material boundary. The finite tetrahedron union and original material are both bounded, hence their mod-two indicators agree in every open chamber away from the supporting planes. Existing source validation supplies the embedding and material interpretation needed for cavities and islands. This is a geometric argument; it is not a new machine-checked chain-complex theorem.

The predicate's material meaning is the regularized closure of its true open chambers. Direct closed-halfspace XOR evaluation at an artificial internal plane is not a boundary classifier: such a point can have two true incident tetrahedra while still being interior material. A future boundary constructor must select faces by opposite-side material and cancel internal carriers. The existing material backend has this two-sided machinery, but a complete general-planar BRep integration has not yet been verified here.

A strictly enclosing finite cylinder contains the whole vertex box, every boundary triangle and every coned tetrahedron. It is conjoined once with the parity expression to satisfy conservative boundedness checks without changing any chamber. All coordinates, planes, normalization and bounds are rational. The exact internal triangle decomposition does not replace the output geometry with a numerical tessellation. There is no tolerance snapping.

Four focused tests pass: independent rational L-shape cells; nested cavity/island plus disconnected-shell cells; immutable empty material; and a box with a sewn collinear boundary port. Strict candidate points lying on any program plane or guard boundary are excluded from these open-chamber checks, with an explicit nonvacuous sample threshold. The tests compare with the independent existing prepared-solid classifier and reject copied ownership. The collinear case checks that zero-volume vertex-fan cones can be skipped without losing material.

On the same triangulated L-shape source, replacing the embedding checker's secondary face-center decomposition with the direct convex-face vertex fan reduces the program from 84 tetrahedra/138 planes to 28 tetrahedra/36 planes. This is an observed representation-size reduction, not a runtime benchmark. The reduced program's general BRep construction is still running; full sewn domains, serialization replay and native Body integration remain subsequent verification work.
