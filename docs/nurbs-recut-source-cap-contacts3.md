# 再切断キャップと残存NURBS面の接触証拠

`inspectNurbsRecutSourceCapContacts3` は所有された再切断キャップ付きB-repに対し、元の有限面の完全な平面ゼロ集合を監査し、残存面と新キャップの接触証拠を返します。接続の閉鎖性と幾何的な非接触性を区別するためのカーネル診断です。

孤立したゼロ点と、正負を隔てないゼロ辺の厳密な標本を残存面UVへ照会し、同じ空間点を新キャップの有限領域へ照会します。キャップ内部との一致は `cap-interior`、宣言された接続では説明できない境界接触は `undeclared-boundary` として、入力・元面・キャップ面・厳密点・由来を保持します。孤立境界点は両面が同じ位相頂点を使用しているかも確認します。捨てた面の接点は報告しません。

標本がキャップ外にあることから、ゼロ辺全体の非接触は推論できません。調べた非横断辺は `pendingArcs` に保持し、結果は常に `certifiesAbsence: false` です。旧平面キャップと新キャップの接触、全接触区間の分類、横断辺全体の宣言済み境界との照合、埋込みと材料の再認定は対象外です。未解決の元面・キャップ照会、ゼロ集合監査、同一平面領域は `unresolved` を返します。

## 回帰例

- 高さ `1-u(1-u)v(1-v)` の屋根を `z=15/16` で切断。閉じた有向接続を持ちながら、新キャップ内部に孤立接触が残る正側を検出し、屋根を捨てた負側では報告しません。
- 高さ `1+(v-1/2)^2` の屋根を `z=1` で切断。接触曲線上のキャップ内部証拠点を返し、曲線全体の検査は保留します。
- 通常の箱、重み付き円柱の宣言済み境界、所有権、照会予算と不変の戻り値を検査します。
