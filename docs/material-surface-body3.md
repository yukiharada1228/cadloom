# 直接構築した材料境界の共通Body採用

`bodyFromMaterialSurfaceBoundary3` は、所有された平面・円柱の統合材料境界を受け取り、面領域の再構築・境界の共有辺への結合・シェルの包含と材料側の解析を通して共通 `Body3` を返します。非多様体の接触は拒否します。内部空洞・別々の成分・空材料を保持します。

位置照会は新境界の正確な正則化判定を使い、各面の位置照会は再構築された有限領域を使います。Bodyとその内部点・面の所有は既存のWeakMapに保持し、構造コピーから取得できません。

新しい構築種別 `surface-material-expression` は円柱・半空間・材料式を保存します。`serializeBody3` / `restoreBody3` は定義から新パイプラインを実行し、保存された順序付きの全レコードと照合します。旧 `cylinder-material-expression` の構築種別と復元経路は維持し、出力の順序や面数を新方式へ暗黙に変えません。

この変更では採用・位置照会・保存復元までを接続します。新しいBodyを既存の全ブーリアン入口へ入力する変換・材料定義の合成は後続です。一般の輸入B-rep、未対応曲面、接続だけが閉じた任意の立体を認定する入口ではありません。
