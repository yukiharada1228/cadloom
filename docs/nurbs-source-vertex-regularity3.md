# 頂点の面内パッチ領域と閉包の片側階数

`analyzeNurbsSourceFaceVertexRegularity3(selection)`は、既存の共通UV頂点と、境界を曲面ノットで分割して追加された全イベントを対象にする。境界使用だけでは見つからない、頂点から面内部へ入るパッチも検査する。

## 局所的な面とパッチの対応

既存の厳密な半辺rotationを使う。各単調な枝の実際のUV germが入る象限と、枝間の面を保持する。象限内の最初の枝の直前の面、および各枝の左側の面を全て含めるため、同じ接線を持つ曲線間の狭い面も消えない。接線角度や直線chordの角度で順序を作り直さない。

境界piece内部のノットイベントには、その辺の正逆二つのgermを用いる。複数の未分割辺が同じ追加点を通るなど、局所接続を確定できなければ未解決にする。孤立UV頂点は厳密な面照会で含まれる面を求め、その面を全象限に対応付ける。

各閉パッチがその頂点からどの厳密な符号象限へ開くかをパラメータ範囲から求め、面と共通の開領域を持つ場合だけ採用する。頂点に点接触するだけで面の外側にあるパッチは採用しない。各面・象限にパッチの被覆があることも検査し、不足を正則性へ読み替えない。

採用した全片側パッチについて、正確な法線分子の同時零と3D像を評価する。結果は元UV頂点ID、追加ノットイベントの由来、各象限の面、patch/face/rank/pointを保持する。

## 閉包の階数のまとめ

`analyzeNurbsSourceFaceClosedRank3(selection)`は同じ所有された選択結果から、内部・全閉境界使用・全頂点領域の解析を実行する。一つでも退化の証拠があればsingular、三つが全て正則ならregular、それ以外はunresolvedとする。位置連続性は別の値として保持する。

ここでの閉包は、そのUV面の内部から近づけるパッチの片側極限として定義する。単一点だけ接する面外のパッチや、NURBSの既定のノットsideを無条件に強制しない。境界解析単独のvertexSectorCoverageはnot-certifiedのまま維持し、別の頂点解析を追加した場合だけ閉包の階数へまとめる。

これは片側階数2の検査であり、C1/G1、単射性・自己交差の不存在、空間面の埋め込み、材料や一般BRepの認定ではない。位置が不連続でも階数だけが正則な場合を許し、面採用には位置・埋め込み等の別条件が必要。

検証は、境界rayに現れない面内パッチの退化（実UV頂点と追加ノット点）、面外だけのパッチ、孤立接触、等接線の狭い面、閉内部退化成分、所有・未解決伝播を扱う。

target側、特異枝・region全境界、保存表現、埋め込み、材料分類と共通Bodyへの採用は残る。
