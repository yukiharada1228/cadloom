# Persistent cylinder partition face domains

The common face-domain schema now includes `cylinder-partition-cell`. It records a finite cylinder product face, a cutter cylinder, ordered refining planes, a strict interior witness and a physical orientation multiplier. `encodeCylinderCellDomain3` accepts only an owned cylinder or plane-refined partition and a valid actual cell index. The index is not persisted.

`decodeMixedFaceDomain3` reconstructs the original cylinder face, repeats the complete cylinder/plane partition and requires exactly one reconstructed cell to contain the witness strictly. This reuses the constructive event-complete strip partition, rather than accepting caller-specified graph bounds or testing their order at finitely many points. The resulting closed domain has exact point location, a strict sample and oriented native/SSI boundaries. Reversal changes physical orientation and boundary traversal together. Existing native face domains also decode through this mixed interface; the native-only decoder explicitly rejects the new tag.

`restoreMixedBRepFaces3` restores common boundary tables and requires every face to have a domain. It checks support/coorientation and pairs the entire oriented domain boundary with serialized edge uses after common noding using mixed sewing. Each boundary piece must pair exactly one domain use and one serialized use; a different valid subdivision is allowed. Shell face-use reversal is applied to the returned physical face sense and loops. Independent pcurves/parameter bounds still require another correspondence backend.

This adds genuine domain definitions for cylinder wall cells, including SSI and plane height bounds, to common BodyRecord. Planar cylinder-cut cells are not yet encoded. Reconstructing a whole cylinder Boolean therefore still needs their domains. Valid individual faces and closed oriented incidence do not establish global shell embedding, cavity nesting, material regions or owned Body3 validity, and do not enable chained curved Boolean operands by themselves.

Tests cover JSON reconstruction and exact location/boundary agreement of plane-refined unequal-radius cylinder cells, orientation reversal, malformed/noninterior witnesses, factory provenance, full face binding and rejection of another cell's boundary. These are executable checks, not additional machine-checked TypeScript refinement proofs. Replay is currently performed per domain; no global unbounded cache is introduced.
