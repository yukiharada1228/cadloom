# 有理平面材料の切断と再結合

`splitPlanarBodyByPlane3(body, plane)` は、所有された通常BodyまたはCellularBodyの有理平面材料を、平面の負側／正側へ正確に分けます。子は閉じた正則化材料で、いずれもCellularBodyとして返します。非凸、穴、空洞、分離成分、辺・頂点接触を既存の材料Booleanから引き継ぎます。曲面・非有理頂点・任意の輸入BRepは受理しません。

```ts
const split = splitPlanarBodyByPlane3(body, plane3(1n, 1n, 1n, '-3/2'));
const negative = restoreBody3(serializeBody3(split.negative));
const positive = restoreBody3(serializeBody3(split.positive));
const joined = rejoinPlanarBodySplit3(split);
```

平面法線は非単位でかまいません。負の係数で平面をスケールすると、幾何的な切断位置は同じで負側／正側が交換されます。正の面積・体積を持たない断片を、浮いた面や辺として材料へ残しません。

## 切断と界面の契約

結果は親、スナップショットされた平面、両側の子と次の情報を持ちます。

- `negativeCutFaces` / `positiveCutFaces`：子のうち切断平面上にある有限面ID。元から存在した親の境界面も含みます。
- `shared`：親の材料内部に新しく生じた界面だけを、負側／正側の実際の面IDで一対一対応します。`polygon` はその厳密な凸面片で、負側の子から外向き、すなわち入力平面法線の向きです。共有辺の追加ポートによる共線点を含む場合があります。
- `kind:'split'`：正の面積を持つ新しい界面があります。
- `kind:'separated'`：両側に正の体積がありますが、新しい面積界面がありません。平面が隙間を通る場合だけでなく、閉包が辺・頂点だけで触れる場合も含みます。閉包が互いに素であるとの宣言ではありません。
- `kind:'one-sided'`：材料は一方にだけ残ります。平面が外にある場合と、境界に接する場合を含みます。
- `kind:'empty'`：親が空材料です。

界面は表示三角形ではなく、既存の厳密な凸面分割です。穴付き切断面は穴を埋めず、複数の凸片で表現します。対の面は向きが逆で、厳密な凸領域として一致することを確認します。共線の辺ポート数が異なっても同じ凸領域を対応できますが、ここでは各coedgeを一対一にするID表までは返しません。親の面・辺・coedge・頂点との由来は、任意の追加解析 [`planarBodySplitProvenance3`](planar-split-provenance3.md) で取得できます。異なる切断間のID安定性は未提供です。

切断面と空洞の壁が一致すると、元の壁が片側だけへ残る場合があります。親材料内部にないその壁は、新しい共有界面へ数えません。体積のない反対側の残片も作りません。

## 正確な有限半空間マスク

親の全境界頂点から有理境界箱を作り、各方向に正の余白を設けます。有界な有理平面材料全体が、この箱の厳密な内部にあります。箱を切断平面でクリップし、正確な交点から凸な閉じる面を構築して、既存の平面立体検査を通します。

親をS、箱をB、閉半空間をHとすると、`S ⊂ interior(B)` なので `S ∩ (B ∩ H) = S ∩ H`。有限マスクを使うことで入力形状を近似したり、許容誤差を加えたりはしません。ガード箱の面は親材料の外にあり、子の物理境界には現れません。多角形と平面の交点、capの角度順、集合演算はすべて有理数で扱います。

両側を構築後、体積和が親に一致することと、全境界頂点が対応する閉半空間にあることを検査します。子の採用は従来どおり材料領域解析と有限面の完全な境界照合を通します。

## 再結合・保存・範囲

`rejoinPlanarBodySplit3` は元の所有された切断結果だけを受理します。両側の和を実際に再計算し、元材料との正則化XORが空であることを検査して、新しいCellularBodyを返します。元のBodyオブジェクトをそのまま返すショートカットではありません。

子はそれぞれ共通APIで保存復元・再切断・再演算できます。切断メタデータ自体の保存復元は未実装です。別々に復元した子の和は共通Booleanで計算できますが、コピーした切断メタデータを再結合の所有証明とはしません。

一般曲面の共通切断、NURBS、永続的な名前と切断メタデータの交換は後続です。既存の限定された円柱切断APIを、この平面材料入口で置き換えるものではありません。大きなモデルでは面の分割・Boolean・領域解析・再結合に時間とメモリが必要で、固定の実用性能上限は未保証です。
