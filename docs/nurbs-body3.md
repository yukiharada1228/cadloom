# 共通KernelBodyのNURBS材料

`bodyFromNurbsMaterial3` は、認定済みNURBS材料を `NurbsBody3` にします。`KernelBody3` は従来の `Body3`、`CellularBody3`、新しい `NurbsBody3` の和型です。解析曲面向けのBodyレコードへNURBSの面・辺を型変換して押し込むことはありません。

包含木の偶数深さの殻ごとに一つの材料領域を作り、その直下の奇数深さの殻を空洞として保持します。材料領域の内点は、向きの認定に使った直線を全境界で分割して探します。所属と最深包含殻を確認するため、外殻の単なる内点が空洞内にあっても材料の代表点には採用しません。

共通の `locateBody3`、`locateBodyFace3`、`intersectBodyLine3`、`intersectBodyRay3`、`intersectBodyLineMaterial3` にNURBSの分岐を追加しました。点・有限面の共通APIは従来どおり三値の所属を返すため、下位の厳密な照会が未解決なら `RangeError` になります。未解決を含む詳細結果が必要な場合は `locateSewnNurbsSourceMaterial3` を使用してください。直線・半直線・材料区間はNURBS側の未解決報告と交差の由来を保持します。既存の解析曲面の戻り値は維持します。

`bodyDocument3`、`serializeBody3`、`restoreBody3` も対応します。NURBS文書には元の有限面を再構築するsource B-repのレシピだけを保存します。保存された証明、接続、領域役割、内点、任意の認定フラグは受理しません。全sourceを復元して、縫合、大域的埋め込み、包含木、向き、材料領域の内点を再計算します。レコードの項目・数値文字数予算はsource一覧全体へ適用し、共通復元の文字数予算も適用します。

`serializeBody3(nurbsBody)` の型を持つ文字列を `restoreBody3` に渡すと `NurbsBody3` の型で戻ります。未知の外部データでは、復元結果の共通和型を扱ってください。NURBSの `kind` は `nurbs-body` です。公開オブジェクトのコピーでは所有権は復元されません。

一般NURBSの集合演算、平面切断、切断面の対応付け、解析曲面の材料プログラムへの変換は未実装として明示的に拒否します。NURBS最近点、変換、質量特性などの既存の解析曲面専用APIも、まだこの型を受け取りません。全操作の共通化が完成したという意味ではありません。下位の埋め込み認定も十分条件によるもので、任意の商用CADデータの受理を保証しません。
