# 有理曲線の全区間対応

`matchNurbsSpanIntervals3` は、二つの非定数な有理曲線と厳密な有限パラメータ区間を受け、両区間の空間像が一致し、対応曲線のパラメータ方向が整合する十分条件を検査します。入力多項式をスナップショットし、区間が元のspan内にあり、閉区間で同次重みが零にならないことを検査します。区間外の分母零は許容します。

XYZの同次曲線の等値方程式から共通の代数的なパラメータ対応曲線を求め、両方の有限区間で切り詰めます。対応する全ての曲線枝について方向を調べ、第一・第二パラメータへの射影区間の和が、それぞれの区間を隙間なく覆うことを検査します。両方の被覆があるため、片方だけの部分一致を成功とはしません。端点のXYZも再検査しますが、全区間の一致は端点・標本の一致から推測するものではありません。

成功時は元のスナップショット、向き、有限な暗黙対応曲線を返します。`nurbsSpanIntervalMatchPoint3` は所有された認定の有限辺だけを評価し、全XYZの等値を再検査します。対応は関係として保持し、一意な逆関数であるとは主張しません。

`nurbsSpanIntervalMatchParameters3` は第一または第二パラメータを指定して、反対側の有限区間内の全ての逆像を求めます。入力区間と所有を検査し、対応多項式のファイバーから候補を分離して全XYZで再検査します。入力側と出力側を取り違えないよう `first` / `second` を明示します。一意性を必要とする節点化処理では、呼び出し側が候補数を検査します。

`not-certified` は空間像が異なることの証明ではありません。例えば同じ線分を折り返して二度たどる曲線は、像が同じでも対応方向が混在するため未認定になります。定数曲線・空区間・閉区間内の分母零は入力条件違反です。

これは有理曲線区間の共通処理です。セルの一般の暗黙境界から有理曲線を取り出す処理、元の共有辺との対応の組立て、面の縫合、キャップと子Bodyの生成はまだ必要です。一般の非有理NURBS交線まで認定したとは主張しません。

独立スナップショットでビルド、関連2ファイルのstrict型検査、関連12ファイル48テストが成功しました（7666.24375 ms、失敗・キャンセル・スキップ0）。無理数の区間端点、非線形再パラメータ化、逆向き、有限区間外の同次共通因子、端点だけの一致、被覆不足、折り返し、定数曲線・零分母・区間・所有ガードを確認しました。253ソースのハッシュとステージ済みソース・テスト524ファイルの一致を確認しました。全リポジトリの検証や新規形式証明は主張しません。
