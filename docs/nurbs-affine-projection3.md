# NURBS曲面のアフィン左逆写像

`certifyNurbsSurfaceAffineProjection3` は、有理係数の空間アフィン写像 P が、全有効パラメータ領域の曲面 S に対して P(S(u,v))=(u,v) を満たすことを確認する。一般のNURBS曲面の埋め込み判定を完成させるAPIではない。

## 検査

入力を曲面コンストラクターで再検査し、全隣接パッチのC0連続性を確認する。各パッチの同次多項式 X,Y,Z,W について、6未知係数の恒等式 n・(X,Y,Z)−c0 W−cu uW−cv vW=0 の全係数から有理数の連立一次方程式を作る。零空間の二つの解の (cu,cv) が独立なら、u,vを復元する二つの空間アフィン形式に変換する。

発見した形式を、全パッチの元の同次多項式へ再代入して恒等式を独立に検査してから証明書を所有登録する。サンプル点の一致だけでは認定しない。重みは曲面コンストラクターで正と検査され、閉じた有効領域で分母が消えない。

## 数学的帰結と限界

S(a)=S(b) なら P を適用して a=b なので、曲面は単射である。各一側パッチでは微分して DP DS=I となり、DSの階数は2である。C0連続なSの像上でPが連続な逆写像になるため、閉じたパラメータ矩形の連続な埋め込みを得る。これは実装契約の数学的説明であり、この新実装のLeanによる機械証明ではない。

節点でのC1/G1連続性は要求も認定もしない。連続な折れ目を認める。円柱など、正則かつ単射でも空間アフィン写像から元のパラメータを復元できない曲面がある。`not-certified` はこの十分条件が成立しないという結果であり、曲面が不正・自己交差するという結論ではない。

## 点の問い合わせ

`nurbsAffineProjectionParameters3` は任意の厳密な空間点から候補(u,v)を返す。射影だけでは曲面への所属を意味しない。

`locateAffineProjectedNurbsSurface3` は候補が閉じた有効矩形内にあること、元の曲面の厳密評価が入力点と3座標すべてで等しいことを確認する。`inside` と `boundary` は曲面上のパラメータ矩形の内部と境界であり、立体材料の内部と境界ではない。任意のトリム領域や閉ソリッドは認定しない。証明書はfactory所有を要求し、構造コピーは拒否する。

## 代数実数の相関

空間座標が同じ代数実数の有理式から生成された場合、新しい `AlgebraicReal.linearCombination` は非公開の生成履歴から共通の根を使う。係数と分母をその根の定義多項式で剰余化し、最後に一度だけ有理式を評価する。独立した生成元には従来の完全な演算へ戻る。呼び出し元のプロパティを相関情報として信用しない。

通常の算術が返す多項式・根の区間を変更せず、生成履歴はWeakMapに保持する。保存レコードへは追加しない。新しい明示的な線形結合APIの結果は、従来の加算列より低い次数の証明書になる場合がある。分母の非零判定・根の枝の選択は既存の厳密な有理式評価が担う。TypeScript実行環境全体の形式検証を意味しない。

## 検証記録

隔離ビルドで、新規10件と既存の根分離・有理像12件の計22件が成功した（失敗・スキップ0）。巨大な平行移動、代数的な点、微小なパラメータ領域、節点挿入・反転、連続な折れ目、不連続な継ぎ目、射影が同じ曲面外点、所有検査、独立した生成元へのフォールバックを含む。全体回帰および保存Bodyの回帰は、この記録では完了としていない。
