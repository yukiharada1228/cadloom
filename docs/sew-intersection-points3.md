# 交差点から共有辺への対応

`sewMixedBRepFaces3(faces, {splitPoints})` は、上流の交差処理で得た厳密な点を、既存の境界曲線の追加切断点として受け取ります。入力点をスナップショットし、実際にその点を含む境界だけを分割します。ネイティブの線分・楕円弧と、所有された円柱SSI曲線の既存分割処理を再利用します。

結果の `splitPointVertices[i]` は入力 `splitPoints[i]` に対応する出力頂点インデックスです。どの境界にも属さない点には `null` を返します。重複入力は同じ頂点へ対応し、既存の端点も再利用します。対応配列は凍結します。既存の `sourceUses[face][loop][curve]` と組み合わせると、入力曲線・切断点・向き付き共有辺の経路を追えます。オプション省略時の対応配列は空です。

`curveNodingPoints3` の点や `intersectPlanarCylinderFaces3` の交差曲線の端点・孤立接点をそのまま候補として渡せます。ただし有限面の交差曲線には、入力面の境界上にない表現上の切れ目もあります。その点は境界の頂点にせず `null` になります。

この処理は、面内部へ交差辺を挿入したり、面領域を分割したりするものではありません。交差片を両方の面の有効なループへ組み込む段階、面の両側の材料分類、埋め込みの検査は別に必要です。閉じた接続も立体としての正しさとは区別します。

検査対象は、箱の共有辺の一貫した分割、同一点・既存端点・無関係な点、SSI曲線の両側の共有、ネイティブ円弧の交差点、有限な平面／円柱の交差から得た4つの境界切断点です。全ケースで既存の曲線別 `sourceUses` の連続した被覆と向きを検査します。
