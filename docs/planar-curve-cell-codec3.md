# 有限曲線で分割した平面セルの保存・復元

`encodePlanarCurveCellDomain3(partition, cell, orientation)` は、所有された有限曲線の平面分割から `planar-curve-partition-cell` レコードを生成します。基底領域・全カット曲線・厳密な内部点・向きを保存します。未検査のセル番号や表示用の三角形を保存してセルの正しさを代用することはありません。

`decodeMixedFaceDomain3` は定義から分割を再計算し、内部点が厳密に一つのセルの内部にあることを検査します。同一の定義は明示的なデコーダーバッチ内で再利用します。向きはセルごとに検査し、反転時には境界の使用方向も反転します。支持面を外れるカットや未対応のNURBSカットは拒否します。

`restoreMixedBRepFaces3` に渡すと、復元したセルの完全な境界と保存された共有辺の使用の一致も既存検査で確認します。スキーマに合うだけのレコードは幾何認定済みとはみなしません。これは面領域の保存復元であり、シェル全体の埋め込み・材料領域・Body所有の認定ではありません。

この形式は、材料定義から直接生成した新しい平面セルを共通Bodyへ接続するための前提です。従来の円柱支持専用セル形式とその復元経路は維持します。
