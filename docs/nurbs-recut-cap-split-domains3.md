# キャップの全世代へ使う平面領域と有限面

平面ループの巻き数・包含関係・有限面所属を内部の `planar-loop-domains3.ts` へまとめました。既存の一世代キャップ分割と、再切断後の旧・新キャップ分割が同じ処理を使います。曲線評価と完全なnative平面分割だけをアダプターから受け取るため、共通処理は切断履歴やキャップ世代へ依存しません。

巻き数は、代数的な照会点を通る直線について全曲線のゼロイベントと重なり区間を求め、境界所属と横断を区別します。頂点に当たる方向は再試行し、予算不足は `unresolved` のまま返します。frameのGram行列から厳密な双対ベクトルを計算するので、原点移動・非正規化・非直交の平面chartでも同じ処理を使えます。

共通処理は構造的な任意ループに埋め込みや材料の認定を与えません。呼び出し元の所有された有限Jordan面と完全な直線分割、分岐のない閉サイクルを前提とします。その下でループ間の巻き数から包含forest・parent・depthを求め、偶数depthの外周と直接の穴を有限面へグループ化します。接触・整合しない包含・未解決の照会は認定しません。各公開経路は所有権を確認し、証明書を別々のWeakSetで管理します。

`analyzeNurbsRecutCapSplitDomains3` / `queryNurbsRecutCapSplitLoopWinding3` / `locateNurbsRecutCapSplitFace3` は、両世代キャップを分割した境界からこの処理を使います。切断平面上の既存辺を片側だけに残した場合や空側も、対応する有限領域として扱います。

`buildNurbsRecutCapSplitFaces3` は外周・穴を共通B-rep面へ採用し、全native曲線をそのまま保持します。両側を構築した場合のcut辺は同じ曲線・同じedgeを逆向きに共有します。親境界のedge・vertexから最終表への対応、面の向き、loop・coedgeを保持します。選んだ片側だけの構築と空の面集合にも対応します。

`locateNurbsRecutCapSplitSurface3` は支持面から外れた点をoutsideとし、有限領域へ厳密に照会します。`nurbsRecutCapSplitSurfacePoint3` は所属を確認したUVだけを3Dへ持ち上げます。既存の一世代キャップ公開APIの型とsource由来も維持します。

検査対象は、新旧キャップの両側、独立した矩形・半平面条件による484点、保持した穴と開いた穴・独立した島、円弧の代数的な照会点、UV/XYZ往復、空側、重なり辺、予算不足の伝播、負側の親、反射・拡大後の再構築、非直交chartを使う共通処理です。

これは有限面群の構築です。三回目以降の閉立体切断には、全残存source面と全キャップの共有区間対応・noding・縫合、境界全体の埋め込み・殻包含・材料再認定、任意回数の保存recordを引き続き接続する必要があります。一般NURBS BooleanとSolidCraft全体の純粋TypeScript再実装は未完了です。

提出対象の隔離ビルドと、新規2・既存キャップdomain/face・recut Bodyの計5テストファイルの追加strict型検査が成功しました。関連25ファイル・新規12件を含む144件が全て成功しました（119710.574 ms、失敗・キャンセル・スキップ0）。実行ソース305ファイル・src/testsのTypeScript合計615ファイルについて、実行した隔離スナップショットとgit indexのbyte一致、および全実行ソースのSHA記録との一致を確認しました。これは再現性の照合であり、TypeScript全体の形式証明や全リポジトリのテスト成功ではありません。
