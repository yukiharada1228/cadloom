# 選択した面境界の閉片側階数

`analyzeNurbsSourceFaceBoundaryRegularity3(selection)`は所有された面側パッチ選択について、各inside面の巡回が実際に使用するパッチの階数を、各有限pieceの全区間と閉端点で検査する。

## 退化イベントの列挙

既存の曲面解析からdu×dvの3分子を再利用する。パッチ全体が正則なら、その閉境界使用も正則である。

NURBS境界では3分子を境界spanへ同次代入し、最大公約多項式の全実根を有限パラメータ範囲とpiece範囲で制限する。3式が恒等零なら区間全体を退化として保持する。選択された陰関数交差辺では、3分子の全多項式イベントで切断する。辺の支持式が一致するだけで別枝の零点を採用しない。

全切断点と各開区間の代表を実際の有限UV枝で評価する。零点を全て列挙した後の代表評価であり、少数のサンプルだけによる正則性判定ではない。閉端点は、内部が正則でも個別に退化を保持する。

## 結果と保証範囲

各useは元のcycle/edge/piece/patch/direction、増加UV軸、閉イベントのUV・3D像・regular、開区間のregularを持つ。面の`selectedBoundaryRegular`はこれら全ての選択使用が正則であることを表す。面内部の正則性は別APIのまま保持する。未解決の選択や有限UV像を正則へ読み替えない。

`vertexSectorCoverage: 'not-certified'`を明示する。選択した辺使用の閉端点は検査するが、頂点まわりの面内に入る全パッチ領域、巡回にない孤立頂点、面閉包全体の片側階数を網羅したという認定ではない。内部正則性とこの値だけで閉じた空間面を採用しない。C1/G1、単射性、埋め込み、材料も未認定。

検証は、内部が正則でも境界全体が退化する例、陰関数交差辺の退化区間、角と未分割境界内部の孤立退化、無理数の境界イベント、未使用側だけの退化、rank-one像、所有と未解決伝播を扱う。

次は頂点の全ての面内パッチ領域と孤立頂点の所属を検査し、閉包の階数条件へ接続する必要がある。target側、特異枝・region全境界、埋め込み、保存表現、材料分類と共通Bodyへの採用も残る。
