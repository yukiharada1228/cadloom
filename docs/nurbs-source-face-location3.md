# 元面UVの面・辺・頂点の厳密照会

`locateNurbsSourceFace3(faces, u, v)`は所有されたUV面分類結果と、有理数または代数的数のUV座標を受け取る。

- `face`: 面IDと、元トリム領域のinside/outside。
- `edge`: 該当する共通辺IDと、その両側の面ID。
- `vertex`: UV頂点ID、該当辺ID、接する面ID。
- `unresolved`: 元の分類が未解決、有限fiberを分離できない、または既知の巻き数に対応しない場合。

辺・頂点の結果を、空間の材料境界と同一視しない。内部wireの両側は同じ面として重複除去する。孤立した接触頂点は、辺を創作せず、そのUV位置を含む面へ対応付ける。境界・頂点の集合は不変の配列で返す。

## 幾何計算

境界NURBSと選択された代数的交差枝の有限fiber評価を、面分類と共通の内部ヘルパーへ抽出した。閉区間の端点は実際の選択枝のUV点として扱う。通常枝はu、垂直枝はvで点所属を検査する。水平fiberは転置した多項式の全実根を有限区間・選択枝で照合する。

辺所属を検査した上で、水平右向きrayの巻き数を計算する。上向きの辺は始点を含み終点を除き、下向きは逆にする半開規則で、rayが頂点・水平辺と同じ高さでも二重計数しない。各巡回の巻き数ベクトルを既存の分類へ照合し、面IDを返す。未分類のベクトルに最寄りの面を割り当てない。

## 検証と制限

矩形と穴の独立した不等式による格子照合、切断の左右・端点、円の独立した距離二乗による格子照合と無理数境界点、wire、孤立接触、未解決分類の伝播・所有を検査する。

照会はsource UVの配置に対するもの。曲面の有効範囲、空間への持上げ、埋め込み、面の向き・材料、target側の一般対応、保存表現と共通Bodyへの採用は別途必要である。
