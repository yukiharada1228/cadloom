# キャップ付きNURBS表面の埋込みと新しいシェル包含

`certifyCappedNurbsPlaneEmbedding3` は所有されたキャップ付き表面に対する十分条件の埋込み証明を作ります。閉じた接続だけからは認定しません。元のグローバル材料証明、完全な有限面の平面交差、既存の厳密な横断的section-wire証明を結び付けます。空の表面は直接認定します。

元の有限面を制限した面同士の接触は元の埋込みを引き継ぎます。横断的な完全なゼロ集合は、既にnodingされた分割境界になります。所有された外周・穴の領域グループから作った平面キャップは互いに交差せず、その内部には元の面が入りません。この条件と再検査済みの閉じた接続・頂点リンクから、共有接続以外の交差がないことを継承します。面内部での孤立接触や接する曲線を単純に無視して埋込みとみなしません。

これは横断的な切断に対する十分条件です。共面領域、頂点接触、境界上の重なり、非横断的または現在の投影で扱えないsectionはnot-certifiedとなり、元の完全な交差・診断を保持します。拒否は形状が不正であるという結論ではありません。妥当な退化切断を一般に認定する処理は引き続き必要です。新しいLean証明やTypeScript全体の形式検証は追加していません。

`intersectCappedNurbsPlaneRay3` / `intersectCappedNurbsPlaneLine3` は所有された埋込み証明を受け、全体または一つの新しいシェルを問い合わせます。元の面の交差は実際の有限な分割領域に絞り、平面キャップとの交差も有限領域で検査します。新しい面ID・シェルID、厳密な代数的パラメータ・XYZ、向き付き法線のdotSignを返します。直線は負のパラメータも保持し、レイは前方だけを残します。

元の境界上のorigin-hitや複数面のイベントでも、調べている新しいシェルの面に属さないものは除外します。これは別シェル上の境界サンプルを問い合わせるために必要です。保持された面の境界、非横断的なヒット、cap平面内のレイ、関連する元面上の重なりはdegenerateとして再試行可能に残します。重なりが切断領域の外でも保守的に再試行する場合があり、全ての退化した直線の重なり区間を列挙するAPIではありません。

`queryCappedNurbsPlaneShellParity3` は実際の有限面上の点をon-faceとし、それ以外では正則な交差の奇偶と向き付き和を返します。Auto版は厳密な有理方向を予算付きで試します。予算切れや逆写像の未解決をoutsideへ丸めません。

`analyzeCappedNurbsPlaneContainment3` は新しいシェルそれぞれの保持された元面から、開いたUVセル内の厳密な有理境界サンプルを選び、他の新しいシェルへの奇偶を求めます。所有された埋込みが、交わらない閉じたシェルという前提を与えます。相互包含・推移律・包含集合が鎖になること・親の深さを検査し、新しい親・深さ・期待される材料方向を記録します。切断で穴が外部へ開くことがあるため、元のシェルの深さは再利用しません。

expectedOrientationは深さから要求される方向であり、全ての新シェルの実際の材料方向を改めて認定したという意味ではありません。新しい材料証明、材料領域の内部サンプル、子立体の採用、共通Body・保存復元・再切断は未完成です。
