# 再切断材料と直線の完全な閉集合交差

`intersectNurbsRecutMaterialLine3` は所有された材料証明書と有理直線から、閉じた材料区間と孤立点を返します。共通 `intersectBodyLineMaterial3` もこの処理へ分岐します。直線は両方向を対象とし、パラメータは入力directionに対する値で、距離に正規化しません。

## 完全なイベント分割

元の全source境界交差、二つの平面が横切るパラメータ、直線上にある全source noding頂点、旧キャップ分割頂点、最終位相頂点、完全な接触監査の追加点を集約します。同一パラメータの空間像が等しいことを確認し、元sourceの由来・どの非平行平面がイベントを作ったか・追加分割点かを保持します。

追加頂点は、直線全体が切断平面上にあり、元の長い境界重なりの途中だけが残る場合に必要です。元の端点と一つの標本だけから短い残存区間の不在を推測しません。元の完全な有限配置のイベントで分けた各開区間と全端点を、実際の再切断材料へ厳密に照会します。

insideまたはboundaryの隣接spanを閉区間へまとめ、inside/boundaryの内訳と有理サンプルを保持します。どの区間にも覆われない保持点は孤立点として返します。元の接触が切断で捨てられた場合は保持しません。未知の所属や閉包の不整合はunresolvedです。

## 退化との関係

横断ヒットに限定された境界ray APIではキャップ支持面上の直線はdegenerateです。この閉集合APIは、平面内の境界span、曲面への孤立接線点、二つの切断平面が同時に作る一点接触も扱います。cap-support上の直線を少し動かす近似やtessellationは使用しません。

回帰では非単位方向、旧・新キャップ上のspan、代数的円柱端点、保持／破棄する孤立接触、切断平面上で1/5〜3/10だけ残る区間、空洞と島の三つの材料区間、元source hitを持たない二平面の孤立交点を検査します。
