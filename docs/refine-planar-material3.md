# 未解決の平面材料セルの再分割

`refinePlanarMaterial3(classification)` は、実際の材料分類の出力を受け取り、内部零点が残る支持面の交線を追加します。平面・円柱の支持交線は零点検査と同じヘルパーで構築し、同じ幾何支持は一度だけ追加します。以前の全切断曲線も保持して再分割し、材料の両側を再分類します。

再分類後に未解決が残れば、内部の不変条件違反として停止します。未解決を成功へ書き換えたり、点の材料判定だけで境界を採用したりしません。結果の分類は `boundaryPlanarMaterialCells3` に渡せます。既に解決済みなら元の分類オブジェクトをそのまま返します。

`parentCells[newCell]` は元のセルのインデックスです。以前の全曲線とそのイベントを残すことで旧セルの境界を維持し、新しい各内部点について元の親が一つだけあることを検査します。`addedSupports` は元の `supports.surfaces` のインデックスです。出力と配列は凍結され、コピーした分類結果は受け付けません。

斜めの切断では、人工的な縦辺の固定座標が無理数となる場合があります。その場合の線分／楕円交差は、二つの固定座標の一致を厳密に確認したうえで、変化する一座標に関する二次式を解くようにしました。二次係数は有理数なので、異なる端点の根の体を合成して除算する必要がありません。楕円の支持平面を横切る場合は平面交差を先に判定し、有限区間と始点から終点への順序を保持します。その他の方向には既存の一般経路が残ります。

検査は、未切断の端面、半円だけの不足、斜めの半空間、解決後の同一性、コピーの拒否、親セルへの包含、独立した円柱・半空間の不等式、無理数の固定位置での端点接触と横断を含みます。新規6件を含む関連30件は12469 msで成功。型検査と既存133宣言の限定監査も成功しました。新規APIのLean形式証明ではありません。

現在は全プリミティブ支持について保守的に再分割します。無効な述語の除外、曲面側の再分割、セル統合、全境界の埋め込みと一般ソリッドへの採用は後続です。一般NURBSや商用CAD全体の対応完了ではありません。

接触・重複支持の追加2件も741 msで成功しました。平面が円柱へ二重の接線で接する場合、接線と高さの切断を再分割しても材料の面を作りません。軸原点を移動し、方向を反転して3倍にし、高さパラメータも変えた同じ円柱の和では、壁の交線を一度だけ追加し、独立した半径不等式と同じ端面材料を保持します。再実行では分類をそのまま返すことも検査しました。
