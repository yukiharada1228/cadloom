# 再切断したキャップの有限面領域

`analyzeNurbsCapSplitDomains3` は所有されたキャップ境界分割結果と側から、子ループの包含関係、直属の親、深さ、外周と直属の穴の組を返します。元の所有されたJordan有限面、完全な直線交差分割、入出次数1の子ループ構築に基づくため、互いに交差しないループの包含を各境界上の一点で調べられます。任意の曲線配列や構造をコピーしたオブジェクトを認定しません。

`queryNurbsCapSplitLoopWinding3` は子ループの元曲線断片と新しい直線辺を同じ厳密な巻き数問い合わせで扱います。元曲線の完全な平面根を子ネイティブ区間へ制限し、直線では代数的オフセットの根を直接計算します。頂点方向や全区間重なりは有理傾きの別方向へ再試行し、接線根では巻き数を変化させません。代数的な問い合わせ点と端点を保持し、方向予算で解けない場合はunresolvedです。

包含の非循環性・推移性・親の深さを検査し、偶数深さを外周、その直属の子を穴として有限面領域にまとめます。切断によって穴が開けば元の内周は外周の一部となり、切断されない穴は直属の穴として残ります。空の子には面を生成しません。

`locateNurbsCapSplitFace3` は所有された証明と面番号に対し、外周内かつ穴の外をinside、元曲線・新切断辺・穴の境界をboundaryとして問い合わせます。これはチャート内の有限面領域であり、まだBRepへの面採用や再切断Bodyの認定ではありません。分割済み元NURBS面の再分割、共有辺のnoding、縫合・埋込み・材料認定が残ります。同一平面・境界重なりなど前段が未解決の場合は境界分割の未解決を伝搬します。
