# 有限NURBS面の完全な平面ゼロ集合の監査

`analyzeNurbsSourcePlaneZeroSet3` は所有された有限平面セル複体から、二次元の同一平面セル、一次元の平面ゼロ辺、孤立した零次元接点を保持します。等符号セルのseam除去で採用面の境界から消える接線接触も対象です。通常の境界ループが空であることを接触なしの根拠にしません。

既存の完全な配置は切断平面の多項式、有限トリム、全投影イベントを含みます。各開辺では符号が一定または辺全体がゼロであり、孤立根はイベント頂点にあります。この分割条件に基づいてゼロ辺を検査し、両端の閉集合所属も確認します。全投影イベント根は採用後のB-rep頂点とは独立に有限面・前回の制限領域へ照会します。判定が未解決なら完全なゼロ集合として返しません。

ゼロ辺は隣接セルが正負に分かれるopposite-signs、同符号のsame-sign、有限領域境界のdomain-boundary、二次元ゼロ領域に接続するcoplanar-incidenceを区別します。これは局所の隣接関係であり、微分的な横断性や材料の接触分類ではありません。各辺の元番号・ネイティブ区間・標本、各頂点の厳密なUVと空間点、ゼロ辺の接続、孤立点、同一平面セル番号を保持します。

穴の内部や以前に捨てた領域の根は、閉じた有限面所属によって除外します。代数的な臨界座標を有理数や浮動小数点へ丸めません。

これは新キャップと残存面の接触検査に必要な全ゼロ層の局所監査です。新キャップ領域との照合、宣言済みの共有境界との区別、一次元接触区間と孤立点の全体検査、新しい幾何学的埋込み・材料再認定は残ります。標本だけから接触不在を証明したり、閉じた接続構造だけで材料認定したりしません。
