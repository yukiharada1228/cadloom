# 有限NURBS面と平面の厳密な交差

`intersectNurbsSourceFacePlane3` は所有されたprepared source face complex、元の有限面ID、平面を受け取り、交点・交差曲線の有限区間・共面領域を返します。準備できていない面や未解決の所属は `unresolved` です。これは支持曲面全体の断面ではありません。

各認定済みパッチについて、同次座標から `n·P + offset W = 0` を作ります。正の重みの領域では、これが空間の平面式と同値です。面の認定矩形とパッチを交差させ、代数曲線の完全なトポロジーを求めます。交差曲線は近似折れ線へ変換しません。

曲線には有限トリムの支持多項式、全有限端点と座標イベントによる分割を加えます。そのため各開区間で有限面への所属が一定です。区間内の厳密な有理パラメータで実際の有限面と接近パッチへの所属を確認し、採用した区間の両端も再検査します。穴の中の曲線や、同じ支持曲線の有限境界を越えた部分は採用しません。孤立接点と特異な交差頂点も残します。

パッチの平面式が恒等的に零なら、実際の有限面の開領域がパッチ内部に存在することを分割の証人で確認してから、共面の `areas` を返します。領域は「元の有限面と閉パッチ矩形の交差」であり、矩形全体を塗りつぶす意味ではありません。穴と片側パッチの制限は引き続き有効です。

曲線の評価は `nurbsSourceFacePlaneEdgePoint3`、共面領域の評価は `nurbsSourceFacePlaneAreaPoint3` を使います。曲線のnative parameterは非垂直UV枝ではu、垂直UV枝ではvです。共面領域の外は `null`、その所属が未解決なら例外を返します。どちらも所有権・範囲・有限面とパッチへの所属を確認し、元XYZで平面式の厳密な零も検査します。

同じUV頂点は統合しますが、継ぎ目でのパッチごとの辺の由来は保持します。共面領域に含まれる辺や頂点も残る場合があります。最大化された平面領域、殻間の縫合済み断面ループ、切断後のBodyを返すAPIではありません。Bodyの平面切断には、これらの断面の組立て、切断面の材料選択と向き、閉じた子Bodyの認定がまだ必要です。

穴付き面の線分断、共面の穴、孤立接点・接線上の曲線・交差する枝、片側の結節線、重み付き円柱の有理・代数的な断面、円形トリムの接触、穴で四つの弧へ分かれる暗黙的な閉曲線、穴の中へ完全に隠れる交線、既存SSIで分かれた面への限定、所有確認と未解決伝播をテストします。新規の形式証明は追加していません。
