# 再切断後の両世代キャップを同じ有限面断面へ接続

`intersectNurbsRecutCapFacePlane3` は所有された閉再切断境界と最終face番号を受け取り、旧キャップの残存面・新キャップの両方を有理平面で断面化します。元の無限平面や切断前のキャップ領域へ戻さず、現在のB-repの全外周・穴と最終共有曲線を使います。

支持面に平行な平面は `parallel` / `coplanar` を区別します。交線がある場合は、全境界曲線をそのnative区間全体で分割し、厳密な交点・重なり端点から交線のイベント列を作ります。イベント間の開区間は実際の有限面へ照会し、閉区間・境界上のspan・孤立接触点を保持します。予算内に照会を決定できない場合は `unresolved` を返します。

`boundaryPartitions` はloop・coedge・最終共有edge・向きと、各辺の全native分割を保持します。交点にも各境界使用のnativeパラメータを保持し、次の面分割で親辺から子辺への全区間対応を作れるようにします。異なる使用の同じ空間点は交線パラメータとXYZの一致でまとめます。端点の一致だけを辺全体の一致とは扱いません。

新旧のcapは現在の構築型から支持frameを取り出す部分だけを分岐し、その後の曲線分割・有限面分類・区間構築を共有します。NURBSのsource曲面を平面キャップとして扱うことや、所有されていない構造コピーは拒否します。

検証では非線形cubeパラメータ、斜め切断、平行／同一支持面、共有辺全体の重なり、孤立頂点接触、重み付き円弧の代数的端点と接線、捨てた円弧、穴と独立した島、両切断の負側、反転した切断平面、反射・拡大・平行移動後の再構築を扱います。各交点の平面所属、元coedge・native評価のXYZ一致、全辺被覆とspanの有限面所属も照合します。

これは次の切断に必要な有限平面キャップの断面です。三回目の閉立体切断、全世代の面分割・共有辺noding・縫合、再埋め込み・材料認定、任意回数の切断recordはまだ未実装です。一般NURBS BooleanやSolidCraft全体の再実装の完了とは区別します。
