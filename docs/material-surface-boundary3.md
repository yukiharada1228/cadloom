# 平面・円柱境界を一つのAPIへまとめる

`boundaryMaterialSurfaces3(material, options)` は、所有された有限円柱・半空間材料について、平面と円柱壁の境界選択を呼び、全体の共有辺を構築します。現在の入力は既存の材料ファクトリーの出力です。任意のBRepや未検査の定義を受け取る汎用ソリッド認定ではありません。

結果は平面・曲面それぞれの詳細と、統合した `faces`・`faceOrigins`・`sewn` を保持します。出力面の由来は、平面なら支持グループとセル、円柱なら候補円柱とセルです。縫合の曲線別対応と合わせて、元の分割から共有辺へたどれます。平面の全イベントと曲面の接触点も共有の分割へ渡します。

全辺について、使用数が2以上で、向きの総和がゼロであることを検査します。部分的で釣り合わない境界は返しません。空であることも元の材料と照合します。`closedOrientedIncidence` は閉じた向き付き多様体の接続についての値で、幾何学的な埋め込みやBodyへの採用の証明ではありません。

既定では、釣り合っている非多様体接触は診断とともに返します。`requireClosed: true` を指定すると、閉じた向き付き多様体の接続を満たさない結果を拒否します。空材料は面・頂点・由来を生成しません。出力は凍結し、内部の所有確認も持ちます。所有確認をソリッドの成立確認とは混同しません。

検査は8件です。単一円柱、内向きの別シェルを持つ閉じた内部空洞、平面残片を持たないSSI交差、離れた2シェル、接線の非多様体接触、空材料、箱の幾何検査と共通Body保存復元、高さ帯の重複と内部端面の除外を確認しました。8件は8095 msで成功し、隔離宣言に対する型検査と既存133宣言の限定監査も成功しています。新たなLean形式証明やTypeScript全体の形式検証ではありません。

一般の解析曲面・NURBS、構築前の材料定義だけを入力とする共通プログラム所有モデル、曲面の全体埋め込み、共通Bodyの新しいレコード採用経路は後続です。
