# 境界から独立した材料定義

`prepareCylinderMaterialProgram3(cylinders, planes, expression)` は、有限円柱と負側半空間の材料式を検査し、不変の `CylinderMaterialProgram3` を返します。複数形状の交差・面分割・境界選択・縫合は行いません。入力の有限円柱自体は、既存のプリミティブファクトリーで作成した所有オブジェクトが必要です。

配列と材料式をコピーし、平面を正確な係数から再構築します。式の参照番号、演算名、循環を検査します。共有する非循環部分式は受理します。疎配列や偽の円柱オブジェクトは受理しません。

全円柱述語を偽、半空間述語を未知として保守的な真偽範囲を計算し、上限が偽の場合だけ受理します。これは円柱の和の外で材料が存在しないことの証明条件です。全ての有界な論理式を受理する完全な判定器ではありません。所有は入力の構造だけでは付与せず、ファクトリー結果をWeakSetで保持します。

既存の `boundaryCylinderMaterialExpression3` もこの定義検査を使います。`materialProgramOfBoundary3` は、実際に構築に用いたプログラムを返します。境界オブジェクトそのものをプログラム所有オブジェクトとみなすことはありません。既存の境界の列挙可能なフィールドは増やしません。

現時点の新しい境界統合APIは依然として既存の材料境界を入力に要求します。次の段階で平面分類・円柱壁の分割をプログラム入力へ接続し、旧境界の事前構築への依存を解消します。この変更だけで汎用B-repカーネルや全体の幾何認定が完成したとは扱いません。

検査は新規3件と既存の材料式・境界統合を含む17件で成功しました。隔離ビルドとその宣言ファイルに対する新規テストの型検査も成功しています。

## 平面パイプラインへの直接入力

`classifyPlanarPartitionMaterial3` と `boundaryPlanarMaterialSurfaces3` は、所有された `CylinderMaterialProgram3` または既存の `CylinderMaterialBoundary3` を受理します。`CylinderMaterialDefinition3` はこの入力の和型です。構造だけが一致するコピーは拒否します。既存境界の場合は保存された実際のプログラムへ解決し、定義の場合はプログラム所有を検査します。結果の `.material` は渡された入力を保持するため、再分割でも同じ所有を確認します。

平面側は旧材料境界のファクトリーを呼ばず、定義から支持面列挙、分割、両側分類、再分割、境界選択、縫合まで進みます。六平面の箱はこの経路で独立した幾何検査へ渡せます。ただし有界性のための有限円柱ガードは引き続き必要です。円柱壁と全体統合の入力はまだ既存境界であり、一般的な曲面境界の独立構築は後続です。
