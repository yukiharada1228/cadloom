# 元の曲線トリムからのセル辺の有理写像

`nurbsPlaneCellRationalMap3` は、所有されたセル辺について、一定の有理u/vの経路、または元のJordanトリムの有理曲線を回収します。後者では、セル辺の両端を元のUVトリムへ厳密に逆写像し、その有限区間を調べます。

端点の一致だけでは受理しません。元のUV曲線を配置多項式に代入した分子が恒等的に零であること、区間内部にuの微分の零点がないこと、向きとnative u区間の被覆を検査します。配置の射影イベント間では根の枝が交わらず、回収したUV曲線は連続かつuが単調なので、区間内部で別の枝へ移れません。一つの内部点で、元の順序付き根の枝を識別します。閉区間端点の臨界点は許容します。

認定したUV曲線を、元の片側パッチの同次多項式へ正確に合成し、空間の有理曲線を返します。空間への持ち上げも元のセル辺の評価と照合します。複数の候補が認定される場合は曖昧なまま未解決として保持します。

結果の `lower` / `upper` と空間spanは、回収したトリムのパラメータです。`parameterSpan` に元のUVトリム写像を保持し、そのx座標がセル辺のnative uになります。`direction` はトリムのパラメータ増加に対するセルnative uの方向です。一定UVの経路では `parameterSpan: null` で、空間spanはセル辺のnative parameterをそのまま使います。

共有辺との照合では、全区間認定の方向にこの `direction` を合成して、元の共有辺の子辺列の向きを決めます。これにより、円弧などの元の曲線トリムも全区間のXYZ対応へ接続できます。

`nurbsPlaneCellRationalMapPoint3` は所有された写像の閉区間を受け、元のトリムパラメータからUVを求め、認定に使った片側パッチへ直接持ち上げます。既知のuからvを独立に解き直さず、共通の代数的パラメータを保持します。元の区間・枝とパッチへの所属は写像作成時の全区間認定に基づきます。複製された写像と区間外のパラメータは拒否します。

診断では、7次の定義式で保持していた端点が厳密には有理数1であることを確認しました。座標逆像の候補に `recognizeRational` を適用し、正確に有理数だと証明できたものだけを有理点へ正規化します。これにより同じ幾何学的な内部点の不要な26次の表現を避けます。非有理な端点や代数的な内部点をテストから除外する変更ではありません。定数・アフィンの有理画像も、既存の厳密なアフィン変換で評価します。

これは元の有理Jordanトリムの回収です。元のトリムに由来しない一般の暗黙SSI枝の有理化や非有理曲線の対応、セル辺の共有分割点での節点化、キャップと子立体の生成はまだ必要です。

独立スナップショット `/tmp/cadloom-trimmap224g-staged` でビルド、関連4ファイルのstrict型検査、数値基盤を含む関連21ファイル95テストが成功しました（93171.648458 ms、失敗・キャンセル・スキップ0）。無理数交点、代数的な内部点とnative-u評価の一致、円の条件、方向合成、既存の非線形セル分解、展開した積との配置比較、隠れた有理根、既存数値演算の回帰を含みます。255ソースのハッシュとステージ済みソース・テスト530ファイルの一致を確認しました。
