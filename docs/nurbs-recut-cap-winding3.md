# 再切断キャップの混合曲線ループの厳密な巻き数

`queryNurbsRecutCapWinding3` と単一ループ用の `queryNurbsRecutCapLoopWinding3` は、再切断した側別境界のキャップ向きループに対して正確な整数巻き数を返します。元NURBS面の曲線と旧キャップ上の直線が混在しても、元のネイティブ区間と実代数的な問い合わせ点を保持します。曲線を折れ線へ変換しません。

`partitionNurbsRecutCurveByAlgebraicPlane3` は局所元面・縫合済み元面・共有断片・キャップの四種類の所有された曲線に対し、端点と全平面根、開区間の符号、全区間重なりを保持します。有理法線と実代数的オフセットに対応します。元面のUV多項式根は既存の完全な分割処理へ委譲し、キャップの直線ではパラメータを厳密に解きます。全候補を現在の閉区間と選択した代数的根へ絞り、共役側の別曲線を重なりとして誤採用しません。

巻き数は直交有理チャートの有理傾き0,+1,-1,+2,-2,...を試します。頂点方向・全辺重なりは別方向へ再試行し、境界点は明示的に返します。孤立した接線根で巻き数を変えず、曲線パラメータの前後符号と有向辺使用から横断を数えます。方向予算で解決しない場合はunresolvedです。空ループ集合では空の巻き数列を返します。

これは各ループの巻き数であり、外周・穴の包含証明や材料充填規則ではありません。旧形状の幾何学的埋込みと再分割の対応を確認した上でのループ包含分類、有限キャップ面、再閉鎖、材料再認定、再切断Body APIが残ります。閉じた位相接続だけからループ間の幾何学的非交差を推測しません。
