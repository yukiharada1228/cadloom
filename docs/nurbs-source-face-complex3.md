# 認定されたNURBS面の境界複体

`prepareNurbsSourceFaceComplex3` は所有された面パッチ選択から閉階数・位置連続性・埋め込みの十分条件を検査し、すべての内側面が認定された場合だけ境界複体を構築します。未解決入力と未認定面は `not-prepared` です。

## 接続の条件

元の共通UV辺とノット分割片が同一である候補だけを比較します。同じパッチなら同一写像です。異なるパッチの場合、既存リフトの全区間連続性、またはノット線上の3成分の同次多項式恒等式 P_i W_j−P_j W_i=0 によって、辺全体の像が等しいことを検査します。端点や中点だけの一致では共有辺にしません。

辺はパラメータ増加方向を基準に持ちます。各面の使用は、元の面・サイクル・サイクル内位置・パッチ側・方向を保持します。頂点はUVが等しく、かつ3D点が厳密に等しい場合だけ共有します。ノットで同じUVを持っても3D像が異なる場合は別頂点・別辺になります。離れたUVの空間的な交差は統合しません。

各サイクルのUVと3Dの端点接続を再検査し、外周・穴・wireの分類を維持します。一使用の辺、逆方向の二使用の辺、それ以外の接続を別々に返します。wireが同じ面の二使用を持つ場合も由来は保持されます。この分類から閉じた立体、多様体、面間の大域的非交差は推論しません。面ごとの埋め込み証明は面同士の非交差証明ではありません。

`evaluateNurbsSourceComplexEdge3` は所有された複体と明示的な辺使用を要求し、そのパッチ側の有限区間を評価します。複製した複体、不正な辺・使用番号、区間外パラメータを拒否します。

## 現在の制限

全内側面の認定を要求し、部分的に成功した複体は返しません。[軸平行なUV継ぎ目の重複](nurbs-source-uv-seam-sharing3.md)は、空間使用を保持したUV辺共有で扱います。一般の非直線重複を認定できない場合は未解決のまま伝播します。異なる支持面からの交差片の統合、任意BRepへの変換、殻の幾何学的成立、材料分類とBooleanの再演算への採用は未完了です。

新規テストは、単独面、SSIで分かれた面の逆向き共有辺、非線形トリム、穴、不連続継ぎ目の非共有、未認定入力と所有・区間検査、上流UV重複の未解決伝播を扱います。数学の形式証明や一般立体の成立をテスト成功から主張しません。
