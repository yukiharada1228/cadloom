# 縫合NURBS閉殻の包含関係

`analyzeSewnNurbsSourceContainment3` は、所有された大域的埋め込み証明を受け取り、殻の包含木を構築します。接続が閉じているだけの面群は入力にできません。元の証明をコピーしたオブジェクトも拒否します。

各殻の一つの面の有理UV内部点を厳密に評価し、その空間点を他の全殻に対して照会します。大域的埋め込みにより異なる殻の境界は交わらず、各殻の境界は連結なので、一つの境界点の所属で、その境界全体が他の殻のどちら側にあるかが決まります。自分自身の境界点を自分の内点として扱う処理ではありません。

半直線の退化は自動再試行し、予算切れや所属の未解決を伝播します。他の殻上という結果も採用しません。包含関係の非対称性・推移性と、祖先が一列に並ぶことを検査してから、最も近い親、全包含殻、深さを返します。入力順から親を推測しません。空の面群では空の木です。

`expectedOrientation` は材料境界とする場合に必要な向き（偶数深さで外向き、奇数深さで内向き）です。実際の法線の向きはまだ認定していません。そのため、この結果だけで空洞や材料を確定したり、共通Bodyへ採用したりはできません。向きを反転した独立殻も、包含木では同じ根として扱います。

非線形パラメータの立方体による三段の入れ子、入力順の入替え、離れた複数の根、向き反転、曲面の重み付きNURBS円柱、証明の所有確認、探索予算の未解決伝播をテストします。このアルゴリズム自体のLean形式証明は追加していません。
