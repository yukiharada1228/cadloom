# 再分割NURBS面と旧キャップの共通辺による接続

`joinNurbsRecutSourceCaps3` は所有された共通区間証明、同じ再分割セル複体から採用したNURBS面、対応する旧キャップの両側の採用面を受け取り、面の辺使用を共通断片へ置き換えてB-repを再構築します。端点が同じ別の曲線を推測して共有する処理ではありません。

共通区間ごとに一つのshared曲線を生成し、元面とキャップの親辺をネイティブ順の辺使用列へ展開します。逆方向のcoedgeでは列の順序と各使用方向を反転します。キャップ側では一本の辺だった区間も、元面側の余分な投影区切りに合わせて細分化します。元面・キャップ双方の入力辺から新しい使用列への表、面番号の対応、共有断片番号を保持します。その他の辺は入力面集合内の共有を保持し、異なる入力間で勝手に同一視しません。

有限面の向き・外周・穴と全辺所属は所有された親面の境界使用から引き継ぎます。共通B-repエンジンで方向・双対coedge・境界ループ・頂点リンクを再検査し、全shared断片に元面とキャップの二つの逆向き使用があることを要求します。区間の被覆不足や接続検査失敗はunresolvedであり、部分結果を接続成功として返しません。

`nurbsRecutJoinedCurvePoint3` は所有された曲線の認定区間だけを元の曲線または親面辺で評価します。`locateNurbsRecutJoinedSurface3` は所有された接続面に対し、元の厳密な有限面所属を利用します。曲線や面の構造をコピーした入力は受け付けません。

現在は一つの元有限面と対応する旧キャップの両側を接続する局所的な開いた面集合です。他の元面間の通常の共有source辺、複数の元面とキャップを一括する共有noding、新しい切断平面を閉じる面、全立体の埋込み・材料認定は残ります。閉じた再切断Body APIやSolidCraft全体の再実装の完成を意味しません。
