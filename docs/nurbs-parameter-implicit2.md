# NURBSパラメータ境界の厳密な陰関数化

`implicitizeNurbsParameterCurve2` は、x=u、y=v、z=0の正重みNURBS曲線を検査し直し、全閉spanの像を含む有理係数の二変数多項式を構築する。トリム境界を曲面交差のパラメータ空間へ引き戻すための基盤であり、[両トリムの交差制限](nurbs-affine-intersection-trim3.md)で有限枝のイベントと実際の所属判定に組み合わせる。

## 消去と恒等式の検査

各spanの同次多項式X(t),Y(t),W(t)から共通因子gcd(X,Y,W)を正確に除く。共通の基点因子を残すと、パラメータ消去の終結式が恒等的にゼロになり、有効な曲線を失う場合がある。元の重みは有効区間内で正であり、この除去で区間内の像は変わらない。

X(t)−uW(t)、Y(t)−vW(t)のt係数をQ[u,v]の多項式として、Sylvester行列の行列式を分数なしBareiss消去で計算する。ピボットは多項式の厳密な非零判定で選び、全ての多項式除算の余りがゼロであることを検査する。浮動小数点の行列式や補間は使わない。

終結式の重複因子をu,vの両偏導関数とのgcdで取り除き、最高次係数を1へ正規化する。最後に、得た多項式Fへ元の有理式を同次代入し、全span上の恒等式が厳密にゼロであることを独立に検査する。少数のサンプル点の一致で受理しない。

両座標が定数の場合は曲線ではなくpoint spanとして有理座標を保持し、元の同次座標との恒等式も確認する。非零長の区間があることだけで空間像の次元を決めない。不連続な一側spanは別々の元span番号と全体パラメータ区間を保持する。

## 必要条件と有限像の区別

F(u,v)=0は元の有限spanの像を含む必要条件である。Fの零点だけでは、選択した枝、向き、有限パラメータ範囲への所属を認定できない。例えば四分円の変換結果は円全体の式を持つが、反対側の円弧が元の四分円に入るわけではない。最小の陰関数式や像集合全体との同値も主張しない。

`implicitNurbsParameterSpanPoint2` は、所有された結果、span番号、元の閉パラメータ範囲を検査し、元のNURBSから厳密に評価する。返す座標はx=u、y=v、z=0であり、Fの任意の零点を受理するAPIではない。入力のキャッシュされた範囲は信用せず、定義から再構築する。

## 交差への統合と制限

トリム付き曲面交差では、この多項式を交差のチャートへ引き戻し、全零点イベントで分割した上で、実際の外周・穴と有限境界への所属を検査する必要がある。陰関数式上で全区間が一致する場合には、有限spanの端点、特異点・射影イベントも区切りとして扱う必要があり、陰関数式だけでboundaryと分類してはいけない。トリム面交差、面分割、一般NURBSのSSI、殻・材料認定の完成ではない。

## 検証

独立した直線・放物線・円の式、非定数重みの垂直線、代数的パラメータ、共通基点因子の除去、重複する終結式の平方因子除去、不連続な一側span、定数span、平面・所有・範囲を試験する。数値helperは独立した一次・二次消去式、行交換が必要な行列、零・定数・共通因子の規約、25個の有理数での既存の一変数Sylvester行列式との照合を含む。これは新実装やTypeScript全体の機械証明ではない。

版177で[両トリムの交差制限](nurbs-affine-intersection-trim3.md)へ接続した。有限spanの端点と両軸の射影イベントも引き戻し、実際のdomain所属で選別する。陰関数化APIだけで有限枝への所属を認定するものではない。
