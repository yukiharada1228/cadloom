# 旧切断辺の全被覆とキャップ側の共通区間

`coverNurbsRecutSectionEdges3` は所有された旧面集合と新しい有限セル複体から、制限元と同一の有限面に接続する全section辺の区間被覆を検査します。新しい境界辺について既存の全区間照合を実行し、元の辺番号ごとにネイティブパラメータ順へ並べます。開始点から終了点まで隙間・重複なく一度ずつ覆うこと、旧境界方向と新しいUV境界方向×面senseが一致することを要求します。不完全な表には被覆証明を発行しません。

結果は旧辺番号・曲線・境界方向・区切り値・各断片の所有された照合証明を保持します。新しい辺から旧section照合への表では、元の共有source境界や内部・新切断辺をnullとして区別します。元面に旧sectionがなければ空の完全な表となります。任意の曲線配列や構造をコピーした入力は受け付けません。

`alignNurbsRecutCapEdges3` は被覆証明と、同一旧面集合に属する所有されたキャップ分割結果から、両側の全区切り値の和集合を作ります。旧曲線オブジェクトと辺番号の同一性により対応付け、キャップ側も全区間を重複なく覆うことを検査します。余分な投影イベントで元面側だけが分割されている場合も共通区間へそろえます。各区間は元面の照合証明とキャップの親断片を保持します。

同一の次切断平面を要求し、平面の負スケールではcapSideを元面側のplaneに対するsideへ変換します。元面とキャップの境界が逆向きであること、各区間の符号が一致すること、両端の空間点が同じことも検査します。欠けたキャップ被覆、未解決キャップ、符号・向きの矛盾はunresolvedです。異なる旧面集合・異なる平面・重複した同じキャップは拒否します。

これは共有nodingのための認定された共通区間表です。まだ面のcoedgeを共通断片に置き換える処理や全立体の再縫合ではありません。通常のsource辺照合、再接続、新しい閉立体の埋込み・材料認定と再切断Body APIは残ります。
