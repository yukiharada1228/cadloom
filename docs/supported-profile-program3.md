# 支持条件と厳密な領域照合による円弧混合プロファイル

押し出しの同一ループに直線と円弧が混在する場合、`prepareExtrudeMaterialProgram3` は対応可能な支持条件の組合せを構成し、元の充填領域との2D XORが空であることを検査してから材料定義を返します。円の内外や直線の左右をサンプルだけで推測して採用しません。

ループを2Dカーネルで正規化してから、直線の材料側半空間で有理の外側長方形を切断します。反時計回りの円弧には円ディスクとの積、時計回りの円弧には円ディスクとの差を適用します。元の領域と一致したときだけ、その多角形押し出しと有限円柱の積・差を同じ順序で構築します。高さは実際の押し出しの範囲を保持します。

これにより、直径と半円弧のD形、複数の円支持から成るレンズ形状、円弧による切欠きを近似なしで変換できます。円弧の端点が無理数でも、有理な支持円と支持直線から表現できる場合を扱います。生成候補と元の充填領域が異なる場合は拒否します。スタジアム形状など、和や別の領域分解を必要とする形状の一般コンパイラーはまだ実装していません。

別ループで構成される多角形・完全円・穴・島のパリティ経路と、従来の円形押し出しの保存復元は維持します。新しい範囲は共通材料カーネル入口に適用し、旧円形専用入口の受理条件を黙って変更しません。
