# 共通Bodyの厳密な有理相似変換

`similarityTransform3([columnX, columnY, columnZ], translation?)` は `q = Lp + t` を表します。列ベクトルの内積を有理数で検査し、互いに直交し、等しい正の長さの二乗を持つ行列だけを受理します。許容誤差は使いません。有理行列で厳密に表せる回転・移動・一様拡大縮小・反射を扱い、せん断・非一様拡大・零行列を拒否します。任意の角度の三角関数を丸めて回転を作るAPIではありません。

`transformBody3` は、既存の `Body3` では所有されたBodyを材料プログラムへ変換し、円柱軸・半径・半空間を変換した後、共通境界・材料領域・Body検査を再実行します。結果は変換済みの定義で保存復元でき、次のブーリアンや変換の入力になります。元のBodyは変更しません。対応する材料定義へ変換できるBody族が対象であり、一般の輸入B-repや未対応曲面の変形ではありません。

## 定義の対応

列長の二乗をs²とすると `LᵀL = s²I`、`L⁻¹ = Lᵀ / s²` です。平面 `n·p + c = 0` は `n' = Ln/s²`、`c' = c - n'·t` とします。すると `n'·(Lp+t)+c' = n·p+c` となり、半空間の符号も保持します。

円柱の軸原点・方向はLで変換し、半径の二乗をs²倍します。軸パラメータは内積の分子・分母がともにs²倍になるため、有限範囲のlower/upperは保持します。円柱の暗黙式は正のs⁴倍になり、符号が変わりません。反射でもこれらの関係は成立し、境界の物理的な向きは材料定義から再構築します。

`transformPointBySimilarity3` と `transformVectorBySimilarity3` は有理点・ベクトルに同じ変換を適用します。ベクトルには移動を適用しません。`transformCylinderMaterialProgram3` は境界構築前の材料定義だけを変換する入口です。全ての入口が変換の実際の所有を要求し、構造コピーから検査済み所有を取得できません。

## 合成と逆変換

`composeSimilarityTransforms3(first, second)` はfirstを適用してからsecondを適用します。線形部は `L₂L₁`、移動は `L₂t₁+t₂` です。引数順を逆にした意味ではありません。結果も同じ厳密な相似条件で検査し、所有された変換として返します。

`inverseSimilarityTransform3` は `Lᵀ/s²` と `-L⁻¹t` を構成します。有理数のまま正確に計算するため、変換と逆変換の合成では単位行列と零移動が得られます。点だけでなくベクトルにも適用でき、変換を一つへ合成してからBodyを再構築することで中間Bodyの生成を避けられます。

Bodyを変換して戻すと幾何が元へ対応しますが、古い構築種別や面の分割・列挙が元と同じになることは約束しません。照合は正確な材料位置と直線パラメータで行います。


## 接触材料とCellularBody

`transformBody3(cellularBody, transform)` はCellularBodyを返します。元の構築DAGの有理平面立体葉を相似変換し、Boolean結果と材料／空領域、面の両側の対応を再構築します。行列式が負なら葉の面順を反転し、物理的な外向きを保ちます。辺・頂点接触を多様体へ分離することはありません。

`transformPlanarMaterial3` はBody採用前の所有された平面材料にも同じ変換を適用します。構築DAGの共有部分式は一度だけ再構築します。有限領域の体積は `|det L|` 倍となり、直線の原点と方向を同じ相似変換で写すと交差パラメータは保持されます。実装では変換後に検査を再実行します。異なる面・領域分割間のID安定性は保証しません。
