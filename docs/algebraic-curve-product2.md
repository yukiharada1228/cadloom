# 因子を保持する厳密な曲線配置

`traceAlgebraicCurveProduct2` は複数の支持多項式の零点集合の和を、積を展開した式と同じ閉矩形上で構築します。入力に零多項式があれば全領域、空の積では零点なしです。垂直成分は係数のcontentから取り出し、非垂直成分は微分とのGCDと既存因子とのGCDで重複を除きます。

射影イベントには各非垂直因子の判別式、最高次係数、矩形の上下境界への制限に加え、因子の全ての組についてresultantを含めます。これにより、因子内部の特異点・垂直接線・境界交点と、異なる因子の全交点を保持します。単に因子別のグラフを並べる処理ではありません。

イベントと開いたslabのファイバー根は各因子から厳密に求め、等値比較で統合して順序付けます。枝の接続用の水平分離線も因子別の制限で検査します。完成したグラフには元の積と非垂直零点集合の多項式を保持し、内部の所有された因子表を使って枝を評価します。公開される枝は従来どおり暗黙曲線で、折れ線には置換しません。

セル分解は同じ零点集合を保持した支持因子をこの処理へ渡します。平面の符号は元の平面式から求めます。投影・根計算で大きな積を一度に扱う必要を減らしますが、全ての入力で高速になることや計算量の上限は主張しません。

展開した積との比較では、同じ端点を持つ別の枝も区別するため、端点に加えて区間内部の曲線評価を照合します。交点、無理数のイベント、垂直成分、重複因子、零因子と空の積を対象にしています。この比較を含む独立スナップショットの関連21ファイル95テストが成功しました（93171.648458 ms、失敗・キャンセル・スキップ0）。ビルドと関連4ファイルのstrict型検査も成功しました。全リポジトリのテスト成功や新規形式証明は主張しません。
