# 重み付きNURBS円柱の統合回帰

既存の公開NURBS入口だけで、4枚の円柱壁と2枚の円形キャップを構築し、面の認定、source B-rep、全境界の縫合、半直線集約、殻の交差偶奇、個別構築レシピの復元まで接続して検査します。円柱専用の解析演算へ処理を逃がしたり、メッシュ近似したりしていません。実行コードの変更はなく、新しい統合回帰です。

## 正確な円の定義

第一象限の二次有理Bezierは、点(1,0),(1,1),(0,1)と重み1,1,2を使います。ローカルなt∈[0,1]について、同次座標はX=1−t²、Y=2t、W=1+t²です。X²+Y²=W²の恒等式から、正確に単位円の四分円です。回転した4区間を9制御点と重み1,1,2,2,4,4,8,8,16で接続します。

壁はこの円にz=vを組み合わせた正の有理重みのNURBS面です。一周する全域を単射な面と偽って認定せず、各四分円のUV長方形を別々に認定します。4枚とも非線形の三角射影証明を使います。キャップは[-1,1]²を支える平面NURBSと、同じ有理円をUVへ変換したJordan外周で定義します。キャップの長方形支持面と有限な円板を区別します。

## 確認した統合

- 6面から頂点8・辺12・coedge24、1つの閉じた向き付き局所多様体の接続を構築し、全共有辺の評価がx²+y²=1と0≤z≤1を満たすことを確認。
- 64点の交差偶奇・向き付き交差和・横断数を、独立した有理式x²+y²<1および0<z<1と照合。
- 側面の非有理な交差パラメータと、キャップの有理な交差パラメータを、独立した二次式と照合。
- 四分円継ぎ目、継ぎ目でない位置の接線、母線上の重なりでは再試行を返し、別の方向では確定できることを確認。
- 円板外だが支持平面上の点を除外し、円板中心・円周・周期境界の面所属を区別。
- 全6面の構築入力を個別に保存・復元して再縫合し、閉じた接続と厳密な壁／キャップ逆照会、殻の偶奇を再確認。

ここで確認するのはこの固定した構成と照会の経路です。任意の入力面群の大域的埋め込みを判定する一般検証器、殻の包含・材料役割、共通BodyへのNURBS採用、一般NURBSブーリアン、STEP互換性やSolidCraft全体の再実装完了を示すものではありません。新規の形式証明でもありません。
