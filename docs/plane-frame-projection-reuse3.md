# Reuse exact inverse plane charts

`planeFrame3` now privately registers the normal computed while validating independent frame directions. Only that actual frozen factory object can reuse the validation. Plain, copied or mutable structural frame inputs are still snapshotted through the normal constructor on every call; public properties do not grant ownership.

For a validated frame, `pointInPlaneFrame3` retains its exact support plane and Gram inverse constants. With `a=u·u`, `b=u·v`, `c=v·v`, `D=ac−b²>0`, the dual vectors remain `U=(cu−bv)/D` and `V=(av−bu)/D`. Chart coordinates are still `U·(p−origin)` and `V·(p−origin)`, and off-plane points still return null. Constants are reused rather than recomputed for each candidate.

A nested WeakMap caches each actual snapshotted immutable point's inverse or null under the actual validated frame. Cache keys never use a caller-mutable point or a copied provenance object. Existing affine correlation is retained exactly as before. Repeated results are frozen coordinate objects, so sharing them does not introduce mutation. Weak keys follow the lifetime of the actual frames and points; no public cache/certification flags are added.

The latter change plain input points and frames between calls, reject off-plane and singular copied frames, and check that copied point fields cannot inherit private affine correlation. No timing thresholds or approximate equality are used.
