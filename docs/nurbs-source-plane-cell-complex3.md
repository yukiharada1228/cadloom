# NURBS平面符号セルの接続

`buildNurbsSourcePlaneCellComplex3` は所有されたセル分解から全セルの閉境界を構築し、同一有限面のパッチ配置間の頂点・辺・セルの接続を作ります。UV頂点は厳密な等値比較で統合します。辺は同じ元の曲線枝または同じ定数u/vの経路、同じ厳密な区間、同じ端点を持つ場合にだけ統合します。端点だけでは曲線を同一と判断しません。

共有辺は二つの異なるセルから逆方向に使われることを検査します。三重使用や同方向使用は不変条件違反として拒否します。元の境界報告・局所辺番号・使用方向を保持し、暗黙曲線を直線化しません。

同じ平面符号で共有辺を持つセルを連結領域へまとめ、領域内部の共有辺を境界から除きます。符号が変わる切断曲線は残ります。残った各境界頂点の入出次数が一なら、全辺を一度ずつ通る向き付き閉路を抽出します。次数が合わない場合は `cycles: null` と元の境界使用一覧を返し、接続順を推測しません。領域は辺を介した連結性で定義し、点だけの接触ではまとめません。

同一有限面内の人工的なセル継ぎ目を除く処理です。パッチの定数u/v境界は、同じ座標線上にある全ての境界端点で区間を追加分割して接続します。UVが一致する頂点では空間座標の厳密な一致も検査します。一般の曲線は同じ配置の同じ枝であることを引き続き要求し、端点だけで統合しません。別の有限面・UV系をまたぐ共有曲線の照合、穴の包含階層、キャップと元の面の接続、閉じた子Bodyの生成と認定はまだ必要です。閉路の向きはUV方向であり、元の面のsenseへの対応付けは別処理です。

独立したステージ済みスナップショットでビルド、関連2テストファイルのstrict型検査、関連5ファイル27テストが成功しました（7114.286834 ms、失敗・キャンセル・スキップ0）。穴付き領域の外周・穴の逆向き閉路、独立した符号付き面積、Euler標数、共有辺の逆向き使用、射影の折り返し点と正負領域、閉路の全接続を確認しました。250ソースのハッシュとステージ済みソース・テスト516ファイルの内容一致を確認しました。全リポジトリの検証や新規形式証明は主張しません。

追加分割後の複合辺には厳密な `lower` / `upper` を記録します。元の境界辺への参照は代表使用であり、元の辺全体と同じ区間とは限りません。`nurbsSourcePlaneCellComplexEdgePoint3` は所有された複合体から追加分割後の区間だけを評価します。各セルの辺順は分割後も保持し、全ての接続を再検査します。

パッチ間の拡張は、独立スナップショットでビルド、関連3ファイルのstrict型検査、関連6ファイル29テストが成功しました（9747.2925 ms、失敗・キャンセル・スキップ0）。4パッチの共面領域、式が変わる連続曲面の不一致な射影区間、共有辺の追加分割・両端点評価、正負領域と閉路を確認しました。250ソースのハッシュとステージ済みソース・テスト517ファイルの一致を確認しました。
