# 認定NURBS面の厳密なUV照会

`evaluateNurbsSourceComplexFace3` は所有された境界複体、元の面ID、厳密なu/vを受け取ります。面IDは配列位置ではありません。未準備の複体は未解決、不正な面IDや複製した複体は例外です。

まず既存の厳密なUV層照会で、指定した面の閉包に点が属するかを調べます。穴や別の面、外部の点は `outside` を返し、曲面上へ勝手に延長しません。照会が未解決の場合もそのまま伝播します。

## パッチ側の選択

- UV頂点とノット分割イベントでは、閉階数検査で記録された、その面から近づけるパッチ扇形だけを選びます。点だけで接する外側パッチは含めません。
- 境界辺の通常点では、面の向き付き境界使用と有限区間からパッチを選びます。同じUVの不連続継ぎ目で、反対の面のパッチ側を選びません。
- 開いたUV面の点では、その点を含む閉パッチを全て選びます。面境界から離れた近傍なので、内部ノット上の全ての側も面内から近づけます。

選択した全パッチを厳密に評価し、全3D点の一致を再確認します。正の埋め込み・連続性認定に反して像が異なる場合やパッチ被覆が失われた場合は内部不変条件違反として失敗します。返り値は共通3D点と全パッチ側の像を保持します。

`stratum` はUV配置上の face/edge/vertex です。wireや孤立した交差接点も含むため、これを材料の内部・境界や立体の所属と解釈してはいけません。3D点からの逆照会や最近点もこのAPIの範囲外です。

## 回帰

穴・外部・閉境界、u²を持つ非線形面の代数的UV、左右で3D像の違う継ぎ目と端点、連続な内部ノットの両側評価、所有とID検査、未準備入力、曲線SSI上の代数的点と両側面、孤立接点を検査します。端点の既定のノット側評価に依存しません。一般曲面面群の大域的非交差・閉じた殻・材料認定は引き続き必要です。
