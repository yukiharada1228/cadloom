# NURBS面の境界と共通BRep接続

`sewAffineNurbsFaces3` は、所有された `AffineNurbsFace3` の閉境界を、共通BRep接続エンジンへ渡す。面ごとの埋め込みは既存の面コンストラクターが確認する。一方、面同士の内部交差、殻全体の埋め込み・包含・材料はこの処理で認定しない。

## 共通エンジン

`BRepFaceInput3`、`BRepFace3`、`BRepTopology3` の支持面型をジェネリックにした。省略時は従来の `Surface3` のままである。内部の `buildBRepTopologyWithGeometryAdapters3` は不変な曲線・支持面の検査をadapterへ委譲し、頂点の厳密な統合、共有稜線、coedge、twin、頂点リンク、shell、境界巡回、接続診断を既存の同じ処理で構築する。従来の解析曲面入口は同じ支持面snapshotと全曲線検査を維持する。

NURBS側の支持面値は、元の所有された埋め込み面そのもの。曲線値は、所有されたlift済み境界とそのpiece番号である。外周・穴・元のパラメータ曲線・パッチ分割片の由来を `sourceUses` に残す。

## 区間全体の共有辺検査

二つの閉じた境界片の端点を正方向と逆方向で照合する。区間端点から得るパラメータ対応が有理係数のアフィン写像なら、元の全同次座標多項式へ代入する。3座標すべてで分母を払った恒等式が成立するときだけ、同じ稜線として共有し、元の巡回方向をcoedgeへ保持する。端点・中点・代表点の一致だけでは統合しない。正の重みと認定済み単純境界の制限から、各片の非退化・分母非零と閉区間の対応が得られる。

曲線全体が元の面の境界の一片とこの意味で一致することをadapterの全曲線所属検査にも用いる。支持面の数点への所属に置き換えない。全境界片は面から直接列挙し、穴や一部の境界を省略しない。

## 未対応

全区間の有理アフィン対応による一致は十分条件であり、一般の非線形再パラメータ化による像の一致判定ではない。別の面の端点が片の途中にある場合の自動分割、T字接続の修復、欠けた内部交差点の発見はまだ行わない。一致を確認できない片は異なる稜線として残り、境界・非多様体などの診断を返す。閉じた接続フラグを一般NURBSソリッドの認定と解釈してはいけない。既存の平面・円柱の自動分割能力をこの新入口の能力と混同しない。

共通Bodyへの採用、混合する解析面との縫合、携帯可能なNURBS面・境界レコード、保存復元、一般曲面の自己交差・材料検査は残る。

## 検証

新規試験は、異なるUV座標系と曲線パラメータ区間を持つ隣接する曲面の共有辺、6面の立方体の12稜線・8頂点・24coedge・閉じた向き付き接続、端点と中点が一致しても異なる曲線の非統合、所有検査、元の曲線への由来、未対応の途中分割が閉接続と誤認されないことを確認する。既存の解析曲面・混合BRep・NURBS面・解析曲線縫合の試験も回帰する。これはTypeScript全体の形式証明ではない。
