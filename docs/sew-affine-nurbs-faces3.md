# NURBS面の境界と共通BRep接続

`sewAffineNurbsFaces3` は、所有された `AffineNurbsFace3` の閉境界を、共通BRep接続エンジンへ渡す。面ごとの埋め込みは既存の面コンストラクターが確認する。一方、面同士の内部交差、殻全体の埋め込み・包含・材料はこの処理で認定しない。

## 共通エンジン

`BRepFaceInput3`、`BRepFace3`、`BRepTopology3` の支持面型をジェネリックにした。省略時は従来の `Surface3` のままである。内部の `buildBRepTopologyWithGeometryAdapters3` は不変な曲線・支持面の検査をadapterへ委譲し、頂点の厳密な統合、共有稜線、coedge、twin、頂点リンク、shell、境界巡回、接続診断を既存の同じ処理で構築する。従来の解析曲面入口は同じ支持面snapshotと全曲線検査を維持する。

NURBS側の支持面値は、元の所有された埋め込み面そのもの。曲線値は、所有されたlift済み境界とそのpiece番号である。外周・穴・元のパラメータ曲線・パッチ分割片の由来を `sourceUses` に残す。

## 区間全体の共有辺検査

高速経路では、二つの閉じた境界片の端点を正方向と逆方向で照合する。区間端点から得るパラメータ対応が有理係数のアフィン写像なら、元の全同次座標多項式へ代入する。3座標すべてで分母を払った恒等式が成立すれば、同じ稜線として共有し、元の巡回方向をcoedgeへ保持する。端点・中点・代表点の一致だけでは統合しない。正の重みと認定済み単純境界の制限から、各片の非退化・分母非零と閉区間の対応が得られる。

曲線全体が元の面の境界の一片とこの意味で一致することをadapterの全曲線所属検査にも用いる。支持面の数点への所属に置き換えない。全境界片は面から直接列挙し、穴や一部の境界を省略しない。

## 未対応

全区間の有理アフィン対応による一致は十分条件であり、一般の非線形再パラメータ化による像の一致判定ではない。全入力境界片の端点で自動分割する。[境界交差](affine-nurbs-boundary-intersection3.md)で内部交差点と非線形なパラメータ関係も検出する。版173では[関係の双方向区間被覆](nonlinear-nurbs-boundary-sharing3.md)により非線形な対応の共有辺も統合する。一致を確認できない片は異なる稜線として残り、境界・非多様体などの診断を返す。閉じた接続フラグを一般NURBSソリッドの認定と解釈してはいけない。既存の平面・円柱の自動分割能力をこの新入口の能力と混同しない。

共通Bodyへの採用、混合する解析面との縫合、携帯可能なNURBS面・境界レコード、保存復元、一般曲面の自己交差・材料検査は残る。

## 検証

新規試験は、異なるUV座標系と曲線パラメータ区間を持つ隣接する曲面の共有辺、6面の立方体の12稜線・8頂点・24coedge・閉じた向き付き接続、端点と中点が一致しても異なる曲線の非統合、所有検査、元の曲線への由来、途中分割の異なる境界を自動分割して共有することを確認する。既存の解析曲面・混合BRep・NURBS面・解析曲線縫合の試験も回帰する。これはTypeScript全体の形式証明ではない。

## 全端点での自動分割（版170）

元の全境界片の空間端点を厳密に重複排除し、全ての片上でそれぞれの点の全逆像を求める。非定数の有理座標N/Wと対象の代数座標の定義多項式Pから、W^deg(P) P(N/W) の全実根を求める。元の閉区間内かつ3座標の再評価が対象点と厳密に等しい根だけを切断位置に採用する。共役根、同じ一座標を持つ別の点、区間外の根は捨てる。重みは正であり、曲線は埋め込み面の単純境界の制限なので、少なくとも一つの空間座標は非定数で、逆像は有限である。

切断位置を整列・統合して正の幅の閉区間へ分け、全区間の多項式恒等式による共有検査へ渡す。曲面の節点から生じる代数的な端点も対象。`AffineNurbsBoundaryEdge3` のlower/upperは元の境界pieceのパラメータに対する閉区間であり、元のpieceの全範囲とは限らない。`affineNurbsBoundaryEdgePoint3` は所有とこの閉区間を検査する。既存のsourceUsesは元の曲線の巡回順で増えた片を保持する。

この分割は入力に存在する端点で完全であり、版172では[境界交差](affine-nurbs-boundary-intersection3.md)の全イベントもこの分割へ渡す。面内部どうしの交差の発見ではない。殻の埋め込み・材料認定・共通Bodyの保存復元は残る。
