# 再切断後の殻包含を再計算

`analyzeNurbsRecutContainment3` は所有された再切断境界の埋め込み認定を受け取り、新しい閉じた殻ごとに有限source面の内部サンプルを選びます。元のセルサンプルのUV・空間像・子領域の内部所属を確認し、正確な有理数座標として表せない場合は未解決です。座標を丸めてサンプルを創作しません。

各サンプルを他の全ての新しい殻へ偶奇照会し、互いの包含と推移性、祖先が鎖になることを検査して、containers・直接のparent・depthを保持します。既に認定された互いに交わらない連結閉曲面では、一つの殻の面上の点は他の殻の内外を変えないため、このサンプルで殻全体の包含を分類できます。予期しない接触、未解決の照会、方向予算切れは認定しません。

切断で以前の空洞が外部へ開くことがあるため、以前の殻番号や深さをコピーしません。回帰では、切断後も閉じている空洞と島に深さ0・1・2を割り当て、空洞を開く別の切断では新しい外側と島を独立した深さ0の殻として分類します。

各ノードの `expectedOrientation` はdepthから得た期待値であり、実際の面法線がその向きであることの検査ではありません。次は方向付き交差列による実際の向き、全境界ギャップ内の材料サンプル、材料証明書と共通Bodyへの採用です。今回の偶奇・包含は、全TypeScriptの形式検証や一般曲面Booleanの完成ではありません。
