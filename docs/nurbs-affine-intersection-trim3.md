# NURBS交差の両トリム領域による制限

`trimNurbsAffineIntersection3` は、所有された[閉パッチ交差](nurbs-affine-intersection3.md)を、元と相手の両パラメータ領域で制限する。外周・穴の定義を再検査し、入力のlocate/sampleは信用しない。`intersectAffineNurbsFaces3` は所有された二つのアフィンNURBS面から、元の交差と両トリムの制限を一括で構築する。

元の曲面は一般の正重みNURBSでもよく、相手にはアフィン左逆写像を要求する。面の直接APIでは両方が所有された埋め込み面だが、低水準の交差制限で元側まで単射に限定していない。

## 有限な境界枝の分割

全境界spanを[陰関数化](nurbs-parameter-implicit2.md)し、支持多項式と元spanの端点座標を集める。全支持多項式の積のグラフを両軸方向へ射影し、特異点・交点・垂直成分・極値などを分離する全イベントの座標も加える。端点・イベントは線の式、または代数座標の定義多項式として保持する。共役根などで余分に分割しても、実際の所属は別に判定する。

相手のパラメータ座標は元の(u,v)の有理式A/W,B/Wであり、元の重みWは閉パッチで正である。相手の全分割多項式Fを、W^totalDegree(F) F(A/W,B/W)として元の座標へ厳密に引き戻す。元の領域の分割多項式も加え、元グラフとの全有限交点、共有因子、垂直fiberから切断位置を求める。保持された元の閉辺区間内で全イベントを整列して分割する。

各開区間は元・相手の実際の検査済みdomain.locateで分類し、両方がinsideまたはboundaryのものを保持する。閉端点と孤立接触も個別に分類する。多項式F=0だけでboundaryとしない。有限の四分円と、同じ円支持を持つ反対側の枝は異なる結果になる。

## 分類が一定となる根拠

検査済みの単純な有限spanの像は、支持曲線の正則な開枝では、端点・特異点を除くと全体を覆うか全く覆わないかである。全span端点の座標線と、積の両軸の射影イベントを加えることで、その切替点を分離する。平面の支持曲線外では閉じたJordan領域への所属は連結成分ごとに一定であり、支持曲線上でも有限枝の分類が一定になる。

正重みの有理チャートは元の閉パッチ上で連続である。その引き戻しの連結な分割セル・開グラフ辺の像は、対応する一定分類の層内に留まる。支持多項式が元の全枝上で恒等的にゼロでも、端点・両軸イベントの引き戻しが有限枝の切替を分離する。片方のイベント線上へ像が潰れる場合も、他軸のイベントで分離し、両座標が固定されれば像は同じ点である。

これは新実装の数学的契約の説明であり、TypeScript全体の機械証明ではない。

## 重なったパッチの暗黙領域

元の非空なregionについては、元のパッチ矩形で、両領域の分割多項式と相手パッチの4閉範囲条件の全符号セルを列挙する。元の空間一致と両domain所属を満たすwitnessがある場合だけregionを残す。穴に完全に含まれる場合は空とし、線だけ・角だけの接触は捨てない。

regionは非空な閉パラメータ集合であり、全境界や連結成分を列挙したものではない。正の面積や空間像の次元も主張しない。元の曲面が1次元へ潰れ、像全体が同じ陰関数支持上にある場合も、実際の有限枝への所属を使う。

## 結果と評価

sourceIntersectionPatchとsourceEdgeで元の結果への対応を保持する。追加の支持・イベント線により、必要以上に細かい分割を含む場合がある。sourceLocation/targetLocationはそれぞれのパラメータ領域の分類であり、空間像や材料の境界ではない。辺のラベルは開区間に適用し、端点はverticesの分類を見る。

`trimmedNurbsAffineIntersectionEdgePoint3` と `trimmedNurbsAffineIntersectionRegionPoint3` は、所有、番号、保持範囲、元の交差の一致と両トリム所属を再確認する。sourceのseamや別パラメータの同じ空間点は統合しない。

## 検証と残る範囲

穴で切れる双曲線、三次の曲線境界、非線形チャートの無理数切断、同じ支持上の有限四分円と別枝、穴を持つ重なり・線・角・空集合、孤立接触、階数1の元曲面、偽のdomain・所有・範囲、保存復元後の直接面交差を確認する。分母を払う代入は、全次数と独立した25の有理評価でも照合する。

面領域そのものの分割、seamをまたぐ混合次元の全体位相、regionの全境界列挙、アフィン左逆写像を持たない相手との一般NURBS SSI、殻の幾何・材料認定、共通Bodyへの採用は残る。
