# 再分割した全元面と旧キャップの一括接続

`joinNurbsRecutAssembly3` は全旧有限面を再縫合した所有された面集合、各旧有限面のキャップ共通区間証明、旧キャップの採用面をまとめて接続します。全旧有限面の対応をちょうど一度要求し、キャップを一度だけ採用します。入力は前回の集合へのpreviousを持ち、両側を保持した再縫合結果である必要があります。

元面同士ですでに共有しているsource辺は同じ入力辺として維持します。旧section境界だけを面ごとの区間表で展開し、元面とキャップに同じshared辺を使わせます。キャップの親辺が元面側だけの投影イベントで細分化される場合も、両者を共通断片列へ置き換えます。逆向き使用では列と各方向を反転し、各入力辺・面から出力への対応を保持します。

全体を共通B-repエンジンで再構築し、closedOrientedIncidenceと全shared辺の元面／キャップからの双対使用を要求します。全キャップを採用しても閉鎖できない場合はincidenceとして未解決です。欠けた面対応、別の前回集合、重複・欠落キャップや片側のみの入力は拒否します。旧sectionが二つの旧元面に共有される構成の一括処理はまだ対象外で、単一の元面所有者を要求します。

曲線は元の区間と代数的座標を保ち、縫合済みsource辺も元の評価器へ戻して評価します。有限面クエリは所有された元の領域へ委譲します。円筒端面など元からある追加の区切りは削除しません。

これは両側の新しい分割線を含む、旧キャップ付き形状全体の閉じたB-rep接続です。新しい二つの子立体を作る処理ではありません。側ごとの面抽出、新しい切断平面の閉鎖面、幾何学的埋込み・シェル包含・実材料方向の再認定、保存復元を含む再切断Body APIは残ります。閉鎖した接続構造だけから材料や幾何学的埋込みを主張しません。
