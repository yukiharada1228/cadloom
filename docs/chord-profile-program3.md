# 有理端点の混合プロファイルを弦と弓形へ分解

支持の積・差と和の候補が一致しない場合、円弧を弦へ置き換えた多角形と、各円弧と弦の間の領域をパリティで合成します。候補全体と元の領域の2D XORが空であることを検査した後にだけ、材料定義を返します。

多角形部分は既存の厳密な平面ソリッド定義へ変換します。弓形は有限円柱と弦の半空間の積です。反時計回りの弧は始点→終点の弦の右側、時計回りの弧は左側を選びます。半円より大きい弓形でも同じ向き付き条件を使います。これらをXORで合成し、直線境界が円弧へ置換される形を保持します。内部の弦は最終境界として残しません。

この分解は全ての対象端点に有理座標を要求し、無理数を丸めて弦を作りません。他の支持条件経路が扱える無理数端点は引き続き扱えます。分解の有理多角形部分が既存の平面ソリッド検査を通ることも必要です。任意の曲線プロファイルを必ず受理する完全なコンパイラーではありません。

凹な丸み付きL字を共通Bodyとして構築・保存復元し、欠けた角を維持することを確認しています。小さい弓形と大きい弓形は、独立した円と半空間の不等式との点格子照合も行います。領域照合は既存の厳密2Dカーネルを利用する実行時検査であり、TypeScript全体の機械的形式検証を完了したという主張ではありません。
