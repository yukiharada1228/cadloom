# 縫合NURBS材料への点の所属

`locateSewnNurbsSourceMaterial3` は認定済み材料境界と有理点または代数的座標を受け取り、`inside`、`outside`、`boundary`、`unresolved` を返します。材料境界の認定をコピーしたオブジェクトは拒否します。

最初に全ての有限面へ正確な逆照会を行います。支持面だけでなくトリムされた面への所属を検査し、境界上の場合は元の面と殻の番号を返します。未知の所属を無視して内部や外部へ分類しません。

境界外の有理点では殻ごとの交差偶奇を照会します。包含する殻は、認定済み包含木で根から途切れない一本の列であることも検査します。包含殻の数が奇数なら材料内部、偶数なら材料外部です。したがって空洞は外部、空洞内の材料島は内部です。深さが最大の包含殻と、包含殻の一覧も返します。

代数的な点は浮動小数点へ変換しません。各座標の厳密な隔離区間で有理数の閉じた箱を作り、その箱と全有限面が交わらないことを検査します。検査はNURBSの同次多項式による六つの箱不等式と、有限面の境界・頂点の分割を用い、各候補で実際の面と接近パッチへの所属も照合します。箱と境界が交わる間は隔離区間を精密化します。

対象点が有限個のコンパクトな面からなる境界の外にあることは最初の逆照会で確認済みです。そのため境界までの距離は正であり、縮小する箱はいずれ境界と分離します。箱が境界を含まなければ、その箱の中心と元の代数的点は同じ補集合成分にあり、中心の有理点での所属を採用できます。結果には `rationalWitness` と `enclosure` を保持します。有理点では箱はその点だけです。

半直線探索の予算切れ、面の逆照会や箱所属の未解決はそのまま伝播します。極めて境界に近い代数的点では精密化と多項式分割が高価になる可能性があり、このAPIに計算時間の上限はありません。共通Bodyへの採用や材料集合演算はまだ接続していません。新規の形式証明は追加していません。
