# 材料プログラムの厳密な整理

`compactCylinderMaterialProgram3(program)` は、所有された有限円柱・半空間の材料プログラムを同じ材料式の意味を保って整理します。新しい幾何や近似を作りません。同じプログラムの結果はWeakMapで再利用し、出力は既存の所有された不変プログラムです。

- 円柱は軸原点・方向・半径の二乗・有限パラメータ区間がすべて一致する場合だけ統合します。同じ支持円柱でも有限範囲が異なれば統合しません。別の軸パラメータ表現まで幾何的同値を解く処理ではありません。
- 半空間は法線とオフセットの全係数が正の比例関係にある場合だけ統合します。負の比例関係は別変数です。支持平面だけが一致しても、正負の材料側を混同しません。
- 同じ変数へ参照を更新した上で、同一部分式の和・積、差・XOR、および空集合の恒等式を簡約します。可換な演算の子の順序も内部で揃えます。分配則で展開する完全な論理式最小化ではありません。
- 簡約後に参照されない支持形状を除きます。空集合は、既存スキーマが要求する円柱1個を運ぶ `A - A` で表します。

出力の円柱・平面の番号は新しい表への番号です。入力の番号、面の番号や並び、保存JSONのバイト一致を保持するAPIではありません。幾何的なεやサンプル点で同値性を決めず、厳密な係数一致とBoolean恒等式に限定します。境界上で逆向きの厳密半空間が互いの論理的補集合になるとは仮定しません。

共通 `splitBodyByPlane3` は曲面経路の親プログラムと、半空間を追加した各子をこの処理へ通してから境界を再構築します。これにより再切断で同じ平面が別の支持変数として増えることを抑えます。処理時間の短縮率、式サイズの固定上限、一般的な同値判定や曲面境界の由来対応は保証しません。
