# 両世代のキャップを両半平面の閉境界へ分割

`splitNurbsRecutCapBoundaries3` は最終の閉再切断境界・face番号・有理平面を受け取り、旧キャップの残存面と新キャップを同じ処理で分割します。完全な有限面断面と、最終共有辺の全native分割を使用します。

結果は空間頂点・境界曲線片・負側と正側の有向閉ループを保持します。`sourceEdges` は元loop・coedge・共有edge・向きと、全native区間を隙間なく覆う子辺使用を返します。配列はnative昇順なので、負方向の親loopへ挿入する場合は配列順も反転します。切断で新設する直線片は両側で同じedgeを逆向きに使います。曲線評価は所有された元曲線のnative区間を保持し、メッシュや近似線分へ置き換えません。

既存境界が切断平面に含まれる場合は、その曲線片の全区間に対する断面結果からゼロ区間を取り、断面直線に沿う端点差の符号・元coedgeの向き・面のchart向きを組み合わせて、有限面が隣接する側だけに採用します。完全な埋め込まれた境界曲線が直線上にある区間なので、nativeパラメータの向きは異なる両端点で決まります。断面のboundary spanは新しいcut辺として重複追加しません。孤立接触は面積ゼロの反対側の面を生成しません。

支持平面全体が一致する場合は `coplanar` として未解決にします。断面照会が未解決、重なりの向きを確定できない場合、有向境界が分岐・零長・閉じない場合も未解決です。閉ループだけを材料立体とは認定しません。

検証では、両世代の非線形native境界、全区間被覆とcoedge由来、両側の閉接続と切断辺の逆向き共有、独立した平面面積、穴を開く切断と島、円弧の代数的端点、接線の片側空集合、既存辺との全区間重なり、両切断の負側、平面反転、反射とスケール、斜め平面、10^-40幅の正面積領域を検査します。

次は閉ループの外周・穴を有限面へグループ化し、残存source面の再分割と全世代のキャップを共有区間で縫合する必要があります。三回目以降の閉立体切断、任意回数の構築record、新しい埋め込み・殻包含・材料認定、一般NURBS Boolean、SolidCraft全体の純粋TypeScript再実装は引き続き未完了です。
