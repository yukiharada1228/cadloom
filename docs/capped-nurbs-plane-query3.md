# キャップ付きNURBS分割結果の位置判定

`locateNurbsPlaneSplitFace3` は所有された元面の分割領域に対して、空間点が有限面のinside/outside/boundaryのどこにあるかを厳密に判定します。まず認定された元の有限面へXYZを逆写像し、該当領域の閉じたUVセルの和に含まれるか調べます。slabのイベント端点と上下の元グラフ枝を使うため、イベント上の点も扱います。その後、領域の実際のnoded境界辺と比較します。同じ領域内で消去された人工的なセルの継ぎ目を面境界として返しません。

`locateCappedNurbsPlaneFace3` は所有された閉じた接続結果と面IDを受け、元の分割面と新しい平面キャップを共通の空間点APIで問い合わせます。キャップでは点が支持平面上にあることを厳密に確認してから有限な外周・穴を判定します。逆写像やキャップの問い合わせが未解決なら、その状態を伝搬します。

`locateCappedNurbsPlaneMaterial3` は元の材料と選択された半空間の正則化された選択に対するinside/outside/boundaryを返します。厳密に反対側の点はoutsideです。選択側または切断平面上の点では、新しく採用された有限境界面を先に問い合わせ、接続結果の面ID・シェルIDを返します。境界にない選択側の点は、元の検証済み材料の位置判定と照合します。

平面上で元の材料内部にあるのに対応するキャップ領域がない場合や、選択側の元の境界点に保持された有限面がない場合は、outsideへ丸めず未解決結果を返します。元の境界上の接触点でも、選択側の新しい境界面に属さないものは自動で引き継ぎません。例えば円柱の外側へ接平面で切った空の選択に、元の接線だけをboundaryとして残しません。保持される側では同じ線は境界のままです。

有理・独立した実代数的な空間座標を受けます。元の材料問い合わせの由来はoriginalで保持しますが、そのシェル番号を新しい子立体の包含番号として扱いません。新しい閉じた表面に対する独立したグローバル埋込み・材料証明、シェルの包含・子立体の採用、共通Body API・保存復元・再切断は引き続き未完成です。このAPIはそれらを構築するための位置判定であり、新しいBody認定を発行しません。
