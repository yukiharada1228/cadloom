# NURBS曲面交差のターゲット座標消去

`nurbsAffineIntersectionEquations3` は、一般の正重みNURBS曲面Sと、所有されたアフィン左逆写像Pを持つターゲットTから、全閉パッチ対の厳密な交差条件を構築する。元の曲面Sは折り返し、階数低下、不連続な一側パッチを持ってもよい。ターゲット側の証明書を省略して一般曲面どうしの認定とすることはできない。

このAPIは交差の方程式と閉じた所属判定を作る段階であり、全根・交線グラフ・トリム付き交差・面分割を列挙する完成済みSSIソルバーではない。

## 4変数から2変数へ

通常の一致条件 S(u,v)=T(a,b) にPを適用すると、ターゲットの左逆写像の恒等式により (a,b)=P(S(u,v)) が必要となる。元の同次パッチを (X,Y,Z,W) とすると、a=A/W、b=B/Wで、A,BはPの有理アフィン係数を元の同次座標へ適用した二変数多項式になる。

ターゲットパッチの全同次多項式Qについて共通次数dを選び、W^d Q(A/W,B/W)を二変数多項式として厳密に構築する。その4成分をXt,Yt,Zt,Dtとすると、返す3つの残差は X Dt−W Xt、Y Dt−W Yt、Z Dt−W Zt である。小数近似やサンプル補間で係数を決めない。

元の閉パッチ矩形内ではW>0。さらに(a,b)がターゲットの閉パッチ内ならDt=W^d Wt(a,b)>0。したがって両矩形の条件の下で、3残差の零点は元の空間一致と同値である。必要性だけの投影条件ではなく、空間3座標の一致を保持する。これは新実装の機械証明ではない。

## 公開結果と評価

`pairs` は元パッチとターゲットパッチの全組合せを保持し、各対にA,Bと3残差を持つ。A,Bの共通分母はsourcePatch.weight。残差だけを解いても、両パラメータ矩形の条件を満たすとは限らない。残差が全て恒等的にゼロでも、有界な共通部分の非空性や面積を宣言しない。

`nurbsAffineIntersectionContains3` は元の閉矩形、ターゲット座標の閉矩形、3残差を検査し、両パッチの空間再評価も独立に照合する。`nurbsAffineIntersectionPoint3` はそれを満たす場合だけ元の(u,v)、ターゲット(a,b)、空間点を返す。偽の証明書やレポート、無効な対番号、所属しないパラメータを拒否する。結果は不変である。

元のパッチが折り返す場合、同じ空間点へ写る複数の(u,v)を捨てない。節点の一側パッチやターゲットの閉seam上の複数の由来も統合しない。次のソルバーはこれらを保持しつつ、零点の曲線・孤立点・恒等的な領域を両矩形へ制限する必要がある。

## 検証

独立して分かる双曲線uv=1/4の係数と交点、斜めのターゲット座標系と10^30の平行移動、非定数の有理重み、折り返した元曲面の同じ空間点に対する二つの解、恒等零でも必要なターゲット範囲、一側の不連続パッチ、所有・範囲・不正な候補の拒否を試験する。
