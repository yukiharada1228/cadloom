# NURBSキャップ境界の厳密な回転数

`partitionSewnNurbsSplitEdgeByPlane3` は所有された有限分割辺を別の有理平面で完全に分割します。元の共有辺は有理曲線の同次平面式の全実根を使います。内部辺は元のUVグラフ上の完全な多項式イベント分割を使い、定数u/vの経路は代数的な固定座標も含めて厳密なfiber rootsを求めます。

結果のverticesは両端点と孤立交点を、intervalsは各開区間の一定符号を保持します。接するだけの零点も残し、符号0の区間は平面上の重なりです。有限個のサンプルから交点の完全性を推測しません。まず全イベントで区切り、各開区間の一定符号を厳密な内部パラメータで決めます。元の有限曲線とnative parameterを維持します。

`queryNurbsPlaneCapWinding3` は所有されたキャップ境界と有理チャート点に対し、各ループの整数回転数を返します。境界上の点はloop/edge付きboundaryです。水平線から始め、傾き0,+1,-1,+2,-2,...を試します。頂点や重なりを通る方向は再試行し、開いた辺内部の交点では前後の符号変化とループ方向から回転数を加算します。接線では前後の符号が変わらず加算されません。境界上の連続した直線区間の点は、単射な元曲線の連続像と厳密な端点座標の範囲から判定します。

maxDirections（既定16）の予算で解決しない場合はunresolvedを返し、外部とみなしません。一般の代数的チャート点はまだ入力対象ではありません。回転数は曲線の問い合わせ結果であり、自己交差の不存在、材料方向、外周・穴の分類、ループ包含の森、キャップ面、子Bodyの認定ではありません。複数ループの回転数の合計を材料として自動採用しません。

相関したUV座標を同次多項式で評価する際の除算は、記録された共通代数パラメータを保つ積の計算に変更しました。無関係のパラメータは従来の厳密計算にフォールバックし、零分母は引き続き例外です。共通の3次パラメータによる独立な有理式との一致、次数上限、零分母を回帰テストします。
