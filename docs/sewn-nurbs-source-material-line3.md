# NURBS材料と直線の閉集合交差

`intersectSewnNurbsSourceMaterialLine3` は、所有された材料境界の認定と有理数の直線を受け取ります。結果は材料と直線が重なる最大の閉区間、および孤立した接触点です。区間端点の代数的な直線パラメータ、空間座標、面・UV・パッチ側の交差情報を保持します。

全ての有限面との直線交差を集約して厳密に並べ、隣り合うイベント間に有理パラメータを選びます。その有理空間点を材料へ照会し、開区間が材料内部・境界・外部のどれにあるかを判定します。有限面の直線交差報告には重なり区間の端点も含まれるため、イベント間に所属の変化はありません。未解決の面交差や所属判定は、部分的な成功結果にせず未解決として返します。

材料内部または境界にある隣接区間を結合し、最大の閉区間を作ります。ただし `spans` に開区間ごとの内部／境界の区別と有理標本点を残します。材料は閉集合なので、区間端点も含まれます。どの保持区間にも隣接しない境界イベントは孤立点です。面群は有界なので、最初のイベントより前と最後のイベントより後は材料外部です。

これは横断数を退化した交差へ無条件に適用する処理ではありません。元の境界報告が `degenerate` であっても、区間の正確な所属を別に確認できれば、接線接触・パッチの継ぎ目・辺上・面上の重なりを解決できます。境界報告とその退化理由はそのまま残します。要求された直線を別方向へ動かすことはありません。

立方体の方向反転とパラメータの拡大縮小、空洞と材料島の三つの区間、空洞面に沿う内部／境界／内部の連結、円柱の代数的端点・継ぎ目・孤立接点・母線上の境界区間、未解決伝播、所有確認、零方向拒否をテストします。

共通Bodyへの統合、面を切る処理、材料同士の3D集合演算は未実装です。この区間走査そのもののLean形式証明は追加していません。
