# 有限曲線による平面の分割

`partitionPlanarFaceByCurves3(face, curves)` は、検証済みの平面領域に有限な直線区間・円弧・楕円弧を挿入し、厳密な縦分解セルと共有辺を構築します。`partitionPlanarFaceByCylinders3` と同じ分解エンジンを利用します。入力曲線は全体が面の支持平面に属することを検査し、面からはみ出す部分は材料のセルにしません。曲線の支持直線・支持円まで無制限に延長する操作ではありません。

各セルには閉じた境界、厳密な内部点、領域判定があります。`sewn` の face と cell は同じ順序に対応し、既存の `sourceUses` によりセル境界の各曲線から向き付き共有辺へたどれます。分解のための人工的な縦辺を残します。内部で終わる切断線は元の面を別の連結成分にするとは限りませんが、縦分解はその端点を共有辺の頂点として保持します。

このため共通の `sewBRepFaces3` にも `splitPoints` を追加しました。有限曲線の端点・交点・極値を境界の分割へ渡します。線分の縦向きの端点も人工的な縦辺上の頂点となります。既存の円柱分割には新たな切断点を渡さず、以前の分割とレコードの再現性を維持する経路を残します。その互換性は全体回帰でも検査中です。

`intersectPlanarCylinderFaces3` が返す有限曲線を入力できます。支持面全体の交差を再計算せず、実際の交差片を面のセル境界へつなぎます。交差の接触多重度はこのAPIで材料の内外へ変換しません。一般曲面の分割、円柱SSIの平面曲線化、NURBS、材料の両側分類、生成セルの統合と商用CAD互換は未完成です。

検査には、有理座標の独立した点集合による領域被覆と内部の重複排除、交差・内部で終わる線分の端点、切断方向の反転、円の内外の一定性、有限面の交差曲線、有限な半円、穴、面外の切断線、非共面の曲線全体の拒否を使います。関連39件が成功。隔離ビルドと既存133宣言の限定監査も成功しました。新規API自体の形式証明ではありません。
