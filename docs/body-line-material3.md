# 直線上の閉じた材料区間

`intersectBodyLineMaterial3(body, origin, direction)` は、所有された有界 `Body3` または `CellularBody3` と直線 `origin + t * direction` の交わりを、最大の閉区間と孤立接触点へ分けます。負のtも含み、方向が単位長であることは要求しません。パラメータを物理距離として扱わないでください。

全シェルの完全な境界イベントを取り、隣り合うイベントの間に厳密な有理パラメータを選びます。その点の材料位置を既存の正確なBody照会で検査します。イベントの間に境界がないことと、Bodyが有界であることから区間を選択します。空洞の境界を落とさないため、一つのシェルだけを選ぶ引数は設けません。

`intervals` は実際の開始・終了イベントと、材料の厳密な内部にある有理の証人点を持ちます。連続する材料区間は閉集合として連結する場合に結合し、内部の接触イベントは `boundary.hits` に保持します。区間に含まれない接線接触は `isolated` に残します。区間内の全点が立体の厳密な内部だという意味ではなく、空洞への接点などの境界点を含む場合があります。

支持面包含や共有辺・頂点に沿う退化は `kind: 'degenerate'` と元の境界照会を返し、区間を推測しません。零方向、不正なBody所有は拒否します。浮動小数のepsilonや表示メッシュは使いません。


CellularBodyの区間分類には、その所有された構築材料の厳密な位置判定を使います。境界変換のための一時的な旧式の殻参照から材料を推測しません。辺・頂点接触の特異イベントは引き続き退化として返します。
