# 材料の真偽範囲と分割線の証人点

平面セルの全支持分類が内部のゼロを検出しても、そのゼロが最終材料へ影響するとは限りません。未知の述語を `[false,true]`、既知の述語を同じ真偽値の上下限として扱い、材料ASTの和・積・差・XORに沿って保守的に範囲を伝播します。両側の真偽範囲がそれぞれ単一の値になった場合だけ、追加分割なしに分類します。未知の結果を推測で確定しません。再分割は未解決セルの支持に限定します。

支持の完全なゼロ曲線とセルの境界の交点で区間を分ける処理は維持します。直線の各区間の内部点には、確認済みの支持直線と、正確な代数的端点の間にある有理座標を使います。支持直線の基点と方向が有理なら点全体を有理で構築できます。所有された共通の有理方向と基点の有理な軸座標が得られる場合も、その軸で内部座標を選んで基点を移動します。それ以外は既存の一般的な証人点構築を使います。

選んだ点は支持直線上かつ区間の厳密な内部にあります。端点を浮動小数へ丸めたり、ゼロ集合の一部を省略したりはしません。別々の代数的端点の差や平均を不必要に合成する処理を避けるための変更です。

補助円柱を持つ箱との連続演算を調査し、旧実装の実行スタックで不要な分割と証人点の体の合成を確認して追加しました。新規4件で不要なゼロの分類、必要なゼロの再分割、有理キャリアと無理数位置の円柱母線の厳密な内部点を検査しています。箱との連続演算全体の回帰は別に継続中で、完了とは扱いません。
