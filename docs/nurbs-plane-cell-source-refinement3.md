# セル頂点による共有辺の追加分割

`refineNurbsSourcePlaneEdgeParameters3` は、所有された共有辺の平面細分化と追加パラメータを受け、以前の全ての分割点を保ったまま再構築します。入力の辺番号と有限区間を全て検査してから、新しい辺を作ります。重複する分割点は厳密な等値比較でまとめます。

追加パラメータは元の共有辺のnative parameterです。元の辺に対して一度だけ分割列を作り、両側の面のcoedgeへ同じ子辺列を適用します。元の辺からの対応に加え、直前の子辺から新しい子辺への `sourceUses` を返します。各子区間が直前の区間を隙間なく被覆し、平面符号を保つことを検査します。元の面・senseと接続の認定条件も再検査します。

`refineNurbsPlaneCellSourceVertices3` は所有されたセル頂点の対応表から追加パラメータを集め、共有辺を再細分化し、全ての入力対応表を新しいトポロジーへ付け直します。共有辺に対応する全てのセル頂点が、新しい共有トポロジーの頂点になったことを再検査します。別の細分化結果の対応表を混ぜることは拒否します。

対応表は一部の面だけでも受理しますが、それでも共有辺の両側に分割が適用されます。与えられていない面のセル分解まで一致したとは主張しません。重複指定や既存端点での追加分割は新しい区間を作りません。配列添字は再構築で変わり得るため、直前・元の辺への対応を使います。

これは共有辺の分割点とセル頂点の整合です。曲線区間全体の同一性、面内部の交線の挿入、キャップとの縫合と子立体の生成はまだ必要です。
