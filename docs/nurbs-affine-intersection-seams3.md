# トリム付きNURBS交差のパラメータseam接続

`sewNurbsAffineIntersection3` は、所有された[両トリム済み交差](nurbs-affine-intersection-trim3.md)から、同じ元(u,v)、同じターゲット座標、同じ空間点の頂点を共有する曲線グラフを構築する。異なる元パラメータへ折り返す空間像は同一視しない。これはパラメータseamの商であり、自己重複を持つ空間像の位相を認定するものではない。

## 点と全区間の検査

元の全頂点を取り込み、各閉辺を他の全頂点の元パラメータで分割する。元の選択されたグラフ枝と(u,v)が一致し、元の一側パッチの空間評価も一致する場合だけ切断する。同じ一座標や投影だけでは接続しない。

隣接する不連続な元パッチは、共有パラメータ辺に制限した同次空間座標の差のgcdを求め、全実根を調べる。保持された両側の辺上にある根を新しい接触頂点として追加し、それから全辺を分割する。端点と中点が同じでも途中の写像が異なる場合には、全区間を共有せず、実際に等しい点だけで接続する。seamContactsはこの辺どうしの有限root接触の記録であり、元の既存頂点の全接触を重複列挙する表ではない。

同じ頂点対を持つ辺の共有では、選択されたUV枝の全区間が一致することを確認する。通常の枝は、元の平方因子を除いた定義式とのgcdの厳密な因子検査と、相手の選択枝との内部一致を使う。両枝は同じ射影開区間内で正則であり、共有因子上の選択枝が途中で別枝に切り替わることはない。垂直辺は同じ固定uを持つ同一のパラメータ線として確認する。

さらに3空間座標それぞれの同次差について、同じ選択枝上で恒等的にゼロであることを検査する。通常枝は同じgcdによる全成分検査、垂直枝は固定uへの特殊化で全係数がゼロかを使う。端点・代表点だけの一致を全空間写像の一致へ拡張しない。正の重みにより分母を払う検査は有効な閉区間上で同値である。

## 結果と保証範囲

頂点usesは元のtrim結果のpatch/vertex/edge、辺usesは元のpatch/edgeへ対応する。各辺のlower/upperは元グラフの共通座標で、通常枝はu、垂直枝はvである。`nurbsAffineIntersectionComplexEdgePoint3` は所有・番号・閉範囲と元の両トリム評価を検査する。

curveComponentsは頂点・辺のグラフだけの連結成分である。暗黙regionは元のpatch番号と所有された集合をregionsへ別に保持し、連結性が分からないregionを1成分として強制的に結合しない。region相互、曲線とregion、region境界の全体位相は未解決のままである。孤立した元の点も曲線グラフの頂点として保持する。

入力の面領域自体を分割したことにはならず、一般NURBS SSI、周期パラメータの同一視、全空間像の埋め込み、殻・材料認定、共通Body採用も完成させていない。この説明は新実装やTypeScript全体の機械証明ではない。

## 検証

相手crease上の重複辺、連続な元seam、同じ元パラメータの不連続な像、端点と中点で一致する異なる写像の全孤立接触、別パラメータの同じ空間曲線、暗黙regionの分離、無理数端点の通常枝の共有、水平seamの同次差検査、所有・範囲と由来を確認する。
