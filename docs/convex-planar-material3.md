# Convex rational polyhedra in the plane/cylinder material backend

`boundaryConvexPlanarMaterial3(source)` accepts an actual factory-owned `PreparedPlanarSolid3`. It requires one nonempty material shell with depth zero and positive volume. Existing planar-solid construction has already checked closed incidence, exact embedding, shell orientation and material nesting. Copies of this object do not inherit ownership.

Each face supplies its outward oriented supporting plane. Every rational source vertex is tested against every kept negative halfspace. A positive value rejects the input as nonconvex. Together with the validated single closed embedded boundary, these supporting faces bound the convex polytope, so their closed halfspace intersection represents the original material. This is a geometric construction argument, not a new Lean theorem or a proof about arbitrary unvalidated meshes. Concave material, voids and disconnected shells require a richer decomposition and are rejected.

A finite auxiliary vertical cylinder strictly contains the vertex bounding box: its radial square is the squared x/y box diagonal plus one, and its axial bounds extend each z extreme by one. It therefore contains the whole convex hull strictly, including the boundary. Conjoining this inactive guard establishes the bounded material constructor's conservative bound without changing the selected boundary. Rational arithmetic, algebraic intersections and complete native domains remain exact; no numerical tessellation replaces the boundary.

Selected faces retain only original planar support IDs; carrier arrangements may split one supporting face into several patches. Maximal coplanar consolidation is not implemented here. The owned material result uses existing manifold Body adoption and complete recipe replay. The mixed Body entry point now accepts actual convex planar/consolidated Body sources alongside native boxes and cylinder-family Bodies; see [Body dispatch](convex-planar-body3.md). General nonconvex planar Body dispatch remains incomplete.

Two new tests pass: a tetrahedron retains exactly its four supporting planes through manifold reconstruction/replay and agrees with independent simplex inequalities at 343 rational grid points; a genuine concave single shell, disconnected tetrahedra and copied ownership reject. The existing planar preparation uses exact triangles for embedding validation; these do not substitute an approximate mesh for the output analytic plane domains. 

All four new cases passed across separate invocations. The added curved intersection retains cylindrical and original planar domains through Body adoption and full replay (about 275 seconds under concurrent diagnostic load). A reflected, sheared and translated tetrahedron also replays with its positive material orientation and independent membership checks (about 13 seconds). The preceding numeric-change source passed all 817 non-hard regressions; that whole invocation was not repeated for this additive bridge. Current source inventory/arithmetic correspondence and the existing 133-declaration scoped Lean audit passed. This is not a full TypeScript execution proof or general SolidCraft parity result.
