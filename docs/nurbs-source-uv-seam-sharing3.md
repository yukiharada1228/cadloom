# 不連続な曲面継ぎ目のUV辺共有

`buildNurbsSourceBoundaryComplex3` は、異なる空間像を持つ交差曲線であっても、厳密に同じ有限な垂直・水平UV線分であると確認できれば一つのUV辺にまとめます。元の交差辺・区間・方向はすべて `intersectionUses` と逆引き `intersectionEdges` に保持します。空間曲線を溶接する処理ではありません。

## 全区間の根拠

垂直線は所有された代数曲線グラフのvertical辺から確認します。水平線は端点のvが同じで、固定した有理vについてグラフ多項式がuの恒等的零になることを要求します。さらに厳密な内点評価で選択されたグラフ分枝がその直線上にあることを確認します。元のグラフ辺には内部の分枝交差・投影臨界点がないため、全区間で同じ直線成分になります。端点や内点の一致だけでは共有しません。有理数として確認できない水平値や一般の非直線重複はこの経路では共有しません。

初めに全交差頂点をUV頂点へ登録し、各辺を全ての所属する頂点パラメータで分割します。その後、両端のUV頂点が同一または逆順で、両方の辺が上記の直線認定を通る場合だけ共有します。部分重複も端点で分割され、共通区間だけが共有されます。正の長さの軸平行線分は両端から一意に決まるため、この条件は全区間のUV像の一致を保証します。

## 下流での意味

UVの回転順序・面分類・面照会は一つの辺を使います。曲面のリフトと面パッチ選択は全ての入射するパッチ側を引き続き保持します。認定面の境界複体は全区間の空間像を別途検査するので、不連続な継ぎ目は別の3D辺・頂点に分かれます。

以前はこの入力がUVの同方向重複germで未解決になりました。既存の同じfixtureを、回転順序、二つの内側面、一つの共有UV辺の照会、異なる空間辺の保持まで到達する回帰へ更新しました。一般の未解決入力を無条件に認定する変更ではありません。

追加の検証は垂直・水平双方の不連続継ぎ目と、その片側だけが長い部分重複を扱います。接線が等しい別の非直線分枝の既存テストも維持します。任意の重複曲線検出、異なるUV面同士の空間交差、閉じた立体や材料の認定は未完了です。
