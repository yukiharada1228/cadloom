# 最小のプレートエディター

```sh
npm ci
node examples/editor/serve.mjs
# http://127.0.0.1:4180 を開く
```

起動時にカーネルと画面のTypeScriptをビルドします。Node.js 24以上が必要です。終了はCtrl+C、ポート変更は`CADLOOM_EDITOR_PORT=4181 node examples/editor/serve.mjs`です。追加の実行時依存・バンドラー・WASMはありません。

## 操作

- 板の幅・奥行き・厚さを整数・小数・分数で変更する。
- 穴を有効・無効にし、穴の位置・幅・奥行きを変更する。
- 3D表示をドラッグして回転、ホイールで拡大縮小する。
- 「JSONを保存」で寸法と厳密なメッシュを書き出す。
- 「JSONを開く」で寸法を復元し、カーネルで再生成する。

全寸法は同じ任意単位で扱い、単位変換は行いません。板と穴の寸法は正、穴は外周へ触れないよう厳密に内側へ収める必要があります。無効入力時は直前の有効な表示を残し、保存を無効にします。

## データ形式

```json
{
  "format": "cadloom.plate",
  "version": 1,
  "parameters": {
    "width": "8",
    "depth": "8",
    "thickness": "2",
    "hole": {"x":"2","y":"2","width":"4","depth":"4"}
  },
  "mesh": {"vertices":[],"triangles":[],"volume":"96"}
}
```

上の`mesh`は形式説明の省略例で、実際のファイルには全座標・面・体積などが入ります。寸法・座標・体積は既約有理数の文字列で保存し、JSONの浮動小数点へ変換しません。例えば小数`1.50`は同じ値の`3/2`として保存します。穴がなければ`hole:null`です。

**復元の正本は`parameters`です。** `mesh`は参照用の派生スナップショットで、読み込み時には使用せず寸法から再生成します。これによりメッシュへの誤変更を計算へ持ち込まず、三角形の分割方法が将来変わっても寸法を復元できます。形式・バージョン・文字列型・正値・穴の包含を検査します。ファイル読み込みは1MBまでです。

## 構成と検証範囲

`model.ts`が入力検査・ドキュメント・再生成、`editor.ts`が画面操作と保存、`viewer.ts`がWebGL表示を担当します。全ての幾何計算はブラウザーが`dist`の同じカーネルを直接呼び出します。サーバーは127.0.0.1に限定した静的ファイル配信のみで、寸法・ファイルを受信せず、ワークスペース全体も公開しません。

`npm test`で保存・復元、分数・巨大座標・微小厚さ、無効寸法、未知バージョン、入力からの独立性を検査します。画面はego-browserで編集、穴切替、無効入力、JSONの実ダウンロードと読み込み、不正ファイルの拒否、回転・拡大縮小・視点復帰、モバイル表示を確認します。

新しい幾何アルゴリズムは追加していないため、UIに形式証明は追加せずテストで検査します。既存のカーネルの限定した数学的証明を、編集画面やTypeScript実行全体の証明とは扱いません。

3D表示のみ近似し、極端な寸法比では細い形状が画面上で潰れる場合があります。対象は長方形の板と一つの長方形の穴です。自由スケッチ、履歴編集、曲面、3D集合演算、商用CADファイル入出力は含みません。自動保存は行わないため、閉じる前にJSONを保存してください。
